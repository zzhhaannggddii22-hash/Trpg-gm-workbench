# Triangle Agency｜Templates

本目录保存三角机构专属模板。系统规则机制字段只适用于 `system_id: triangle_agency`，不得作为通用 Session 模板复用。

- [游戏 LOG 模板 v0.1（历史版本）](./SESSION_LOG_TEMPLATE_v0.1.md)：早期三角机构桌面记录模板，保留 QA、Harm、Chaos Pool、Burnout 等系统专属字段。

注意：该模板为历史版本，不取代当前通用 Session Log 规范，也不自动成为当前战役的权威记录模板。当前通用模板位于 `GM_Training/03_SESSION_LOG_TEMPLATE.md`；正式战役状态仍以 Campaign 内对应权威文件为准。
