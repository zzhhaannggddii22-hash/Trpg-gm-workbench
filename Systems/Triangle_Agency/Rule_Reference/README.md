## 检阅顺序

1. 按[常规规则调用路由](./05_常规规则调用路由.md)识别当前阶段、机制和所需资料。
2. 读取对应专题协议、基础规则笔记和相关疑点/裁定记录。
3. 专题资料未覆盖关键条件或需要完整上下文时，回查上游 Markdown 母稿的相关完整章节。
4. 涉及图表、表单、轨迹、视觉布局、遮挡、跨页结构或 OCR/提取歧义时，回查 PDF 对应页面；PDF 不作为普通规则查询的默认入口。
5. 结合角色当前 ARC、已解锁能力、补给和战役状态核对适用性。
6. 结论中区分原文、整理笔记解释、助手推论、未决疑点和用户确认的桌规。

## 维护原则

- 本目录中的工作文档随实际备团、带团和规则核验持续修订。
- 上游规则原文保持原样；本目录只维护索引、检阅笔记和桌面裁定。
- 不把摘要当作原文，不把待核推论升级为正式规则。
- 新发现的规则差异记录问题、证据页码、影响范围、临时处理和用户最终裁定。
- 页码明确标记为中文版 PDF 物理页码；不得与源 PDF 页码或正文印刷页码混用。
