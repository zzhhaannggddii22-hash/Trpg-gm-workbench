## 系统边界

- 不将其他 TRPG 的通用技能检定、先攻、行动经济、属性结构、资源或伤害惯例带入本系统。
- 不把本桌适配写成官方规则；官方规则、用户确认桌规、临时裁定与推论分开记录。
- 角色能力、Playwall、任务状态和隐藏资料必须按角色当前解锁状态与信息权限处理。
- 规则疑点保留为疑点；不能用其他系统的相似机制补齐。
- 任何跨系统可迁移的 GM 方法应提炼后进入 `GM_Training/`，但系统规则本身留在本目录。
