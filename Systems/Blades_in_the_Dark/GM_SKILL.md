# Blades in the Dark｜GM Skill

> system_id: blades_in_the_dark  
> 状态：DRAFT / 待候选验证  
> 本文件仅定义本系统的主持习惯，不代替规则文本与 Campaign 设定。

## 1. 核心主持立场

Blades 的 GM 负责让一座动态的地下世界围绕 Crew 运转，而不是预先写好一条剧情路线，再让玩家逐步经过节点。

- 为每个重要 NPC 确定具体欲望、偏好的行动方式、资源和边界。
- 为每个重要派系确定目标、关系、Tier、Status、可采取的行动。
- 把可行动的机会提供给玩家；让玩家决定要冒什么风险、做什么交易、伤害谁或帮助谁。
- 依照玩家的行动和世界中的实际动机，推进后果与变化。
- 不保护玩家免于坏结果，也不为了戏剧性制造没有因果来源的惩罚。
- GM 不需要预知故事结局；需要知道当前局势、各方目标，以及行动会怎样改变局势。

## 2. 呈现与节奏

### 2.1 场景呈现

描述玩家能观察、听到、闻到、触摸到的具体事物；用人物的行动和环境细节传达社会地位、威胁、机会与情绪。不要用抽象总结替代可供玩家判断的现场信息。

一个场景至少要让玩家知道：
- 他们在哪里，谁在场；
- 最明显的机会或问题；
- 可见的危险、限制和时间压力；
- 与行动相关、角色有资格知道的事实。

不要把每个普通场景都写成长篇氛围散文。重要信息应可理解、可用，不能淹没在修辞中。

### 2.2 直接切入 Score

玩家确定 Plan + Detail、选好 Load 后，进行 Engagement Roll，切到行动开始且遇到第一个真正障碍的现场。不要再详细叙述一段“他们谨慎接近目标”的流程；这是 Engagement 已经处理的内容。

### 2.3 事前计划轻量化

不要求玩家列出每个备用方案、装备、路线与临场安排。玩家只需选择 Plan 并提供关键 Detail。遇到具体障碍后，让 Flashback 处理此前合理完成的准备。事前准备真正改变风险/机会时才进行信息搜集或长时间场景。

## 3. 行动裁定

- 先问清玩家目标，再确认他们实际上做什么。
- 玩家选择 Action；GM 以其实际行为判断 Position 和 Effect。
- 掷骰前说明 Position、Effect 与可能的风险。
- 不把一个明确危险拆成不必要的多次掷骰；一次 Action Roll 通常应处理一个有意义的障碍与对应后果。
- 不因玩家骰点低就随意增加无关惩罚；每个后果应当是眼前局势可能发生的结果。
- 不因玩家骰点高就忽略后续因果；成果必须按 Effect 合理实现。
- 角色有机会获得信息时，直接给他们可知内容。危险调查和不确定信息使用不同骰型。
- 后果揭示后，给玩家选择是否 Resistance 或 Armor 的机会。

## 4. 时钟使用

时钟用于显示玩家能够理解的复杂进程、时间窗口、危险累积或竞争状态。

建立时钟前先问：
- 这里是否真的有一个多阶段障碍或持续过程？
- 角色是否有办法通过行动推进/阻止它？
- 时钟填满时会发生什么？
- 玩家是否有合理机会知道它正在推进？

时钟应能指导玩家决策，而不是隐蔽的“剧情脚本”。不要将普通门锁、一个守卫或一段简单对话自动转换成进度钟。

## 5. NPC 与派系

重要 NPC 必须有自身利益、目标和偏好手段。差异主要通过他们会如何回应压力、愿意付出什么、如何回避风险、如何对待关系来体现，不必为每人设计夸张口头禅。

派系是城市动态的主要驱动单位：
- 他们会争夺 Claim、保护资产、扩大影响、结盟、背叛或施压。
- 他们的行动必须符合 Tier、资源、关系和已有目标。
- 每次 Downtime 只推进玩家当前关心的相关派系；不要后台模拟全城。
- 派系行动变成地下社会流言时，借由朋友、联系人或 Vice purveyor 通知玩家。

## 6. 后果与公平

- 明确后果，不玩“成功了但其实什么都没发生”。
- 一个后果可以是 Harm、Complication、Reduced Effect、Lost Opportunity 或 Worse Position。
- 如果玩家 Resistance，抵抗必然有效；GM 决定减轻到何种程度，并说明 Stress 成本。
- 不把后果当作惩罚玩家敢于尝试的工具。
- 对不可逆后果（严重 Harm、关系破裂、Faction Status 大幅变化、资源损失、死亡等）确保规则依据和因果链清晰。

## 7. Downtime 的主持

Downtime 是明确的规则阶段，不是简单跳过时间：
1. Payoff；
2. Heat；
3. Entanglements；
4. PC 的 Downtime Activities；
5. 相关 NPC/Faction 的行动与项目推进。

玩家的正式活动次数有限，但普通自由互动不限。帮助玩家提出有趣的 Long-Term Project 点子；尤其当玩家没有明确想做什么时，不要让他们对着菜单发呆。

## 8. 保持规则与设定的边界

- SRD 机制示例不等于可自由复制的官方世界设定。
- 没有经过合法来源核对的地区、NPC、派系细节或专属能力，不可冒充官方内容。
- Fan-made Playbook、Crew、模块和规则扩展必须单独标记为 OPTIONAL / FAN-MADE。
- GM 对规则的解释不是官方原文；需与 SOURCE 和 TABLE ADAPTATION 分开。
