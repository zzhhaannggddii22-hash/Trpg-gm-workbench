# 多斯科沃派系｜GM 速查

> 来源：《暗夜刀锋》中文版规则书 V1.3，PDF pp.288–303。  
> 本文为原创派系索引与状态管理摘要；完整地盘、NPC、盟友/敌人、资产和进度钟细节请查私人原书。

|---|---:|---|---|

| 血肉之躯无我教会 | IV | 崇敬肉体生命力、排斥腐化灵魂世界的宗教秘密结社 | 探索超凡入圣、压制或清除相关灵魂势力 |

| 死域拾荒者 | II | 由囚犯与无业者组成，在闪电屏障外的死域活动 | 获取赦免、争夺死域资源与禁地 |
| 雾中猎犬 | I | 粗野的私枭团体，正在寻找稳定赞助人 | 清除竞争者、争取赞助与航运线路 |

## 2. 派系记录字段

原书详细派系条目通常包含：
- Tier / 层级；
- 简介与当前状态；
- Turf / 地盘；
- NPC；
- Assets / 显著资产；
- Allies / Enemies；
- Situation / 当前情况；
- Faction Clocks / 派系进度钟。

在 Campaign 状态中，建议每个正在影响 PC 的派系至少记录：
`tier`、`status`、`relationship`、`turf`、`active_clocks`、`allies`、`enemies`、`key_npcs`。

不需要为所有城市派系持续模拟每一轮。优先追踪：
1. 与 Crew 关系达到 +2 / -2 或已开战的派系；
2. 正在推进会影响 PC 的进度钟的派系；
3. 与当前 Score、巢穴、熟识或恶欲来源直接相关的派系；
4. GM 当前明确选择采取行动的派系。

## 3. 运行规则

- 派系是有目标、有资源、有关系的行动者，不是静态背景说明。
- 派系进度钟应表达其目标和行动，不应只用作 GM 随机制造麻烦的工具。
- 当派系关系变化时，更新集团卡/派系状态；若变化触发战争、地盘争夺或纠葛，应按核心规则处理。
- 详细 NPC 个性、地盘与进度钟必须查原书，不从本摘要自行补造。
- 公开索引不包含所有派系条目全文；对当前战役真正重要的派系应从私人原书建立独立 Campaign 记录。
