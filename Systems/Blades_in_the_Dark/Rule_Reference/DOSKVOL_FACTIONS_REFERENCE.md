## 2. 派系总表中的其他组织

p.288–290 还列出或简述了以下组织/群体。它们可作为城市背景、关系对象或后续扩展派系，但不要在没有原书详细条目的情况下自行补齐其完整资产和 NPC：

- 机构与执法：帝国军、铁钩监狱、督察官、伊鲁维亚领事馆、斯科夫兰领事馆、赛维洛斯领事馆、匕首群岛领事馆、掠火旅。
- 边缘与神秘团体：被遗忘的众神、狂群、回响道途、斯科夫兰难民、哭泣女士教会。
- 劳工与行业：基建基金会、码头工人、劳工群众、海员、篷车夫帮、密送人行会、墨耙众、铁道护卫、仆人。
- 其他黑道：红焰环社、司库洛克勋爵、群鸦队、昏光修女会、粉碎党、黑灯党、游魂党、乌尔夫·铁裔等。

部分群体可按地区公民、劳工组织或临时势力处理；原书特别提示，若要追踪公民与集团关系，可以将各地区公民视为派系，并根据地区财富与权力决定其层级。

## 3. 详细派系记录字段

原书详细条目通常包含：
- Tier / 层级；
- 派系目标与进度钟；
- Turf / 地盘；
- NPC；
- 显著资产；
- 奇事；
- 盟友与敌人；
- 当前情况。

Campaign 运行状态建议记录：
`tier`、`hold`、`relationship_to_crew`、`turf`、`assets`、`allies`、`enemies`、`key_npcs`、`active_clocks`、`current_situation`。

## 4. GM 如何选择需要追踪的派系

不必每次游戏都模拟整座城市的全部派系。优先追踪：
1. 与 Crew 关系已达到 +2 / -2 或正在战争中的派系；
2. 正在推进会影响 PC、Crew 或城市局势的进度钟的派系；
3. 与当前 Score、巢穴、熟识、恶欲满足者或关键 NPC 直接相关的派系；
4. 已经在虚构中采取行动、会对玩家行动产生后果的派系。

其余派系保留为可查询背景。只有当其行动进入当前游戏时间线时，才需要更新状态。

## 5. 派系行动与状态更新

- 派系必须有目标、资源和行动路径；进度钟描述其正在推进的目标。
- 派系之间的盟友/敌人关系是当前设定状态，不代表关系永远不变。
- 当 PC 的行动改变派系资源、地盘、领导层或利益时，更新相关派系记录。
- 进度钟推进应有虚构中的行动或时间经过作为依据，不要仅为制造戏剧性而任意推进。
- 派系行动产生的结果应进入城市状态，并在之后的场景中以可见方式呈现。
- 不需要为所有派系建立独立、持续运转的后台模拟；仅模拟对战役有意义的势力。
