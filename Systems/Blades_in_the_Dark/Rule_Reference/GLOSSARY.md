# Blades in the Dark｜术语表与译名约定

> system_id: blades_in_the_dark  
> 依据：中文《暗夜冷锋》SRD 与官方英文规则用语  
> 状态：首轮工作译名；未来 Campaign Binding 可锁定本表版本。

## 1. 核心骰型与流程

| English | 当前中文工作译名 | 说明 |
|---|---|---|
| Action Roll | 行动骰 | 处理 PC 的危险/麻烦行动 |
| Fortune Roll | 运气骰 | 判断不确定结果的表现程度 |
| Resistance Roll | 抵抗骰 | 对已明确的后果进行抵抗 |
| Downtime Roll | 休整骰 | 休整活动使用的骰型/骰池称呼；不是独立结果体系 |
| Score | 案件 / 任务行动 | 有具体目标的犯罪任务 |
| Free Play | 自由阶段 | 非 Score、非 Downtime 的自由行动 |
| Downtime | 休整 | Score 结算后的个人与组织活动阶段 |
| Engagement Roll | 参案骰 | 决定 Score 开始时的进入状态 |
| Flashback | 追叙 | 通过过去的准备影响当前场景 |
| Load | 负载 | Score 中角色携带装备的负担档位 |
| Plan | 计划类型 | Assault、Deception、Stealth、Occult、Social、Transport |
| Detail | 计划细节 | 选择计划后必须补足的具体关键细节 |

## 2. Action / Position / Effect

| English | 工作译名 | 说明 |
|---|---|---|
| Action | 行动 | 角色正在执行的具体行动类型 |
| Action Rating | 行动评等 | 该行动的骰池点数 |
| Position | 情势 | Controlled / Risky / Desperate；决定后果严重度 |
| Controlled | 稳妥 | 更有利的情势 |
| Risky | 险峻 | 通常默认情势 |
| Desperate | 绝望 | 极其危险的情势 |
| Effect | 效果等级 | 决定行动成果范围 |
| Limited Effect | 有限效果 | 较弱/部分成果 |
| Standard Effect | 标准效果 | 预期成果 |
| Great Effect | 重大效果 | 超额/更大成果 |
| Consequence | 后果 | 行动风险的实际代价 |
| Reduced Effect | 减弱效果 | 成果被削弱一级 |
| Complication | 复杂状况 | 新麻烦、威胁或危险进程 |
| Lost Opportunity | 失去机会 | 当前机会消失，需要新进路 |
| Worse Position | 更糟情势 | 后续行动处于更危险的位置 |
| Potency | 效力 | 方法/能力对目标的有效程度 |
| Quality | 品质 | 装备、资源或资产的品质 |
| Scale | 规模 | 人数、范围或影响量级 |

## 3. PC 属性与行动

| Attribute | 中文 | Actions | 中文工作译名 |
|---|---|---|---|
| Insight | 洞察 | Hunt / Study / Survey / Tinker | 狩猎 / 研究 / 调查 / 修补 |
| Prowess | 勇猛 | Finesse / Prowl / Skirmish / Wreck | 灵巧 / 匿踪 / 冲突 / 破坏 |
| Resolve | 决心 | Attune / Command / Consort / Sway | 同调 / 命令 / 勾结 / 动摇 |

注意：属性组用于 Resistance Roll；普通 Action Roll 使用一个具体 Action Rating。不要将“属性”当成行动骰池。

## 6. GM 运行规则

- “行动”不能与“行动骰”混用：前者是玩家选择的具体行为，后者是处理危险行动的骰型。
- “情势”不能译/读成难度；它只决定后果风险。Effect 决定成果范围。
- “Turf” 与 “Claim” 不同：前者对 Crew 成长有直接作用；后者是地图上的利益节点，部分 Claim 可能本身也属于 Turf。
- “Tier” 与人数不等价；Tier 同时反映实力、品质、地位和资源。
- “Downtime” 并不等于“只能做六种事”；六项正式 Downtime Activity 有次数限制，其他自由互动仍可进行。
