# Blades in the Dark｜PC Playbook 与 Crew 能力索引

> 规则身份：`blades_in_the_dark`  
> 交叉核验：官方 Full Player's Kit v8.2；中文《暗夜冷锋》SRD 的能力说明。  
> 用途：角色/组织建档时选择实际能力，并在运行中按触发条件调用。  
> 本文是原创短摘要，不复制官方工具包或中文 SRD 的完整能力描述。正式裁定仍以 Campaign 锁定版本的卡面原文为准。

## 1. 使用规则

1. 每个 PC 必须绑定一个 Playbook；每个 Crew 必须绑定一种 Crew Type。
2. 建卡时，玩家从对应 Playbook/Crew 的能力列表中选择起始 Special Ability；后续成长继续从该列表选择。
3. **Veteran** 是跨来源能力入口：按规则允许时，从其他 Playbook 或 Crew 的能力来源选择一项；记录它来自哪里。
4. 运行时只加载本桌 PC 与 Crew 实际拥有的能力。没有选取的能力不参与被动效果、资格判断或触发检查。
5. 每项能力以 `ability_id / trigger / effect / cost / timing / reset / exceptions` 记录。成本与恢复时点尤其要留意 Special Armor、Stress、Downtime、Score 次数与每次行动限额。
6. 本索引的中文名称用于检索，英文名用于精确对照。若与 Campaign 使用的角色卡译名不同，以英文 ability name + 卡面正文定位。

## 2. 角色创建运行要点

- Playbook 是角色的专注领域、能力选择和 XP 触发方式，不是职业限制；任何 PC 都可以使用全部 12 项 Action。
- 每个 Playbook 卡上有 3 个预置 Action dots；玩家额外分配 4 dots，总计 7 dots。创建时任何 Action rating 不能超过 2。
- 依次选择 Heritage、Background、Playbook Special Ability、一个 Friend、一个 Rival、Vice 与 Vice Purveyor，填写姓名/别名/外貌，并检查起始物品和 XP Trigger。
- 每个角色卡有普通 Armor、Heavy Armor、Special Armor 三个独立使用格。没有相应 Special Ability 的 PC 不能使用 Special Armor 格。
- Score 前只选择 Load 档位；行动期间再按 Load 额度声明携带的道具。

## 3. 七种核心 PC Playbooks

### 3.1 Cutter｜利刃 / 危险且具有威慑力的战士

核心侧重：近战威胁、战斗中的保护、身体强力与威慑。

| Ability | 运行摘要 |
|---|---|
| Battleborn（为战而生） | 消耗 Special Armor 来降低战斗伤害，或在战斗中 Push Yourself；此能力的强推不付通常的 2 Stress，按能力列明的收益处理 |
| Bodyguard（保镖） | Protect 队友时，抵抗骰 +1d；为当前情境潜在威胁搜集情报时 +1 Effect |
| Ghost Fighter（奥术战士） | 为双手/近战武器/工具灌注灵体能量，对抗超自然目标时获得 Potency，并可按能力与灵体缠斗 |
| Leader（领导者） | 在战斗中 Command Cohort 时，其 Level 3 Harm 不会使其退出战斗；获得 +1 Effect 和 1 Armor |
| Mule（骡子） | Load 上限提高：Light 5、Normal 7、Heavy 8 |
| Not to Be Trifled With（万夫莫敌） | Push Yourself 做出超人级身体力量，或与最多 6 人的小帮派平等近战，不受相应 Scale 弱化 |
| Savage（野蛮） | 释放身体暴力时特别吓人；Command 被恐惧影响的目标时 +1d |
| Vigorous（强健） | Healing Clock 开始时永久标记 1 格；治疗处置骰额外 +1d |
| Veteran | 从允许的其他能力来源选择 |

## 4. 六种核心 Crew Types

## 5. 运行时能力装载

正式 Campaign 建立 PC / Crew Sheet 后，建立一份已选能力清单：

```yaml
active_abilities:
  pc:
    - actor_id: "<pc>"
      playbook: "<playbook>"
      abilities:
        - ability_id: "<exact English ability name>"
          source_version: "<version>"
          trigger: "<trigger summary>"
          cost: "<stress/armor/coin/time/none>"
          reset: "<when restored>"
  crew:
    crew_type: "<one of six types>"
    abilities:
      - ability_id: "<exact English ability name>"
        scope: "<crew-wide / PC / cohort / score / downtime>"
        trigger: "<trigger summary>"
        cost: "<if any>"
        reset: "<if any>"
```

运行时只在以下事件触发能力检查：
- 对应 Action / Resistance / Cohort / Score / Downtime 活动正在发生；
- 特定资源、关系、环境或目标符合能力条件；
- Score / Session / Downtime 结算点触发 XP、额外活动或被动收益。

不要在每次玩家发言时扫描全部能力。角色获得/更换能力时更新已选能力表；规则版本变化或能力原文不明确时回查该卡面。
