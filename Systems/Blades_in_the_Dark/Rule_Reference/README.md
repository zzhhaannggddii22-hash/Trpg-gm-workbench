# Blades in the Dark 规则来源与覆盖索引

本文件只负责定位来源、说明覆盖边界与记录版本状态，不重写或替代规则原文。当前规则状态为学习阶段；尚未批准任何 Campaign 版本。

## 一、中文核心来源

**主入口：**[暗夜冷锋（Blades in the Dark）中文 SRD](https://bitd.wayneh.tw/)

中文站将规则主体分为以下部分：

| 章节 | 页面 | 覆盖主题 |
|---|---|---|
| 基本规则 | [基本规则](https://bitd.wayneh.tw/1-basic) | 游戏结构、共同创作与主持立场、主观判定、行动骰与抵抗、压力与创伤、时钟、行动流程、情势与效果、后果、护甲与死亡、调查、货币、层级/地盘/派系地位/权利、角色与组织成长 |
| 角色 | [角色](https://bitd.wayneh.tw/2-characters) | 角色创建、出身与背景、行动点、角色特殊能力、密友与敌手、恶习、负载与装备 |
| 组织 | [组织](https://bitd.wayneh.tw/3-crew) | 组织类型、初始组织、猎场、升级、联络人、同夥、组织特殊能力与组织资源 |
| 案件 | [案件](https://bitd.wayneh.tw/4-score) | 案件目标、计划、参案、负载、追叙、团队合作与放弃案件 |
| 休整 | [休整](https://bitd.wayneh.tw/5-downtime) | 案件结算、盯迫/通缉压力、糾葛、监禁、派系/NPC 动态、休整活动、恶习、长期专案、恢复、仪式与打造 |
| 非 SRD 部分 | [资源](https://bitd.wayneh.tw/6-resources) | 列出辅助表单与玩家工具包；页面明确说明本部分资源不在 CC BY 授权范围内 |

以上是网站提供的章节导航与覆盖主题概览，不表示每一项已完成逐条规则核验。具体裁定仍须进入对应页面核对完整规则上下文。

## 三、版本与证据优先级

当前中文 SRD 的介绍页说明它翻译自 One Seven Design 发布的 Blades in the Dark System Reference Document，并标注 CC BY；中文翻译由洪伟以 CC BY 发布。中文网站没有清楚标注 SRD 的具体修订号。不可仅凭网页当前可访问或工具包文件名，推断未来 Campaign 的规则版本。

未来 Campaign 应在 `SYSTEM_BINDING.md` 明确精确规则版本。规则冲突按以下顺序解决：

1. Campaign 绑定的完整规则版本、官方勘误与对应补充文件；
2. 同一版本的官方 SRD / 官方免费工具；
3. 本目录内经核验的规则索引与摘要；
4. 明确批准的本桌适配；
5. GM 推论（必须标记为推论，不得伪装成规则）。

中文 SRD 是当前首要中文查阅入口；当它未覆盖某个角色能力、世界设定、规则例外或官方补充时，必须回查适用版本的合法官方来源。不得拿其他系统的相似术语补缺。

## 四、授权和文件存放规则

- 中文 SRD 页面标示原 SRD 及中文翻译的 CC BY 授权。引用/改编时保留 One Seven Design、John Harper（适用时）、译者洪伟、来源链接与授权说明。
- 中文网站的“非 SRD 部分”不受该 CC BY 声明覆盖；其中在线工具包与表单只保留外链，不镜像、不提取其内容进仓库。
- 官方付费规则书、第三方模组和完整翻译不得复制进公开仓库。
- 本地资料只保存自写摘要、检索入口、规则 ID、术语索引、核验结果与明确授权的内容。

## 五、规则查阅原则

遇到规则问题时，先锁定当前 Campaign 的 `system_id` 和 `ruleset_version`，再进入本目录对应条目。规则摘要负责定位，不替代原文。涉及成本、触发条件、骰池、行动顺序、情势/效果、后果、持续时间、抵抗、例外或状态变更的裁定，应检查完整适用条文。

当前尚未建立正式运行协议。不要把这份来源索引当作 GM Runtime 已可运行或系统已激活的证明。
