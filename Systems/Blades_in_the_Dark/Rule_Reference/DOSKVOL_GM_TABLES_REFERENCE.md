# 多斯科沃 GM 生成工具｜本地检索与运行参考

> 来源：《暗夜刀锋》中文版规则书 V1.3，PDF pp.287、305–313。  
> 原始随机表与完整条目保存在私人资料库。本文为原创工具索引、使用程序和状态记录规范，不复刻原书表格。

## 2. 城市周度变化：三类工具不要混用

### 街头流言（p.287）

每周或 GM 需要时，从原表生成一条流言。它表达的是城市里正在传播的说法，不自动等于事实。

运行时记录：
- 流言原话或玩家听到的版本；
- 来源/传播者（若已知）；
- 可信度线索；
- 可能牵涉的派系、地区或 NPC；
- 是否已被验证、证伪或转化为实际事件。

### 登报城市事件（p.287）

每周或需要时生成一个城市尺度的事件类别。它改变城市背景节奏，可影响多个地区、派系或普通居民。

不要自动将每个事件都变成 PC 必须处理的任务。先判断它对当前地区、Crew 目标、派系行动或 NPC 日常是否产生可见影响。

### 惊奇要事（p.287）

每周或需要时生成一个地区尺度的奇事。与城市事件不同，它更适合直接成为抵达场景时可观察到的环境变化或即时麻烦。

**推荐节奏：** 每个游戏周最多按需处理这三类信息；当玩家正专注于紧凑的 Score 场景时，不要为了“周度模拟”强行插入随机事件。

## 3. 恶欲满足者（p.305）

原书按恶欲类别列出满足者及其地点，包括狂信、赌博、奢侈与享乐、义务、享乐与麻木、怪诞等类别。

使用流程：
1. 先读取角色卡上的恶欲类别与具体表现。
2. 在原书对应类别中选择适配的满足者/地点；若角色已有固定满足者，优先沿用。
3. 确认满足者与角色的关系、可接触性、利益和风险。
4. 将实际变化写入角色关系或战役状态，而不是把满足者当作一次性场景装饰。

原书中的名单是可用人选，不表示所有角色都与这些人物有既定关系。

## 4. 城市场景生成（pp.306–307）

### 街头（p.306）

原表提供六组场景维度：
- 可见事物与城市设施；
- 地点用途；
- 氛围；
- 视觉、声音、气味；
- 道路/空间类型；
- 场景细节。

### 室内（p.307）

原表提供：
- 室内物件；
- 建筑用途（常见/少见）；
- 环境细节。

**轻量使用规则：**
- 每次场景只取 2–4 个互相支持的细节，不必把所有维度都掷满。
- 优先选能影响行动、揭示阶层/用途或制造可交互对象的细节。
- 已有明确地点事实时，不再随机覆盖它。
- 随机结果若与当前地区、季节、时间或场景逻辑冲突，重新选择或改用合适维度；不要为了服从骰表而破坏连续性。

## 5. NPC 生成（pp.308–309）

原书人物生成工具覆盖：
- 出身（含阿克洛斯与外地来源）；
- 打扮；
- 外貌；
- 目标；
- 首选手段；
- 普遍/少见职业；
- 姓名、姓氏、绰号；
- 性格特征、兴趣与特色。

### 推荐生成顺序

1. **场景职责**：先确定 NPC 在当前场景中的作用（阻碍、提供服务、见证、雇主、竞争者等）。
2. **社会位置**：确定出身、职业与所在地区是否相容。
3. **目标**：选择其正在追求的具体结果。
4. **手段**：确定其通常如何争取目标。
5. **个性辨识**：选取一个主要性格特征，再选兴趣或特色作为补充。
6. **外在识别**：选择外貌、服饰、姓名或绰号。
7. **关系与行动**：只在 NPC 与 PC/派系产生持续联系时，才建立可追踪关系或进度钟。

### 反模板化约束

- 不要把所有 NPC 都生成成“性格特征 + 兴趣 + 特色”三项标签的堆叠。
- 选一个能改变其行为的主特征即可；兴趣和特色只在场景中自然出现时呈现。
- 目标必须是当前可行动的目标，而不是抽象人格描述。
- 首选手段决定 NPC 面对阻碍时会采取什么方式；这比多加几个形容词更能区分人物。
- 对背景群众与一次性小角色，不必完整生成姓名、目标、兴趣和关系。

## 6. 幽灵、恶魔与惊骇憎物（p.310）

原书提供几类不同的超自然生成维度：

| 对象 | 生成维度 | 使用目的 |
|---|---|---|
| 恶魔 | 名称、外在特征 | 快速建立可辨识的恶魔形象 |
| 幽灵 | 性格/行为特征、引发效应 | 确定其行动倾向及现场异常表现 |
| 恶魔 | 类型、亲和、欲望 | 建立其本质、力量倾向和驱动力 |
| 被召唤的惊骇憎物 | 外形/构成类别 | 生成仪式产物或异常威胁 |

**运行约束：**
- 幽灵引发效应是现场现象，不等于幽灵本身的完整能力清单。
- 恶魔欲望用于理解其动机，不自动构成可交易条款。
- 外形随机结果不替代核心规则中的超自然力量、仪式、危险与后果裁定。
- 惊骇憎物的外观生成不等于其战斗属性；若进入冲突，仍需按当前规则和具体虚构情境确定能力与风险。

## 7. 被遗忘的众神与邪教活动（p.311）

原表以神明与活动类别组合邪教行为。活动类别包括献祭、集会、获取、毁灭、祝圣和亵渎。

使用时先确定：
1. 邪教追随的神明/存在；
2. 本次活动属于哪一类；
3. 活动需要的对象、地点、仪式材料或参与者；
4. 活动对外部世界产生的可观察后果；
5. 与之冲突或合作的派系。

不要把表格生成结果直接当作邪教完整教义。神明、教团和活动之间的关系仍需根据具体场景建立。

## 8. 刻痕生成（pp.312–313）

### 客户/目标与工作类型（p.312）

原书将客户/目标分为平民、罪犯、政治、黑道、奇异等方向，并提供不同工作类型。它适合快速生成“谁来找 Crew、希望他们做什么”的起点。

### 扭曲或复杂化（p.313）

复杂化表覆盖超自然、犯罪、交通/地点限制及各方秘密愿景等方向。其作用是改变工作条件、制造额外风险或揭示幕后动机。

### 关联人物与派系（p.313）

原书提供一名关联人物的类别，以及一组可供选择的城市派系。这可用于把 Score 接入 PC 的朋友/竞争者/恶欲满足者、Crew 熟识、城市名流或超自然存在。

### Score 种子生成程序

1. 选定客户/目标类别。
2. 选定工作类别。
3. 确定本次工作真正的目标和可见报酬。
4. 选取一个扭曲因素；只有当工作需要更复杂的局面时才叠加第二项。
5. 选定关联人物或派系，将其利益与工作目标连接。
6. 明确开局时玩家能知道什么、需要调查什么。
7. 生成 Engagement 前，确认目标、计划方向与潜在风险均已进入虚构。

**不要**把表格的每一项都强制塞进同一个 Score。它们是生成工具，不是必须全部触发的程序。

## 9. 本地资料调用规则

- 精确随机表结果、完整名单和表格格子：查私人资料库中的核心规则书 V1.3 对应 PDF 页。
- 本文件用于知道“有哪些工具、何时用、如何把结果接入游戏”。
- 如果战役状态中已有事实，优先使用既有事实，不要重新掷骰覆盖。
- 随机生成只负责提供素材；GM 仍须判断因果、场景可见性、角色动机和规则后果。
- 公开仓库不复制原书完整随机表或大段名单。
