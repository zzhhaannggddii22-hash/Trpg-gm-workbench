# 暗夜刀锋｜角色卡与集团卡模板字段索引

> 来源：用户提供的深度切割空白角色/集团剧本工作簿，以及官方核心剧本卡 ZIP。  
> 本文只记录模板结构与使用定位，不公开原始表格、不复刻完整卡面。

## 1. 资产清单

### 官方核心剧本卡 ZIP

ZIP 内共 19 个 XLSX：
- 2 个空白模板：角色剧本、集团剧本；
- 10 个角色剧本表：核心 Playbook 与特殊/扩展角色表；
- 7 个集团剧本表：核心 Crew 类型。

角色剧本表：低语、剃刀、毒蛭、滑弦、潜影、猎犬、络蛛，以及吸血鬼、幽灵、机壳三张特殊/扩展表。后面三者并非默认核心 PC 选择，启用前应核对其适用资料与 Campaign 设定。
集团剧本表：刺客、匪寇、影贼、私枭、邪教、黑商，以及一张空白集团表。

### 深度切割空白角色剧本

工作表：
- `角色卡`
- `笔记`
- `Sheet1`

主要覆盖：
- 角色归属集团、姓名、绰号、出身、经历、外貌；
- 恶欲及满足者、硬币/存款；
- 行动与属性点数、压力、额外压力、创伤与伤害；
- Playbook 特殊能力、经验触发；
- 仪式书、工艺蓝图；
- 常规物品与 Load 参考。

### 深度切割空白集团剧本

工作表：
- `集团`
- `派系阶梯`

主要覆盖：
- 集团名称、巢穴、名头；
- 声名、罪熵、通缉等级、层级与权势；
- 强化、资本、地盘、麾下、熟识；
- 监狱资本与相关能力；
- 派系层级、权势、关系；
- 战争状态与战争惩罚。

## 2. 字段使用原则

1. **角色卡与集团卡是状态记录工具，不是规则引擎。** 所有格子含义以 Campaign 绑定的规则文本为准。
2. 角色卡中压力、伤害、创伤、行动点数、特殊护甲等状态需要在对应规则事件发生时更新。
3. 集团卡中的声名、罪熵、Heat/Wanted、层级、权势、关系和资本不能混为一个资源。
4. Playbook 特殊能力与 Crew 特殊能力应记录“实际拥有”的选项；运行时按触发条件加载，不需要每轮扫描所有能力。
5. 仪式书、工艺蓝图和常规物品栏用于保存角色实际掌握的具体内容；不能只记录一个名称而省略效果、条件、成本和副作用。
6. 派系阶梯用于追踪外部势力的状态；派系关系变化应同步影响对应的派系记录，而不是只改叙事描述。

## 3. 建档时的推荐检查

### PC

- Playbook 与规则版本；
- 出身、经历、恶欲及满足者；
- Action dots 与 Attribute 分组；
- Special Ability；
- Load / Armor 相关状态；
- 已知仪式、配方、工艺与物品；
- XP、Stress、Trauma、Harm。

### Crew

- Crew Type 与规则版本；
- Hunting Ground / 专属活动类型；
- Tier、Hold、Rep、Heat、Wanted、Coin；
- Lair、Turf、Claims；
- Upgrades、Special Abilities、Cohorts；
- Contacts / 熟识与其威胁；
- Faction status 与 Faction clocks。

## 4. 版本与模板差异

- 官方核心剧本卡 ZIP 与深度切割工作簿并非同一套表格布局。
- 深度切割工作簿额外提供笔记/仪式/工艺/物品参考，以及派系阶梯等宽表。
- 不要把模板中出现的字段自动视为所有 Campaign 都必须使用的规则机制。
- 若模板字段与所绑定规则版本不一致，应以规则文本为准，并在 Campaign 使用的卡表中记录差异。
