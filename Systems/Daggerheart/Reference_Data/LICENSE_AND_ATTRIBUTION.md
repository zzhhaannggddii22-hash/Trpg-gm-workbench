# 数据许可与署名记录

本目录包含 Darrington Press 发布的 **Daggerheart System Reference Document 2.0**（2026-08-25）Public Game Content 的部分规则与数据。DPCGL 2.0（许可 PDF 标注 Last Updated 2026-08-05）明确将 Daggerheart SRD 2.0（包括 Domain Icons）列为 Public Game Content，并在符合许可条款的前提下允许整体或部分复制、分享。该授权不意味着取得 Darrington Press / Critical Role 的所有知识产权。

## 官方许可

- 官方 SRD 2.0：https://www.daggerheart.com/srd/
- DPCGL 2.0：https://darringtonpress.com/license/
- 官方下载与勘误：https://www.daggerheart.com/downloads/

## 本目录允许收录的范围

- SRD 2.0 中属于规则、机制、工具、参考卡与 Stat Block 的 Public Game Content。
- SRD 2.0 内可按许可共享的职业、子职业、领域卡、种族、社群、敌人与环境数据、装备条目。
- 对 SRD 内容进行的结构化重排、Core / Hope & Fear 分组、索引和格式转换；此类文件属于 Adaptive Content，仍须遵守 DPCGL。

## 明确排除

- 商业核心规则书中未列入 SRD 2.0 的精确正文、章节文本、版面设计与整页扫描。
- Campaign Frame 的完整原文、地图、剧情、派系设定及其他专有故事内容；DPCGL 对 Campaign Frame 的分享范围另有限制，只允许以实际游戏记录形式分享，不得通过其他格式重新发布、印刷或改编成新的文字/衍生作品，除非另获书面许可。
- 艺术、插画、地图、角色图像、Logo、商标图形、音乐与其他视觉/音频作品。
- 非公开/付费模组、未获再分发授权的卡牌图像及商业工具包。
- 任何未明确包含在 Public Game Content 内、仅因可在线浏览或可下载而被误认为可镜像的材料。

本项目不导入 SRD 中单独列出的 Campaign Frame 文件，也不复制官方地图与卡牌视觉设计。Supplemental Campaign Mechanics 是 SRD 2.0 的可选规则章节，单独隔离，不等同于完整 Campaign Frame。
