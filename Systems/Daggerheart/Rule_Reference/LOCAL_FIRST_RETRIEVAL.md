# Daggerheart｜本地优先检索协议

## 权威顺序
1. 当前 Campaign 的 SYSTEM_BINDING 与明确桌规；
2. 本地 Core Set 运行手册、Rule ID 与检索表；
3. 本地 `Reference_Data/Core_Set/` 完整结构化条目；
4. 官方 SRD 2.0 与官方勘误；
5. 用户合法提供的 Core Rulebook 原文（如有）。

## 日常检索
- 行动掷骰、Hope/Fear、伤害、休整、死亡、倒计时：查 CORE_RULES_RUNTIME.md 与 LOOKUP_TABLES.md。
- 创建角色：查 CHARACTER_OPTIONS_INDEX.md 与 Core Set classes/subclasses/domains/ancestries/communities。
- 武器、护甲、物品：查 GEAR_INDEX.md 与 Core Set 对应 JSON。
- 敌人、环境：查对应索引后读取完整 Stat Block。
- Hope & Fear 默认不加载。只有 Campaign 明确启用时才读取扩展目录。
- Mixed_Version 与 Optional_Procedures 不得自动载入。

## 联网条件
仅在本地缺项、官方勘误/版本变化、数据疑似错误、SRD 未覆盖或用户要求新资料时回查。回查后记录来源、版本、许可和影响，再更新本地索引。

## 版权边界
SRD 2.0 Public Game Content 可在 DPCGL 条件下本地整理；商业规则书非 SRD 正文、Campaign Frame 全文、地图、艺术与付费工具不得因放入私人仓库就视为可自由复制。用户提供合法材料时，可按其授权范围建立私人检索摘要或索引。
