## 1. Trait Difficulty Benchmarks

GM 为未指定 Difficulty 的行动设定难度时，综合虚构情境、压力、时间、阻碍与失败后果。不要把每个行动都机械套进表格。

## 2. Difficulty 与敌人

- 对 Adversary 的 Attack Roll：Difficulty = 目标 Adversary 的 Difficulty。
- 对 Adversary 的其他 Action Roll：以目标 Difficulty 为基准，适用时加上其相关 Experience 修正。
- 敌人攻击 PC：比较 GM 的攻击总值与目标 Evasion。
- Difficulty 不是固定难度等级；它描述当前目标/情境的挑战。

## 4. Encounter Battle Points

初始预算：`3 × 参与战斗的 PC 数量 + 2`。

| 调整条件 | BP |
|---|---:|
| 战斗较轻或较短 | −1 |
| 使用 2 个或更多 Solo | −2 |
| 全部敌人伤害额外 +1d4 或固定 +2 | −2 |
| 选择低于队伍 Tier 的敌人 | +1 |
| 没有 Bruiser / Horde / Leader / Solo | +1 |
| 希望战斗更难或更长 | +2 |

| Adversary Type | BP Cost |
|---|---:|
| 一组 Minions（数量等于 PC 数） | 1 |
| Social / Support | 1 |
| Horde / Ranged / Skulk / Standard | 2 |
| Leader | 3 |
| Bruiser | 4 |
| Solo | 5 |

预算只是建遭遇的起点。还要考虑敌人动机、目标、空间、Fear、逃跑路线与战斗之外的利害。

## 6. Range 与移动

| Range | 约略距离 |

| Melee | 可触及，几英尺 |
| Very Close | 5–10 ft |
| Close | 10–30 ft |
| Far | 30–100 ft |

| Out of Range | 超过 Very Far |

可选格地图参考：Melee 1 格、Very Close 3 格、Close 6 格、Far 12 格、Very Far 13 格以上；不要与默认抽象距离混算。

## 7. Rest 速查

| 项目 | Short Rest | Long Rest |
|---|---|---|
| 时间 | 约 1 小时 | 数小时 |
| 每人 Downtime Moves | 2 | 2 |
| HP / Stress / Armor | 1d4 + Tier | 全量 |
| Prepare | 独自 +1 Hope；共同 +2 Hope | 独自 +1 Hope；共同 +2 Hope |
| Project | 不适用 | 可 Work on a Project |
| GM Fear | 1d4 | 1d4 + PC 数量 |
| 其他 | 免费调整 Loadout/Vault | 免费调整 Loadout/Vault；可推进长期 Countdown |

连续 3 次 Short Rest 后，下次必须 Long Rest。Long Rest 可被打断并降为 Short Rest 收益。

## 8. Fear 场景预算参考

| 场景强度 | 建议 Fear 消耗 |
|---|---:|
| Incidental（闲谈、搜集信息、补给、休息） | 0–1 |
| Minor（旅行、介绍新敌人的小冲突） | 1–3 |
| Standard（重要战斗、危险旅行、关键社交） | 2–4 |
| Major（Solo/Leader 大战、角色命运转折） | 4–8 |
| Climactic（篇章反派决战、史诗场面） | 6–12 |

该预算用于调节戏剧张力，不是 GM 必须花完的额度。

## 9. Gold 换算

- 10 Handfuls = 1 Bag。
- 10 Bags = 1 Chest。
- 最多持有 1 Chest。
- 某一档满格后继续获得同档财富，转换成上一级单位并清空低级单位。
