# External Blind GM Test 01 — Execution Protocol

## Purpose

Run a short, clean-session test of the Daggerheart GM runtime. This is an external validation step, not a campaign start and not a rules lookup exercise.

## Prepare a clean chat

Start a new conversation with no prior Daggerheart test transcript or GM feedback in context.

Load these files from the repository:

1. Systems/Daggerheart/GM_SKILL.md
2. Systems/Daggerheart/GM_RUNTIME_FIELD_GUIDE.md
3. Systems/Daggerheart/GM_DESIGN_FIELD_GUIDE.md
4. Systems/Daggerheart/Rule_Reference/CORE_RULES_RUNTIME.md
5. Systems/Daggerheart/Testing/EXTERNAL_BLIND_GM_TEST_01_PLAYER_BRIEF.md
6. Systems/Daggerheart/Testing/EXTERNAL_BLIND_GM_TEST_01_GM_ORACLE.md

The GM may read the GM Oracle. Do **not** provide the Evaluator Scorecard to the GM during play.

Use the Core Set records for Raging River, Glass Snake, and Jagged Knife Bandit from Reference_Data/Core_Set. Do not load Hope & Fear expansion content.

## Start instruction

Send the GM this instruction:

> Prepare External Blind GM Test 01 using the supplied player brief and GM Oracle. Follow the Daggerheart GM Skill and Core Set runtime rules. Ask only for missing character information needed to resolve actions. Do not start the scene until I explicitly say “开始”. Do not reveal GM-only information or discuss the evaluator criteria.

Then provide existing Tier 1 character sheet(s). Do not spend time on new character creation.

## During play

- Play naturally. Do not hint at hidden clues or remind the GM of specific mechanics.
- Ask questions and choose actions as a player would.
- Do not intentionally trigger every feature; the GM should decide when the fiction and rules warrant them.
- Do not grade the GM mid-session or coach it toward a desired outcome.
- End when the scene reaches a clear resolution or the party abandons the objective.
- This test evaluates GM execution and narrative quality, not solo encounter balance.

## Evaluate after play

1. Save or copy the complete transcript.
2. Open EXTERNAL_BLIND_GM_TEST_01_SCORECARD.md only after the scene ends.
3. Score each criterion 0–2 and record concrete transcript evidence.
4. Check critical failure conditions separately; a high total does not cancel a critical rules error.
5. Compare failures against Rule IDs and DH-I-020. Distinguish confirmed rule errors from unresolved interpretations.
6. Record whether the test was run with one PC or multiple PCs; do not use it as proof of solo encounter balance.

## Pass threshold

- No critical failure.
- At least 30/40 overall.
- At least 15/20 in Mechanics and 15/20 in GM Quality.
- Any score of 0 must have a concrete remediation note before a repeat test.

A pass is evidence for this scenario only. It does not by itself validate every Adversary, Environment, card feature, or production Runtime path.
