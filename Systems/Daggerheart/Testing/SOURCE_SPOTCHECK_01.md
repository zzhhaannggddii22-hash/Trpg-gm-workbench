# Daggerheart Source Spot-Check — High-risk timing boundaries

- Date: 2026-11-28
- Sources: Official Daggerheart SRD 2.0 as indexed by public rule reference, with official SRD rule sections surfaced during this review; source URLs below.
- This spot-check supplements desk tests; it does not replace full Core Rulebook review.

## DH-T45 — Hope Feature payment timing

**Result: Confirmed.** SRD text expressly states that Hope gained from rolling with Hope for that action can be spent on the Hope Feature, or toward it if the feature requires multiple Hope. This supports the assertion as narrowly written. It does not authorize retroactive payment for arbitrary earlier features or unrelated actions.

- Source: https://daggerheartsrd.com/rules/making-moves-and-taking-action/
- Source: https://www.daggerheart.com/wp-content/uploads/2025/09/Daggerheart-SRD-9-09-25.pdf

## DH-T08 / DH-T09 — Stress overflow versus paying Stress to activate a move

**Result: Confirmed with distinction.** If a consequence requires Stress marking but the character cannot mark, they mark 1 HP instead. However, a move requiring the character to mark Stress cannot be used if all Stress slots are already marked. Overflow does not replace a move's activation cost.

- Source: https://daggerheartsrd.com/rules/stress/

## DH-T10 — Last Stress and Vulnerable

**Result: Confirmed.** Marking the final Stress slot causes Vulnerable until at least one Stress is cleared.

- Source: https://daggerheartsrd.com/rules/stress/
