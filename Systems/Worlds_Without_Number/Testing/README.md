# WWN Testing｜测试入口

当前状态：研究资料已整理；规则行为测试尚未开始。文件存在不表示系统已通过测试或可以正式开团。

## 测试前置条件

- 规则来源、目标版本和覆盖边界明确。
- 核心规则、世界构建、Tags、冒险、Faction 与 Projects 已有可执行摘要。
- 官方规则与 House Rule / AI Runtime Adaptation 明确分开。
- 测试标记 TEST_ONLY_NON_CANON，不连接正式 Campaign。
- 核心机制以 SRD 1.0 为离线基线；GM 工具以 2021 Free Version 正文为研究基线。

## 建议测试序列

1. **核心规则**：技能检定、四类豁免、阵营先攻、攻击与 Shock、濒死/稳定/恢复。
2. **世界构建**：从一个玩家目标出发，按需展开 Region、Polity 和 Site；检查是否生成无关设定。
3. **Site Tags**：双 Tag 组合生成地点主题、NPC/组织、问题、资源和行动机会；检查素材是否被机械拼贴。
4. **冒险创建**：同一目标分别构建 Combat、Exploration、Investigation、Social 主挑战；检查多路径和后果。
5. **Investigation 专项**：至少三条线索路径；一次检定失败后仍有可行动线索，但失败代价真实存在。
6. **Faction Turn**：检查收入、维护、资产特殊能力、单个 Action、多资产参与、Goal 与资源账本。
7. **Major Project**：检查可行性、范围、最大反对力量、民众反感、Renown 和阵营协助。
8. **单人适配**：对照默认致命性，评估单 PC、雇员/随从、逃跑/谈判/绕行路径，不擅自削弱世界中的合理威胁。
9. **Runtime 负载**：确认只在触发时读取相关规则和状态，不进行无意义 NPC 日常模拟或完整世界经济模拟。

## 测试报告格式

每项报告记录：
- 规则版本与来源定位；
- 输入场景与 PC 状态；
- 预期规则过程和结果；
- 实际执行过程和结果；
- 发现的问题、严重度和修正；
- 是否需要 House Rule；
- 结论：通过 / 有条件通过 / 未通过。

规则摘要存在不代表行为测试通过。测试完成前 WWN 保持 Candidate。
