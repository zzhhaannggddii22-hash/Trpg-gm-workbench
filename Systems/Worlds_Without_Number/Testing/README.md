# WWN Testing｜测试入口

当前状态：未开始规则行为测试。目录先用于记录将来的验证范围，不表示系统已通过测试或已具备正式开团条件。

## 测试前置条件

- 核心规则来源与目标版本已核验。
- 关键判定、战斗、探索、阵营和项目机制已有可执行摘要。
- 官方规则与本项目 house rule / AI GM adaptation 已明确区分。
- 测试场景注明 TEST_ONLY_NON_CANON，不连接正式 Campaign 状态。

## 计划验证范围

1. 核心规则：检定、豁免、战斗、伤害与恢复。
2. 探索循环：旅行、野外远征、地点探索和资源消耗。
3. GM 工具：从标签/生成器产出有具体行动机会的地点或冒险。
4. 阵营：Faction Turn 的触发、合法行动、资源/资产变化与结算时序。
5. Major Projects：目标、规模、难度、进展、对抗和完成。
6. 单人适配：角色生存、随从/雇员、遭遇规模与行动自由。
7. AI GM 行为：只在触发时读取规则和更新状态，不将每个行动变成额外流程。

## 报告要求

测试报告须标明规则版本、测试输入、期望结果、实际结果、证据来源、缺陷和结论。文档存在或静态检查通过，不等于 AI GM 已能在实时跑团中正确执行。
