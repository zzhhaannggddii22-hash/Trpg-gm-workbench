## 系统定位

WWN 是一套奇幻角色扮演规则，同时提供世界构建、地点生成、冒险设计、阵营运行等沙盒主持工具。研究对象分为游戏规则与 GM 工具体系，两者必须分别核实。

## 权威与许可边界

作者 SRD 1.0 以 CC0 许可放弃其明确覆盖的规则机制；本仓库保存 SRD 全文、结构化记录与中文摘要。SRD 不包含完整 Free Edition / Deluxe 的大部分 GM 工具正文及 Latter Earth 设定。出版方商品说明称 Free Edition 包含主要世界构建、冒险创建和阵营工具，但仍需取得规则书逐章核验。CC0 不自动延伸到 SRD 外的出版内容、插画、世界设定、NPC、地点或创作性表格。

第三方结构化数据仅作检索层；争议裁定回到本地 SRD 原文和目标版本官方规则书。

本目录只维护 WWN 专属规则、术语、资料、研究与系统适配。跨系统 GM 能力属于 GM_Training；Campaign 人物、地点、阵营状态属于对应 Campaign。任何简化或 AI GM 操作约定都必须标记为 house rule / runtime adaptation。
