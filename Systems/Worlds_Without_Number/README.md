## 权威与许可边界

作者 SRD 1.0 以 CC0 许可放弃其明确覆盖的规则机制；本仓库保存 SRD 原文、结构化记录与中文摘要。SRD 不包含完整 Free Edition / Deluxe 的大部分 GM 工具创作性正文及 Latter Earth 设定。公开仓库不保存受保护的具体 Tag 正文、随机表全文、插画或世界设定；GM 工具仅以原创中文摘要、通用结构和来源定位保存。

第三方结构化数据仅作检索层；争议裁定回到本地 SRD 原文和目标版本规则书。

## 接入边界

本目录只维护 WWN 专属规则、术语、资料、研究与系统适配。跨系统 GM 能力属于 GM_Training；Campaign 人物、地点、阵营状态属于对应 Campaign。任何简化或 AI GM 操作约定都必须标记为 Runtime Adaptation / House Rule，不得冒充官方规则。
