## 系统定位

WWN 是一套奇幻角色扮演规则，同时提供大量面向 GM 的世界构建、区域与地点生成、冒险设计、阵营运行和其他沙盒主持工具。出版社明确将其描述为 OSR-compatible 规则，并强调其系统中立 GM 工具可供其他规则体系的主持人使用。

本系统研究有两个并行但必须区分的对象：

1. **游戏规则**：角色创建、技能与属性检定、战斗、伤害与恢复、旅行和探索、魔法、成长等实际游玩机制。
2. **GM 工具体系**：世界构建、标签与生成表、冒险构建、Faction Turn、Major Projects 等用于产生和维护沙盒内容的工具。

研究重点是判断这些机制与工具如何组成可持续运行的单人沙盒，以及哪些部分适合 AI GM 直接执行、哪些只适合作为主持参考。

## 接入边界

- 本目录只维护 WWN 专属规则、术语、资料、研究与系统适配。
- 不从 Triangle Agency、Cairn、Blades in the Dark 或 D&D 自动借用任何规则。
- 跨系统 GM 能力继续归属 GM_Training；Campaign 的人物、地点、阵营当前状态及事件记录归属具体 Campaign。
- 研究结论不自动成为正式规则；任何单人适配、简化或 AI GM 操作约定，都必须标记为 house rule / runtime adaptation，并与官方规则分开记录。
- 在完成核心规则核验、关键机制运行设计和必要测试之前，保持 candidate，不生成正式 Campaign 的系统绑定。
