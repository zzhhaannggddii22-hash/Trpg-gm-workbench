# Rule Reference｜规则索引

本目录用于建立可在跑团时直接检索的 WWN 规则参考资料。当前只有索引约定，尚未完成逐章规则提取。

## 资料优先级

1. 用户提供或可访问的目标版本官方规则书（Free Edition / Deluxe）；核对完整说明、示例、表格、例外与页码。
2. 作者发布的 Worlds Without Number SRD 1.0；用于核对其明确覆盖的规则机制。SRD 引言说明它是供设计者查阅机制的文件，不是完整玩家参考书，也不包含完整 GM 工具与世界设定。
3. 出版方勘误、补充说明与正式出版资料。
4. 第三方转录、整理或翻译仅作为检索入口；关键规则必须回到权威文本核实。

## 核对要求

- 规则摘要必须注明来源版本及章节/页码。
- 区分官方规则、官方示例、作者建议、第三方解释和本项目的 AI GM 适配。
- 对骰池、检定目标、时序、资源消耗、持续时间、范围、例外和失败后果，优先记录完整执行条件。
- 不确定内容登记为开放问题，不用常见 D&D 或其他 OSR 规则补齐。
- 若 SRD 与实际规则书文本、勘误或示例存在差异，记录差异并暂缓将冲突内容写成确定规则。
- 不在公开仓库复制非 CC0 的规则书段落；采用原创摘要、定位信息与必要的短语引用。
