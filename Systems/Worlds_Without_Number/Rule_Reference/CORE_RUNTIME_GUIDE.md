# WWN 核心规则运行手册（SRD 1.0）

- 规则基准：Kevin Crawford, *Worlds Without Number System Reference Document v1.0*（2024-03-13）。
- 范围：仅整理 SRD 明确覆盖的机制；不是完整 Free Edition / Deluxe 手册。
- 核验入口：同目录 `Data/SRD.md`；结构化条目见 `Data/wwn-srd-data.jsonld`，名称/章节目录见 `Data/catalog.json`。
- 下文章节号指 SRD 章节，不代表已核验 Free Edition 印刷页码。

## 1. 核心检定

### 属性

六项属性：Strength、Dexterity、Constitution、Intelligence、Wisdom、Charisma。属性通常为 3–18。

| 属性值 | 修正 |
|---:|---:|
| 3 | -2 |
| 4–7 | -1 |
| 8–13 | +0 |
| 14–17 | +1 |
| 18 | +2 |

### 技能检定（SRD 2.3）

**2d6 + 技能等级 + 属性修正，结果达到或超过难度即成功。**

| 难度 | 常见含义 |
|---:|---|
| 6 | 超出日常职责但相对简单；比这更简单的事通常不掷骰 |
| 8 | 对胜任的专业人士构成显著挑战 |
| 10 | 需要熟练专家，专家也可能失败 |
| 12 | 只有大师能较可靠地完成 |
| 14+ | 只有大师才有机会，且大概率失败 |

- 没有相关技能（低于 0）：检定 -1。特别专业或玄奥的行动，完全没有相关训练时可能无法尝试。
- 合理的环境修正通常在 -2 至 +2 之间。
- 多种技能/属性组合都合理时，玩家可选择其中较有利的一种；仅勉强相关的组合可受 -1 或 -2。
- 对抗检定：双方分别检定，比总值；平局由 PC 获胜。
- 协助检定成功后，受助者 +1；多人协助的总加值仍最多 +1。
- GM 决定是否需要检定；不是每个行动都自动掷骰。

### 豁免（SRD 2.2）

掷 1d20，结果大于或等于目标值成功。自然 1 必定失败，自然 20 必定成功。

| 类型 | 适用范围 | PC 目标值 |
|---|---|---|
| Physical | 疲劳、毒素、疾病等身体危险 | 16 − 等级 − max(力量修正, 体质修正) |
| Evasion | 爆炸、陷阱、突发危险 | 16 − 等级 − max(敏捷修正, 智力修正) |
| Mental | 精神攻击、心理创伤、部分魔法 | 16 − 等级 − max(感知修正, 魅力修正) |
| Luck | 纯粹运气 | 16 − 等级 |

NPC 通常共用一个豁免目标：15 − 向下取整(HD / 2)。

## 2. 时间单位（SRD 2.1）

- **Scene**：一场战斗、追逐、谈判或同一地点的持续活动，通常约 10–15 分钟。
- **Round**：战斗轮，约 6 秒。
- **Turn**：危险地点探索等复杂活动用的 10 分钟单位；需要时相当于一个 Scene。

不要把 Scene、Round、Turn 混成一个“回合”。

## 3. 战斗（SRD 2.4）

### 先攻与顺序

每个阵营掷 1d8 + 本阵营最高敏捷修正；高者先行动，平局 PC 方优先。每方成员在己方行动阶段内安排顺序；所有阵营行动完成后按原先顺序进入下一轮，不重新掷先攻。

个体先攻是可选规则：每名战斗者独立掷 1d8 + 敏捷修正。若一组完全未察觉战斗，可能遭受 Surprise，敌方先获得完整一轮行动；主动警戒战斗时通常不会被完全突袭。

### 行动类型

| 行动 | 规则 |
|---|---|
| Main | 每轮 1 次；攻击、施法、急救、主要技能行动 |
| Move | 每轮 1 次；普通移动（人类通常 30 英尺）、起身等；可放弃 Main 换第二次 Move |
| On Turn | 短暂动作；GM 认为合理时可多次 |
| Instant | 可在非自己回合、甚至掷骰后发生；数量由 GM 按合理性判断 |

### 攻击与伤害

攻击 = 1d20 + 基础攻击加值 + 武器对应属性修正 + 战斗技能等级。达到对应 Melee AC / Ranged AC 即命中。没有至少 0 级对应战斗技能时，攻击 -2。普通 NPC 攻击加值通常等于 HD，训练或特殊能力可提高。

命中伤害 = 武器伤害骰 + 武器对应属性修正。武器的 Shock 可能在未命中时仍造成伤害：若目标 Melee AC 不高于 Shock 所标阈值，即承受相应 Shock。盾牌持有者每轮忽略第一个 Shock 来源；某些能力也能免疫 Shock。命中伤害不能低于该攻击原本会造成的 Shock。

**Trauma Dice 是可选规则。** SRD 指向 *Cities Without Number* SRD 获取完整武器 Trauma 数据；没有该来源时不要自行补齐。

### 常见战斗动作

- Snap Attack：Instant；放弃本轮 Main，在规则允许时进行一次 -4 攻击。
- Charge：消耗 Main + Move，直线移动至多两倍速度，末尾攻击 +2；本轮 AC -2。
- Screen an Ally：Move；保护邻近盟友，通过对抗检定决定攻击落点。
- Total Defense：Instant；放弃 Main，AC +2，并免疫 Shock 直到下回合开始。
- Fighting Withdrawal：Main；避免离开邻接近战敌人时遭免费攻击；动作本身不提供额外移动。
- 从 Stowed 背包取出物品需要 Main；拾取地面物品通常为 Move。

### 0 HP、濒死和急救（SRD 2.5.1）

PC 被致命攻击降至 0 HP 时进入 Mortally Injured。若未稳定伤势，会在失去行动能力后的第六轮结束时死亡。

稳定伤势通常消耗 Main，使用 Dex/Heal 或 Int/Heal：
- 难度 = 8 + 目标倒下后已经过去的完整轮数。
- 没有治疗工具时难度 +2。
- 每轮只允许一名盟友尝试，但可在后续轮次重试。
- 稳定后目标无行动能力 10 分钟，随后恢复 1 HP 并获得 Frail；Frail 状态再降到 0 HP 会立即死亡。
- 普通且不重要的 NPC 通常在 0 HP 时直接死亡；明显不可生还的灾难性伤害可直接致死。

## 4. 恢复与 System Strain（SRD 2.5）

- 最大 System Strain = Constitution 属性值；正常角色从 0 开始。
- 魔法治疗和部分强化能力增加 Strain。若会超过上限，角色不能从效果中获益；被不可避免的效果强制超过上限则昏迷至少一小时。
- 温暖、吃饱、舒适且连续睡眠至少 8 小时后，每晚恢复 1 Strain。
- 良好休息、食物和舒适条件下，PC 每天早晨恢复等于等级的 HP；NPC 恢复等于 HD 的 HP。
- 使用治疗工具花 1 分钟急救，恢复 1d6 + Heal 技能等级 HP；没有 Heal 技能时为 1d6−1；每次急救增加目标 1 点 Strain。
- Frail 不能靠自然 HP 恢复解除，须依照医疗/休养规则处理。

## 5. 追逐（SRD 2.6）

步行追逐由双方各进行一次团队技能检定：

1. 逃跑方由最佳 Dex/Exert 或 Con/Exert 角色掷骰，作为团队 Pace。
2. 同伴可通过合理行动拖慢追兵；每次成功 +1，最多 +3；有害失败可 -1。
3. 追逐方做一次 Dex/Exert 或 Con/Exert 检定，按人数、先机、地形熟悉度和追逐动机修正。
4. 追逐方超过逃跑方 Pace 才追上；平局或较低则逃跑方脱离即时追击。

骑乘追逐另用 Ride，不要套用步行追逐流程。

## 6. 负重（SRD 2.9）

- 装备分 Stowed（收纳）与 Readied（随手可用）；从 Stowed 取出需要 Main。
- Stowed 上限 = 力量；Readied 上限 = 向下取整(力量 / 2)。
- 口袋小件 0；单手物品 1；需双手 2；全身发力搬运 5+；拖动昏迷队友 12。
- 短期超负荷可增加 2 Readied 与 4 Stowed；第一次移动速度降至 20 英尺，第二次降至 10 英尺。更重的东西不能实用地长距离搬运。
- 3 件形状规整的小件可捆成 1 点负重；拆包需要额外 Main。

## 7. 旅行与探索（SRD 2.11–2.13）

### 大地图旅行

一般季节可每日旅行约 10 小时。基础速度（英里/小时）：

| 地形 | 速度 |
|---|---:|
| 平原/稀树草原 | 3 |
| 疏林/沙漠 | 2 |
| 密林/崎岖丘陵 | 1.5 |
| 沼泽 | 1 |
| 山地/险恶荒地 | 0.5 |

道路速度 ×2，但不能超过 3 英里/小时；坏天气/泥泞/大雨 ×0.5；深雪 ×0.1。每个旅行日和每个户外露营夜各做一次漫游遭遇检查，具体骰型依地区安全程度确定，掷出 1 触发。

### 六英里 Hex 探索

轻度搜索一个标准 6 英里 Hex 以找出主要兴趣点，需要一整天侦察；极崎岖或遮蔽地形可能耗时 2–3 倍。此程序不保证发现很小、很隐蔽的特征。

### 远征补给

食物、水、住所、火源是远征基础保障。食物/水按每人每天 1 点负重；压紧的一周口粮 4 点；一晚燃料 4 点。缺粮、缺水、缺住所会增加 Strain 或阻断恢复。Foraging、驮兽和雇员的完整表格见 Data/SRD.md 第 2.12 章及 Data/wwn-srd-data.jsonld。

### 地下城 / 危险地点

每个 Turn 为 10 分钟：

1. 如有必要，秘密进行漫游遭遇检查。
2. 玩家决定本 Turn 的主要行动。
3. GM 告知行动结果。
4. 推进时间并开始下一 Turn。

遭遇检查频率依防御组织程度：
- 已警戒组织化地点：每 Turn。
- 未警戒组织化地点：每 2 Turn。
- 无组织化主动防御：每 3 Turn。
- 移动居民很少：每 4 Turn。
- 废弃角落：每 6 Turn。
- 原住民未知的隐藏区域：不检查。

普通街道、草地和轻松地点探索不必强制启用地下城 Turn。

## 8. NPC、怪物与遭遇（SRD 5）

**Reaction Roll**：通常 PC 遇到生物或群体时掷 2d6；若 PC 有机会主动问候，加入魅力修正。2− 极端敌对；3–5 比预期更不友善；6–8 符合情境常态；9–11 比预期友善；12+ 在其本性及处境允许范围内友善且愿意帮助。除非冲突明显不可避免，不要把遭遇自动变成战斗。

**Morale**：NPC 掷 2d6，结果高于自身 Morale 才会动摇并尝试逃跑/停止战斗。PC 不掷。常见触发：平民首次面临严重危险；群体首名成员死亡/失能；明显败势；遭遇可怕魔法或压倒性敌人。

**Instinct**：触发时掷 1d10；结果 ≤ 生物 Instinct 值，它做出冲动、短视或战术不佳的行为。PC 不掷。失败不是“失控”通行证，应按生物本能和处境处理。

## 9. 成长（SRD 2.7）

- 普通成功任务默认通常奖励 3 XP；默认最高 10 级。
- 区分 Fast / Slow 成长表。
- 升级获得 3 Skill Points；Expert 和 Partial Expert 的 Quick Learner 可额外获得 1 点。
- 技能逐级购买，成本 1/2/3/4/5 点对应技能 0–4；技能 2/3/4 分别要求角色至少 3/6/9 级。
- 属性成长逐次变贵，最多 5 次；第 3/4/5 次分别要求 3/6/9 级。
- 新 Focus 可在 2、5、7、10 级获得。
- Spell、Art 与职业成长按各职业进度，不要套用统一模板。

## 10. 数据定位与边界

完整职业、能力、Foci、法术、装备、怪物与阵营资产数据均保存在 Data/wwn-srd-data.jsonld。SRD 不等于完整 Free Edition：示例、解释、正式 GM 工具正文、页码和勘误尚待完整规则书核验。已知截断：Accursed Arts 的 Night-Black Eyes 仅保留开头，不得猜测续文。
