# WWN 世界构建运行手册（Free Edition）

状态：已按 2021 Free Version 目录与正文研究；这是原创中文摘要与 AI Runtime 适配，不复制原书表格或设定文本。

## 1. 核心原则：从战役范围反推准备量

先确定战役的实际活动范围，再自上而下建立背景。越远离当前活动范围的层级，准备越少。不要先写百科全书，再寻找它能支持的冒险。

官方准备原则可转成两个检查：
1. 正在构建的内容是否让 GM 觉得有趣？
2. 如果不有趣，下一场游戏是否确实需要？
两项都是否定，就暂停。只需领先玩家约一个 Session。

## 2. 背景层级

### World
记录玩家会自然知道、且会影响战役范围的全球事实：
- 世界称呼与明显不同于现实的物理/日常规律；
- 已知的异界、宇宙结构或世界级力量；
- 只需给远离战役范围的国家、帝国和历史一两句定位。
不要提前绘制与战役无关的完整世界地图或宇宙史。

### Region
约两百英里尺度的连贯区域，也可以是一座半岛、一片岛屿或相连地理单元。
- 确定主要地形、交通障碍、资源和气候；
- 列出多个国家、群体和权力中心；
- 记录它们的历史关系、竞争与依赖；
- 不必把每个国家都发展成完整设定。

### Kingdom / Polity
选择首场冒险所在的王国、政体、部族领地或省份，作为首批深入构建对象。
按实际需求补足：
- Society：生活方式、阶层、习俗、社会价值和矛盾；
- Government：谁拥有权力、权力如何运作、权力的限制与争夺；
- Religion：信仰结构、教团、仪式、社会作用及内部张力；
- History：形成、兴盛、衰退、转折事件，以及这些事件留下的现实后果。
这些不是纯背景栏目；每个重要事实都应能成为关系、资源、障碍或冒险钩子。

### Sites
将背景落到 PC 能实际接触的地点：
- Community：城市、村庄、部族、流亡群体等社会聚落；
- Court：围绕统治者、权力人物或组织核心形成的利益场；
- Ruin：废墟、地下城、古代设施等探索场所；
- Wilderness：荒野、边境、自然区域及其中的兴趣点。
一个地点的准备应服务于当前冒险，不要求整张地图全部填满。

## 3. 从冒险反向补充背景

先明确玩家要做什么，再补齐完成该行动所需的地方、人物、制度和历史。
例如：若冒险围绕一处古代遗迹，就先定义遗迹和它所在的局部区域；只有当玩家需要与附近村庄、领主或教团互动时，再扩展相应资料。
这比先完整生成国家、宗教、历史，再等待玩家碰巧用到它们更节省准备成本。

## 4. 世界事实的运行记录

每条重要事实建议记录：
- 事实：可验证的简短陈述；
- 作用范围：World / Region / Polity / Site；
- 关联对象：人物、组织、资源、地点；
- 当前状态：稳定、紧张、变化中；
- 玩家可感知方式：传闻、目击、记录、后果；
- 可触发的行动或冲突。
不要把推测写成既定事实；未知内容保留为空缺。

## 5. AI Runtime 适配（非官方）

- 只构建玩家可能触及的区域，允许世界边缘保持模糊。
- 使用“向下按需展开”：只有玩家行动需要时，才从 Region 展开到 Polity，再到 Site。
- 让历史和制度解释当前行为，而不是单独堆砌背景段落。
- 每次准备结束时保留 1–3 个可行动入口，而不是预设剧情路线。
- 发生重大行动后更新受影响的事实；无影响的远端背景不做模拟。
