# Cairn 规则检阅与裁定协议

## 适用范围

本协议仅适用于 `system_id: cairn`、Cairn Second Edition。不得用于 Cairn 1e、其他 Into the Odd 衍生系统或其他 TRPG，除非单独核对兼容性。

## 来源优先级

1. 本桌绑定的 Cairn 2e 官方英文规则原文及官方勘误/补充。
2. 本桌明确指定的合法桌规或经用户批准的适配记录。
3. 本目录的规则索引、速查和已核对裁定。
4. GM 对未明确条文的解释；必须标记为推论，不得伪装成官方规则。

中文 SRD 用于提高阅读效率和术语一致性。中文翻译与英文原文出现冲突、遗漏或版本差异时，回到英文官方原文核验并记录差异。

## 裁定分类

所有有规则影响的结论应区分：
- `SOURCE`：官方规则原文。
- `TABLE_ADAPTATION`：经用户明确批准的本桌适配。
- `GM_INFERENCE`：官方规则未明确覆盖时的主持推论。
- `UNKNOWN`：来源、版本或适用条件未核实。
- `DISPUTED`：来源之间存在未解决冲突。

不得使用其他系统的相似机制填补 Cairn 规则缺口。

## 规则检索

- 先按本 Campaign 的 `system_id` 和精确版本筛选。
- 规则索引只用于定位，不替代完整条文。
- 关键裁定必须检查触发条件、行动主体、目标、成本、持续时间、例外、结算顺序及角色当前状态。
- 如果官方规则未定义某个结果，记录已检查来源和具体缺口；只暂停依赖该规则的行动，不冻结无关互动。

## 版权与仓库边界

只保存自写摘要、条文定位、术语表、勘误索引和合法来源链接。不得将第三方规则书、付费模组或完整翻译文本复制进公开仓库。引用与改编必须遵守原作品许可。
