# Cairn 2e Warden's Guide 导航与主持要点

> 核验日期：2026-11-27
> 来源基准：官方 Cairn 2e 英文 SRD（yochaigal/cairn 仓库 main，对应 cairnrpg.com/second-edition/）。
> 状态：官方 Warden's Guide 23 个章节已完成来源核验与用途分类。此处的“已核验”表示章节来源、内容范围与运行适用性已审阅；不表示 Bestiary、Spellbooks、Reliquary、全部背景或模组数据已逐项复制进本地运行手册。

## 1. 核验结论与使用边界

Warden's Guide 不是一整本都属于可直接调用的规则流程。其章节可分为：
- **运行规则/主持原则**：直接影响 Save、战斗、知识、探索、成长、Detachments、NPC 反应与信息呈现。
- **生成工具**：用于创建设定、地城、森林、怪物、NPC、名称和地图结构；不应在每次游戏行动中机械触发。
- **数据目录**：Bestiary、Spellbooks、Reliquary 等提供具体生物/物品条目；遇到具体条目时按原文逐项查证，不用概括性摘要替代。
- **示例/设定/参考资料**：帮助理解运行方式与默认世界，但不是所有战役必须采用的规则。

Player's Guide 的基础流程仍然优先：Core Rules 与 Procedures 决定核心机制；Warden's Guide 提供扩展解释、生成程序、主持建议与具体条目。发生冲突时以官方 Cairn 2e 对应规则原文为准。

## 2. Warden's Guide 章节核验表（23/23）

| 官方章节 | 核验分类 | 本地运行方式与边界 |
|---|---|---|
| About the Example Party | 示例 | 示例队伍由背景、装备、关系和人物设定组成；只作理解规则组合的案例，不作为默认玩家队伍或强制角色模板。 |
| Bestiary | 数据目录 | 收录怪物分类与完整生物条目。HP、属性、Armor、攻击、能力及特殊 Critical Damage 效果均按具体条目调用；不得只凭怪物名称推断数据。 |
| Bibliography | 参考资料 | 设计与规则参考书目，不产生桌面机制。 |
| Bonds and Omens | 角色钩子/成长原则 | Bonds 可关联 PC、设定与 NPC，提供物品/能力/任务/行动方向；可通过揭示谜底或解决根因来解决，角色不被强制要求解决。解决后应带来某种 Growth，Warden 可选择生成新 Bond。Omens 是冒险种子，具体解释结合战役。 |
| Combat | 战斗原则与示例 | 确认首轮 PC 以 DEX Save 争取行动、双方按 Side Initiative 行动、同侧行动结果同时发生、攻击自动命中、多名攻击者对同一目标取最高伤害骰，以及 HP/Scars 的特殊性；具体步骤仍调用 CORE_RULES_RUNTIME。 |
| Creating Backgrounds | 生成设计指南 | 背景连接人物历史、知识、专长、设定与起始装备；背景可以成为不掷骰的理由。此章指导自制背景，不替代官方 20 个背景的逐项条目。 |
| Creating Monsters | 怪物生成程序 | 通过外观、特征、攻击、能力表和 stat block 原则创建独特怪物；生成后必须明确 HP、Armor、属性、攻击、能力及其触发。转换其他系统怪物时按本章转换原则，不直接照搬外系统数值。 |
| Detachments | 战斗规则 | 大群敌人作为单一实体；更难命中、可同时伤害多个目标；受到 Critical Damage 后被拆散或被击败。个别大型生物也可按其条目作为 Detachment。常规调用 CR-DETACH。 |
| Dungeon Exploration | 主持原则/示例 | 明确即将发生的危险；反复交代空间位置和感官信息；先呈现明显威胁与 NPC，再呈现显著物件；只描述角色眼前发生的事；给出下一区域的声音/气味/高低差线索；提醒玩家 Cycle 与时间成本。机械流程以 Player's Guide / Procedures 为准。 |
| Dungeon Seeds | 地城生成工具 | 生成地城历史、居民、派系、目标、地图路径与房间内容；是备团工具，不是每个地城必须使用的随机程序。 |
| Forest Seeds | 森林/Forestcrawl 生成工具 | 以路径连接 POI，生成森林特征、居民、危险与地点；探索沿用 Player's Guide 的地城/荒野程序，并根据场景使用相应事件表。 |
| Growth | 成长原则与触发框架 | 成长不按击杀、掠夺或探索数量发奖；须来自对角色产生显著影响的经历。有效 Trigger 通常至少涉及以下三项中的两项：围绕目标持续行动、承担可能产生严重后果的明显风险、与独特物品/生物/实体互动。改变应永久且与经历相关；可能是负面变化或有代价的新能力。Downtime 研究、训练和派系关系也可推动成长。 |
| Knowledge And Perception | 信息/知识规则原则 | 不存在通用知识/专长检定或感知检定。知识由虚构经历支撑；无依据则不知道，必要时可用 Die of Fate 判断机会。Warden 应提供基本感官可感知的最大相关信息。初次获得陌生 Relic 时可用 Downtime 学习或冒险实验；允许玩家提问并逐步解释其功能。 |
| Naming Procedures | 生成工具 | 通过地形、地方特征、历史人物、危险与故事生成聚落、派系、领域和森林名称；不构成强制随机步骤。 |
| NPC Tables | NPC 生成表 | 提供姓名、Quirks、Background、Goals、Virtues、Vices。随机结果只提供素材，不等于完整人物模型；NPC 的知识、资源、动机与行动仍须与世界事实一致。 |
| Pointcrawls | 地图抽象程序 | 在地图上标记 POI、入口/出口、连接路线及缺少连接的地点；估算两点间旅行 Watches/天数，综合路径、距离、地形、天气、队伍速度等。路线 Watch 成本使用 Player's Guide / Procedures 的规则，不另造一套移动机制。 |
| Reliquary | 遗物数据目录 | 每件 Relic 有独立能力、使用次数、充能条件、库存属性与限制。调用 CR-RELIC 后仍须查对应 Relic 原文；不能将“通常有限次数/有 Recharge”当成所有遗物统一模板。 |
| Saves | 豁免主持原则 | Save 常用于规避风险后果、对抗、协助他人。先判断时间/资源/技能/优势；无真实风险则不掷。致命风险须预先让玩家理解，并提供可行替代选择。机制本身调用 CR-SAVE。 |
| Setting Seeds | 世界生成工具 | 从地域、居民、派系、资源、目标、地形、POI 和路径生成设定种子；是备团生成程序，不是桌面每轮机制。 |
| Spellbooks | 法术数据目录 | 提供具体法术书与效果。施法基本程序调用 CR-MAGIC；具体法术范围、限制、异常效果必须查该 Spellbook 条目。 |
| Vald | 默认世界设定 | 提供 Cairn 默认世界、Wood、Roots、信仰、派系、日历和天气背景。属于默认设定参考；除非 Campaign Binding 采用 Vald，不得把其设定事实强加到其他战役。 |
| Variable Difficulty | 主持裁定原则 | 奖励创造性思考，按投入调整虚构结果，优先呈现虚构后果而非机械 Buff；时间、努力与技能可能消除风险，无真实风险时跳过 Save。不是给每次检定套用难度修正的数值系统。 |
| Wilderness Exploration | 旅行示例 | 示例展示 Watch、天气、Travel、迷路和 Wilderness Event 的串联。权威流程与表格在 Player's Guide / Procedures；本章不另设一套规则。 |

## 3. 当前战役相关的规则资料

### 3.1 NPC 与信息边界

- NPC Tables 是生成素材，不是完整人物状态机。
- NPC 的知识必须来自背景、亲历、关系或可靠来源；不得因 GM 掌握秘密而自动让 NPC 知晓。
- NPC 的资源、行动能力与计划受时间、资源、技能、机会和现实处境限制。
- Workbench 的 L3 NPC 资源账本、独立目标/计划与跨 Session 连续性属于 Workbench 要求，不是 Cairn 官方新增的 NPC 等级或规则。

### 3.2 单人/小队旅行

- Watches、每名角色每 Watch 一项 Wilderness Action、旅行成本、天气、迷路、Wilderness Events 和 Make Camp 的规则均来自 Player's Guide / Procedures。
- Make Camp 需要安排守夜轮值；官方明确指出小队人数少时可能需要冒无人守夜风险，或跨多日轮换睡眠。
- 不得默认单人 PC 能同时守夜和获得完整睡眠收益；必须把风险与选择呈现给玩家。

### 3.3 Growth 与 Downtime

- 成长必须与角色的显著经历相关，不是自动经验值或战斗奖励。
- Downtime 由一次一项的行动构成，可围绕 Research、Training、Strengthening Ties 等展开。
- 多步骤目标使用 1–5 Milestones 和具体 Costs；完成条件与成本在行动前明确。
- 详细执行见 RUNTIME_PROTOCOL.md §4.6。

## 4. 本地化与按需回查

以下项目不需要重复复制到本地手册；遇到实际对象时应查官方 2e 对应条目：
- Bestiary 中具体怪物 stat block、特殊攻击、能力与 Critical Damage 效果；
- Spellbooks 中具体法术效果；
- Reliquary 中具体 Relic 的能力、uses/charges 与 Recharge 条件；
- 未被当前 Campaign 角色卡完整记录的背景专属表格与物品；
- 模组自定义遭遇、地图、NPC、派系、随机表和地点数据。

稳定通用规则已归入 CORE_RULES_RUNTIME.md 或 RUNTIME_PROTOCOL.md；具体条目仍遵循官方原文。未收录不等于规则不存在。不得用 Cairn 1e、Barebones、Into the Odd 或其他系统补缺。
