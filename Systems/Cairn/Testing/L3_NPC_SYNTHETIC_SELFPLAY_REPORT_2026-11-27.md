# Cairn 2e L3 NPC 合成自运行报告

- 日期：2026-11-27
- 类型：`TEST_ONLY_NON_CANON` / synthetic self-play
- 系统：`system_id: cairn` / Cairn Second Edition
- 依据：[L3 NPC PC 级资源与主动性验证计划](./L3_NPC_PC_RESOURCE_AND_AUTONOMY_TEST_PLAN.md)
- 目的：在真实短团前检查 L3 NPC 是否能在 Cairn 的资源、时间与信息边界下维持 PC 级资源账本和独立行动。
- 限制：同一模型分别扮演测试玩家与 Warden/NPC；不是独立玩家盲测，不证明真实桌面迁移，也不属于任何 Campaign CANON。

## 1. 测试方法

- 采用 8 个行动回合，分成 A/B/C 三条隔离分支。
- 每条分支均从同一不可变初始状态复位；不把上一分支的资源、知识或计划变化带入下一分支。
- 顺序为 `PLAYER ACTION → NPC/WARDEN RESPONSE → STATE DELTA`。
- 在执行前建立角色初始状态与可见信息边界；完成全部回合后才按验收维度复核。
- 只在真实风险存在时调用 Cairn Save；没有风险或装备足以消除风险时不强行掷骰。
- 所有 NPC 私有信息仅用于测试审计，不属于测试 PC 自动获知的内容。

## 2. 不可变初始状态

### 场景

虚构边境聚落 **Alder Ford**，一条秋季水位偏高的河流从聚落旁经过。测试开始时间为 08:00，Morning Watch。天黑前仍有足够时间，但傍晚水位将继续上涨。

PC 是临时测试角色 `PC-A`，不是用户的正式 Cairn 角色，也不预设凯瑟琳的任何履历。

### L3 NPC：Mara Bell

| 字段 | 初始状态 |
|---|---|
| 身份 | 渡船经营者；Workbench L3 NPC |
| 属性 | STR 10 / DEX 13 / WIL 12 |
| HP / Armor | 4/4 / 0 |
| Fatigue / Deprived | 0 / false |
| 库存 | 6/10 格；背包容量 6 格 |
| 物品 | 30ft rope ×1、boat hook ×1、lantern ×1、oil flask ×1、belt knife ×1、Rations ×1（3 uses） |
| 金钱 | 12sp；小额钱袋 Petty，不占格 |
| 交通/资产 | 一艘 skiff；当前不在码头，最后一次被看见在下游 landing |
| 人手 | 无可立即调用的雇工或帮手 |
| 社会义务 | 欠本地木匠 4sp；受药剂师委托找回一只封好的货箱 |
| 长期目标 | 维持渡船生意，并逐步还清木匠欠款 |

## 3. 八回合自运行记录

### Branch A｜搭话与谈判（从初始状态复位）

**A-1｜PC Action**

> 我问她能不能现在就送我过河。

**Warden / Mara Response**

码头木桩上缠着几圈湿绳。Mara 没有立刻抬头，她把绳结拉紧，拇指沿着磨毛的纤维摸了一遍，才看向你。

“现在不行。我的船不在这儿。”

她朝下游抬了抬下巴。

“昨晚水涨得太快，skiff 被冲到下面去了。我得先把它拖回来。你要是只想过河，等我把船弄回来；你要是愿意搭把手，我可以把这趟渡船算进去。”

**State Delta**

- 无资源变化。
- 无金钱支付。
- 无时间推进。
- Mara 继续检查绳结，未停止自己的准备工作。

**A-2｜PC Action**

> 我说我可以付 2sp，让她先送我过去。

**Warden / Mara Response**

Mara 看了一眼你手里的钱袋，又看了看河面。

“2sp 买不到第二艘船。”

她把绳圈挂回肩上。

“我能拿出 3sp，给愿意帮我把货箱拖上岸的人。船回来以后，我送你过河，不再收钱。你现在付钱，我也没法让河水倒着流。”

她没有接受 2sp，也没有承诺先放弃自己的工作。3sp 是她目前能提出的报酬上限；尚未形成支付。

**State Delta**

- 无金钱变化：Mara 仍有 12sp。
- 新增一项条件性承诺：若 PC 协助找回货箱，Mara 支付 3sp，并提供一次免费渡船。
- 承诺未被接受，尚未成为双方已成立的交易。
- 无时间推进。

**Branch A 结果**：NPC 有自己的事务与价格边界；能谈判但不自动服从 PC。没有凭空支付或扣款。

### Branch B｜PC 离场与游戏内时间推进（从初始状态复位）

**B-1｜PC Action**

> 我决定花一个 Watch 去查看旧磨坊附近有没有别的过河路线，之后再回来。

**Warden / World Response**

PC 离开码头，花费一个 Morning Watch（8 小时）查看旧磨坊附近的河道与道路。时间推进至 16:00。

Mara 不会因为 PC 不在场就被逐分钟模拟。根据初始日程锚点，她在 10:00 离开码头，带着 rope 与 boat hook 前往下游 landing。到 16:00，她已抵达并确认 skiff 卡在泥滩边缘；船还没有被拖回，货箱也没有取出。

**State Delta**

- 游戏内时间：08:00 → 16:00。
- Mara 位置：Dock → Lower Landing。
- 当前事务进度：0/3 → 1/3（已定位并确认 skiff 被泥滩卡住；尚未固定/拖船，尚未取箱）。
- Mara 资源：无消耗；HP 4/4、属性、Armor、Fatigue、Deprived、库存、12sp 均不变。
- PC 不自动知道 Mara 已发现什么。

**B-2｜PC Action**

> 我回到码头，问其他人 Mara 去哪里了。

**Warden / World Response**

码头边一个正在修网的老人朝下游指了指。

“她吃过早饭就走了，带着那根长钩和一卷绳子。说天黑前回来。”

老人继续补网，没有更多消息。

**State Delta**

- PC 只获得老人亲眼观察到的信息：Mara 离开时间大致在早餐后、携带 rope 与 boat hook、方向是下游。
- PC 不知道她已找到 skiff、skiff 卡在泥滩，也不知道封箱货物的情况。
- Mara 的私有状态不自动写入 PC 知识。

**Branch B 结果**：离场模拟按游戏内时间锚点触发；没有逐分钟后台演算、无依据资源消耗或重逢时全知泄露。PC 获得的信息受消息来源限制。

### Branch C｜资源约束、拒绝与计划受扰（从初始状态复位）

**C-1｜PC Action**

> 我问她能不能把 rope 和 lantern 借给我。

**Warden / Mara Response**

Mara 把肩上的绳圈往后挪了挪。

“绳子不行。没有它，我连船都固定不了。”

她看了眼你的 torch。

“灯可以换。你把那支 torch 留给我，我把 lantern 给你。下游天黑前还能看清路，但我不打算摸黑找船。”

她没有把所有物资都交给 PC，也没有因为请求而改变自己最关键的资源配置。

**State Delta**

- 无物品交接。
- Mara 保留 rope、boat hook、lantern。
- PC 仍持有 torch。
- 无时间推进。

**C-2｜PC Action**

> 我同意，用 torch 换她的 lantern。

**Warden / Mara Response**

Mara 接过 torch，先试着按了一下燃烧端，又用手掌挡了挡风。

“行。这个够用。”

她把 lantern 递给你，随后把 torch 固定在腰侧。动作很快，像是已经在脑子里重新排过一次装备。

**State Delta**

- PC：Torch ×1 → Lantern ×1。
- Mara：Lantern ×1 → Torch ×1。
- 双方库存格数不变：Mara 仍为 6/10，PC 仍为 4/10。
- Mara 的 oil flask 仍在她的库存中；没有凭空消失。
- 金钱、HP、属性、Fatigue、Deprived 均不变。
- 交易双方各自持有的物品只有一份，没有复制。

**C-3｜PC Action**

> 我说她应该先把我送过河，skiff 和货箱可以之后再找。

**Warden / Mara Response**

Mara 抬起头，脸上第一次露出一点不耐烦。

“那艘 skiff 就是我的渡船。它不在，我拿什么送你？”

她用靴尖拨开脚边一段湿草。

“货箱是药剂师托我的。船和箱子都得找回来。你可以不帮我，但我不会把它们丢在河里，专门替你赶时间。”

她没有争吵，也没有接受这个要求；她仍然准备按自己的优先事项行动。

**State Delta**

- 无资源变化。
- Mara 不接受放弃 skiff/货箱的建议。
- 关系没有自动恶化到敌对；她仍愿意按先前条件交易。
- 当前计划不变。

**C-4｜PC Action**

> 我检查码头上游的泥地和芦苇，看看有没有船被拖走的痕迹，然后把发现告诉她。

**Warden / World Response**

靠近旧磨坊的那段泥岸上，有一条新鲜的拖痕从水边斜着穿过芦苇，延伸到上游的小路。几根芦苇被压断，泥面上还留着半个船底的弧形印子。痕迹很新，边缘没有被雨水冲平。

这不是“可能有船经过”的模糊印象：它足以让人判断，有人或某种力量把 skiff 从水边拖向上游。

Mara 蹲下来，用指节刮了一点泥。

“这就不是下游了。”

她站起来，把 rope 重新盘好，boat hook 从肩上换到右手。

“我差点白跑一趟。先去旧磨坊那边。你要是想过河，等我把船找回来再说。”

她没有要求 PC 必须跟上，也没有把计划变更解释成 PC 的命令；她根据新证据主动调整自己的路线。

**State Delta**

- PC 观察到的可见线索直接提供，不调用感知检定。
- Mara 的知识更新：从“最后目击在下游，预计下游 landing”更新为“有可靠新证据显示 skiff 被拖往上游旧磨坊小路”。
- 计划：Lower Landing → Old Mill Upper Bank。
- 事务进度仍为 0/3（重新定位尚未完成）；不虚报已经找到船。
- Mara 准备在 10:00 出发，携带 rope、boat hook、torch；lantern 已交给 PC。
- 资源账本无额外消耗；HP/属性/Armor/Fatigue/Deprived/金钱不变。
- PC 可知道自己观察到的拖痕及 Mara 明确说出的计划；不会自动知道 Mara 的债务、长期目标或她对药剂师的私人承诺。

**Branch C 结果**：NPC 能拒绝、保留关键资源、完成真实物品交换、根据证据修正计划，并在 PC 不同行时继续自己的行动。

## 4. 最终状态对账

### Branch A（谈判）

- Mara：6/10 slots；12sp；HP 4/4；Fatigue 0；位置 Dock；计划不变。
- PC：4/10 slots；持 Torch。
- 新增条件性报价 3sp + 免费渡船；未接受、未支付。

### Branch B（离场）

- Mara：6/10 slots；12sp；HP 4/4；Fatigue 0；位置 Lower Landing；事务进度 1/3。
- PC：只知道 Mara 带 rope 与 hook 前往下游。
- 没有凭空消耗口粮、灯油、金钱或 Fatigue。

### Branch C（资源与计划干预）

- Mara：6/10 slots；12sp；HP 4/4；Fatigue 0；位置 Dock，准备转向 Old Mill Upper Bank；持 Torch，不持 Lantern。
- PC：4/10 slots；持 Lantern，不持 Torch。
- Rope、boat hook、oil flask、knife、Rations 仍在 Mara 账本；没有复制或丢失。
- 计划更新来自 PC 提供的可观察证据，不是 GM 任意改写。

三个分支的最终状态互不继承。

## 5. 验收结果

| 维度 | 评分 | 观察 |
|---|---:|---|
| 资源真实性 | 4/4 | 物品交换双方同步；库存格、现金、Fatigue、HP 与属性无无因变化；关键资源被拒绝借出有明确理由 |
| NPC 主动性 | 4/4 | NPC 有独立目标和计划；拒绝 PC、提出条件、离场行动、根据证据调整计划 |
| 离场连续性 | 4/4 | 只在游戏内 Watch 推进后核算离场变化；位置与事务进度有锚点；不逐分钟后台模拟 |
| 知识边界 | 4/4 | PC 只知道亲见/他人告知的内容；NPC 私有债务、目标和未知货箱内容不自动泄露 |
| 玩家能动性 | 4/4 | PC 可以谈判、拒绝、交换、改变信息；NPC 不替 PC 决定是否同行 |
| 人物表达 | 3/4 | Mara 有具体习惯、资源意识和表达差异；但只有一名 NPC，尚未验证多 NPC 之间的对比度 |
| 叙事承载 | 3/4 | 场景反馈有物件、动作和环境线索；合成对话仍不足以证明真实桌面节奏与长段落信息密度 |
| Cairn 规则调用 | 3/4 | 时间、库存、可观察信息和无风险行动裁定有体现；未覆盖战斗、伤害、Save、Fatigue 增长等真实危险情境 |

**综合结论：CONDITIONAL PASS。**

合成测试表明，L3 NPC 可以在本次短场景中维持资源账本、拒绝玩家、推进个人事务、离场后连续行动并根据新证据调整计划。但这仍是同一模型的自我扮演，人物对比度、压力下的状态维护、复杂 NPC 交互与真实玩家迁移均未得到独立验证。

## 6. 发现与后续修正建议

1. **交易应成为显式状态事件**：物品交接必须记录双方、物品、格数、使用次数、时间与承诺；不能只在叙述中说“交换完成”。
2. **NPC 私有状态与 PC 已知事实分栏**：每个 L3 NPC 的私有目标/资源/知识不得与 PC 的可知信息混写。
3. **计划与事务进度分离**：计划改变不等于事务进度完成；Mara 从下游改为上游，只更新路线，不把“找到 skiff”虚报为完成。
4. **时间推进采用事件锚点**：离场期间保留出发时间、预定行动、重返时间与结果；不逐分钟模拟。
5. **增加多 NPC 对比测试**：本次只有一个 NPC，无法验证角色之间的表达、注意力和决策风格是否真正拉开差异。
6. **增加真实风险场景**：后续短团需要让 L3 NPC 在资源不足、伤害、撤退、Morale、Fatigue 和时间压力下作出选择，并用 Cairn 2e 对应 Rule ID 结算。

## 7. 测试边界

- 本报告中的 Mara Bell、Alder Ford、PC-A、skiff、货箱和所有事务均为临时合成测试素材，不属于任何 Campaign。
- 不代表 CAS-1 的任何 NPC、地点、剧情或秘密。
- 不代表用户正式 PC 的背景、属性、物品或人物关系。
- 不把本次结果计为真实玩家盲测或正式短团通过。
