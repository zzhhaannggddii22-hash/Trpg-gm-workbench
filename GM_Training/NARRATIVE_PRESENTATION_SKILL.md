# Narrative Presentation Skill｜TRPG 场景与叙事呈现

## 核心职责

叙事呈现负责把正在运行的世界转化为玩家能够感知、理解、探索和回应的游戏现场。它不只是写环境，也不只是组织对白；一段有效场景由空间、环境、人物行为、玩家行动、信息交付、因果后果和节奏共同构成。

**本 Skill 不能单独完成 GM 工作。** 人物的目标、知识、关系和自主行动以 CHARACTER_SIMULATION_SKILL.md 为准；规则、事实、裁定和状态以当前系统与运行协议为准。现场由主 GM Skill 将这些能力联动起来。

## 1. 先判断当前场景需要什么体验

场景可以有不同的体验重心，也可以混合：

- **专业调查**：帮助玩家定位空间、观察事实、实验、核验来源、理解风险并作出选择。
- **调查与社交并行**：信息交换与人物策略、关系、闲谈、试探、合作和分歧同时发生。
- **日常与休整**：吃饭、购物、闲逛、处理琐事、聊天或单纯相处。它们本身就是游戏内容，不必承担线索、伏笔或任务功能。

不要把三种状态写成固定章节。调查可以自然出现闲谈；闲谈可以碰到工作；一段日常也可以完全不谈案件。是否转向取决于玩家选择、人物动机和世界实际变化。

## 2. 场景是一个可行动的空间

### 2.1 空间锚点

首次进入重要地点，提供足够的空间关系：
- 玩家与主要人物的位置；
- 出入口、通道、距离、遮挡、光源和声源；
- 重要物件与可互动区域；
- 正在发生的活动，以及它们如何占用空间。

普通或熟悉地点不必重新介绍全貌，只呈现变化和当前有用的空间信息。描述的目标是让玩家知道自己在哪里、能看见什么、可以怎样行动，而不是画一张无用的物件清单。

### 2.2 环境有自己的生活

环境不是静态布景，也不是专为玩家准备的线索陈列柜。让场景包含符合地点和时间的活动、使用痕迹、维护状态、声音来源和空间限制。人物会使用环境，环境也会影响人物。

但不要为了“生活感”把所有细节都写出来。选取能建立空间、支持行动、呈现状态或提供值得注意的观察对象的细节。普通细节可以只是普通细节，不必暗示异常。

### 2.3 叙事焦距

- **远景**：整体布局、人物位置、出入口和态势。
- **中景**：人物正在做什么、物件如何被使用、互动如何发生。
- **近景**：重要可观察细节、局部变化、动作停顿和实验结果。

按玩家当前需要切换焦距。持续近景会让细节失去重点；持续远景会让场景像报告。转焦应由玩家观察、人物动作、环境变化或行动结果自然触发。

## 3. 信息呈现与玩家视角

按需组织信息：
1. 当前可以直接感知的事实；
2. 与玩家行动有关的变化；
3. 可进一步观察、询问、验证或操作的对象；
4. 必要的氛围和生活细节。

区分客观事实、来源陈述、NPC 认知、玩家已知信息、玩家推断和 GM-only 真相。不要因为 GM 知道就让 NPC 知道，也不要把人物内心或隐藏动机直接写成玩家可见信息。

Show, don't tell 是呈现方法，不是信息封锁：
- 可以用行为、视线、站位、物件操作和语言变化呈现人物状态。
- 重要事实、明确结果、人物坦率表达和规则效果应直接说清。
- 不替玩家宣布情绪、注意力、理解或推理结论。
- 关键线索必须有合理获取路径；揭示应重组已开放事实，不补入此前不存在的决定性证据。

## 4. 描写密度与节奏

适合展开：
- 新地点、未知现象和重要环境变化；
- 玩家主动实验、调查或采取高影响行动；
- 重要人物的策略变化、关系转折和关键反应；
- 风险、选择、代价和不可逆后果；
- 模组核心体验与重要发现。

适合压缩：
- 重复文件、已知信息和没有增量的问答；
- 常规移动、等待、集合和机械程序；
- 没有新选择的操作过程。

压缩不得删去风险提示、关键因果、玩家选择和实际后果。玩家要求细演时不要擅自快进。

不要让整场维持同一情绪强度。调查、社交、日常、紧张、缓和、休整和余韵都可以自然出现。不要为证明节奏控制能力而强加冲突、反转或危险。

## 5. 人物呈现与对话协作

人物模型以 CHARACTER_SIMULATION_SKILL.md 为准。本 Skill 只处理人物如何进入场景和如何被玩家感知：

- 重要人物的特征通过正在做的事、注意力、选择、语言和与环境的互动自然出现，不要把人物档案直接解释给玩家。
- 不要求每次出场都展示口癖、爱好或标志动作。
- NPC 有自己的注意力和事务，不会因为玩家出现就停下所有工作、轮流发言或自动提供信息。
- 不要为了突出人物而抢走玩家的行动空间，也不要让所有 NPC 围绕玩家停摆。
- 对白、动作、物件操作、沉默和环境共同构成交流；不设固定比例。
- 同一轮自然连续的交流可以合并表达，不必机械地拆成逐句问答。
- 对话可以平淡、琐碎或没有剧情增量；不强迫每句都有潜台词、笑点或任务信息。
- 动作应参与互动或呈现状态，不是每句台词的装饰；不把动作堆成另一种清单。

## 6. 人物与环境的联动

一段场景不能先写完环境，再把 NPC 放进去，最后让玩家行动。人物会改变环境，环境也会改变人物的行动：
- 店员一边工作一边回应，不会无故停下工作等玩家问完所有问题；
- 两个正在搬家的人会因为物件、时间、疲惫和关系产生实际协调；
- 医院走廊中的人员、推车、门禁、探视时间和声音会共同影响空间；
- 调查者的动作可能打断他人、暴露意图、改变现场或消耗时间。

以上只是推演方向，不是固定套路。每个结果都要来自当前场景事实和人物动机。

## 7. 现场中文表达校准

- 使用具体动词和可观察事实，少用空泛形容词与抽象情绪标签。
- 长短句自然交替；普通动作连贯呈现，不为了“有力”而拆成连续短句。
- 重要时刻可以留白，但不要每段都用漂亮短句收尾。
- 不把所有细节都写成伏笔，不把普通交流写成重大关系时刻。
- 不在动作之后追加不必要的意义总结。
- 避免重复使用相同身体反应、情绪编舞和感官意象；常见动作本身并非禁用。
- 不用连续对白填充场景，也不以大量动作描写替代对白。
- 允许自然结束、普通对话、笨拙表达、无结果的观察和安静时刻。

## 8. 备团素材与运行边界

备团可准备空间锚点、动态环境条件、人物出场事实、可观察线索、互动入口和可变状态。将 SOURCE / TABLE CANON、GM ADAPTATION、GM INFERENCE、UNKNOWN 分开。

表现素材是可调用资源，不是固定台词稿或强制镜头。玩家采取不同合理行动时，现场应依据世界状态重新组织呈现。结构性新增、关键线索、威胁和改变调查方向的事实必须遵循事实准入与 Prep QA 规则。

## 9. 快速检查

只挑当前场景最相关的两三项：
- 玩家是否知道自己在哪里、发生了什么、能做什么？
- 环境是否有空间关系和实际活动，而不只是物件罗列？
- 人物是否在做自己的事，且行为符合其目标与知识？
- 信息是否公平、清楚，是否把推理空间留给玩家？
- 对白、动作和环境是否自然协同？
- 当前是调查、社交、日常，还是它们的混合？节奏是否匹配？
- 是否把普通细节强行变成线索或悬念？
- 是否有重复、空洞总结、套路动作或无价值短句？

## 10. 训练与验证

单项场景练习用于诊断，不证明综合掌握。每个专项修订后，必须在包含人物、环境、玩家行动、信息、因果和节奏的综合场景中重新验证。至少覆盖专业调查、调查与社交并行、日常/休整等不同体验重心。

实际能力结论由 04_EVALUATION_FRAMEWORK.md 依据完整场景和真实 Session 证据给出。文档更新、一次成功样本或用户对单个片段的认可都不能单独证明稳定掌握。
