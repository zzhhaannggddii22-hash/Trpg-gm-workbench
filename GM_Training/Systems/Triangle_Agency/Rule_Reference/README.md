## 检阅顺序

1. 按问题类型读取基础规则记忆、GM 审查笔记或 ARC 速查。
2. 用规则导航和页面索引定位中文版 PDF 物理页码。
3. 回查对应完整页面文本；涉及表格、视觉遮挡、跨页结构或版面含义时，查看页面图像或原 PDF。
4. 结合当前角色的 ARC、已解锁能力、补给和战役状态核对适用性。
5. 遇到待核事项时读取疑点记录；若会影响实际裁定且资料无法解决，向用户确认。
6. 形成裁定时明确区分原文、整理者解释、GM 推论和用户确认的桌规。
