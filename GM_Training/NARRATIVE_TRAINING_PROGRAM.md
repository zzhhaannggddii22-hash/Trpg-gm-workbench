# TRPG 叙事与主持能力训练体系

## 目标与阶段边界

当前阶段以 A「技术型 GM」为主：建立稳定、可靠、可复现的主持表达与运行能力。暂不把个人文风、独特审美或自由创作作为主要考核目标；这些属于后续阶段。

训练成果必须进入实际工作流。研究笔记和练习作品只是证据与素材，不能替代运行 Skill，也不能因文档更新而宣布能力已经提升。

本体系分成五个相互衔接的环节：

1. 能力训练：通过专项练习改善具体技术。
2. 备团应用：将已验证的方法转化为可调用的事实卡、场景素材、NPC 模型和调查结构。
3. 实战应用：在玩家行动不可预测的情况下执行叙事、扮演、裁定和状态维护。
4. 质量控制：用事实核验、状态机制、复盘和外部反馈纠偏。
5. 知识沉淀：将经过验证的改进写入对应的运行 Skill，并保留来源与适用边界。

## 一、能力地图与工作阶段

| 能力领域 | 主要训练内容 | 备团阶段的应用 | 带团阶段的应用 |
|---|---|---|---|
| NPC 维护层级 | L0 临时路人不建人物卡；L1 为值得建立模组人物卡或低重要性战役人物；L2 为战役常驻配角或长模组重要互动角色；L3 为战役核心长期角色；L4 仅为凯西助手人格 | 按角色实际重要性分配档案与现场模拟深度，详见 CHARACTER_SIMULATION_SKILL.md |
| 场景与空间呈现 | 空间锚点、感官细节、焦点、描写密度 | 重要地点入口卡、感官/动态锚点、互动对象 | 根据玩家视角即时描述、随行动更新空间 |
| NPC 人物与对白 | 目标、顾虑、策略、声音、动作、关系 | NPC 目标/知识/关系/资源卡、可演方向 | 即兴回应、策略变化、人物状态连续 |
| 玩家行动反馈 | 意图识别、因果、风险、后果 | 关键机制、可变状态、可能后果与触发条件 | 回应预案外行动，完成结果与状态更新 |
| 线索与信息呈现 | 线索公平、来源可靠性、信息层次、揭示 | 线索/来源账本、替代路径、验证条件 | 按角色可知信息交付，不替玩家推理 |
| 节奏与场景结构 | 展开/压缩、场景功能、悬念与缓和 | 场景节拍、时间线、可摘要流程 | 识别当前是否需要细演、停顿或快进 |
| 氛围与情绪 | 正常基线、异常对比、感官选择、余韵 | 氛围锚点、异常可观察表现 | 结合当下视角控制强度，不强制制造戏剧性 |
| 连续性与状态管理 | 时间、位置、物品、知识、关系、事件一致 | 初始状态、事实卡、交接快照、检查点 | 维护运行状态，避免重演、遗忘、穿帮与错误回滚 |

能力领域不是要求每场都完整执行的清单。按训练目标和场景风险选择必要部分。

## 二、参考材料：小说是主要训练来源之一

优秀 Actual Play 和实况记录可以观察互动节奏、主持回应与玩家选择，但资源有限，且节目形式、剪辑、玩家熟悉度和桌风会影响表现。因此，小说应成为重要的技法研究来源，不能只研究真实跑团记录。

按需要从不同类型作品中选择具体片段：

- 推理与悬疑：线索预埋、公平揭示、信息分层、误导来源、证据重组。
- 恐怖、怪谈与 Weird Fiction：正常基线、异常显现、感官锚点、不安与悬念、留白。
- 科幻与世界观驱动作品：规则一致性、复杂概念的可理解呈现、环境如何展示世界运行逻辑。
- 人物驱动与现实题材：自然对白、关系变化、言外之意、日常细节和人物差异。
- 冒险与动作作品：空间调度、行动过程、风险提示、动作结果和节奏变化。

可以研究用户已提及的作品与类型，例如《诡秘之主》早期章节、《深渊漫游者》，以及 SCP、Backrooms、Control 等作为异常叙事的补充材料；它们只是研究样本，不是风格模板。

研究单位优先选择“片段/场景”，而不是整本书。每个样本记录作品与章节定位、该片段要解决的叙事问题、使用的技术、效果来源、潜在副作用，以及哪些部分不适合迁移到桌面游戏。

## 三、小说技法迁移：从阅读到可玩的 GM 技术

禁止把“像小说一样写”作为迁移目标。迁移的对象是可复用的叙事技术，而不是作者文风、句式、剧情安排或整段文本。

每个样本按以下流程拆解：

1. **识别效果**：读者在这一段获得了什么体验或信息？例如空间清晰、人物可信、悬念增强、线索被重新理解。
2. **提取技术**：作者通过什么手段实现？例如焦点切换、细节选择、动作顺序、信息延迟、对话策略、重复意象或句长变化。
3. **转换为桌面可感知内容**：玩家角色此刻能够看到、听到、触碰、询问或验证什么？哪些信息仍然属于隐藏事实？
4. **增加互动入口**：玩家可以如何检查、改变、绕开、追问或利用这个场景？不同合理行动会产生什么反馈？
5. **进行可玩性测试**：假设玩家不按作者安排行动，场景是否仍然成立？是否仍保留选择、因果和信息公平？

### 迁移边界

| 小说技法 | 可迁移的 GM 用法 | 不能照搬的部分 |
|---|---|---|
| 内心视角与心理描写 | 转换为角色可观察的行为、语言、注意力和环境反应；用于 NPC 时遵守信息公开边界 | 不替玩家角色书写思想、情绪、判断或未声明的注意力 |
| 作者控制的信息揭示 | 设计玩家可发现的信息层次和合理获取路径 | 不把关键事实藏到玩家无法接触的叙事机关后面 |
| 伏笔与回收 | 预先呈现可识别事实，使后续揭示重新解释旧证据 | 不在揭示时补入此前不存在的决定性证据 |
| 场景调度 | 准备空间关系、人物位置、动作顺序和可互动对象 | 不强迫玩家走作者安排的路线或镜头 |
| 对白与潜台词 | 建立 NPC 的目标、策略、关系距离和表达习惯 | 不给每句台词强加潜台词，不把 NPC 变成谜语人 |
| 节奏与段落长度 | 决定现场何处展开、何处摘要、何处停下来交还行动权 | 不把小说长段落直接搬到桌面，忽略玩家输入 |
| 情绪与氛围 | 通过可感知的变化、正常基线和少量高价值细节建立氛围 | 不替玩家宣布感受，不用抽象情绪标签代替体验 |

迁移成功的标准：小说技法在不损害玩家能动性、规则、事实、信息公平和现场清晰度的情况下，改善了玩家可感知的体验。

## 四、训练类型与完整训练单元

每个训练单元应以一个相对完整的工作包交付，不要求用户在执行过程中持续盯守或逐段批改；常规流程为 Casey 自主选题、完成后交用户复盘审核。

### 训练选题与复盘审核

- Casey 自主维护 [NARRATIVE_TRAINING_QUESTION_BANK.md](./NARRATIVE_TRAINING_QUESTION_BANK.md)，负责准备、更新、轮换和淘汰训练题目。
- **题目由 Casey 自主选择并准备，但每次正式训练前必须先把完整新题提交用户检查。** 用户可以确认、修改或要求换题；未得到确认前只进行题目设计与自查，不进入正式训练。
- 用户确认题目后，Casey 独立完成初稿、诊断、修订和自评，不在训练过程中反复打断用户索取反馈。
- **训练完成后再交用户审核**：重点展示最终成果、关键修订、尚存问题与自评；认真记录用户对效果、节奏、表达和适用边界的反馈。
- 用户可以随时主动调整方向、替换题目或提供 USER-SUPPLIED 题目；收到这类明确指示后按其要求执行。
- 若新题会改变已确认的训练方向、涉及用户不愿触碰的内容，或必须依赖用户未提供的关键偏好，才在开始前询问。
- 用户反馈进入训练记录与题库，区分用户判断、Casey 自评和仍待实战验证的假设。

建议训练单元结构：

1. 目标与约束：说明本次具体训练什么，不同时练所有能力。
2. 样本与拆解：必要时选择小说、Actual Play、模组或既有跑团片段。
3. 初次产出：完成一段完整场景、对话、行动反馈、调查结构或模拟。
4. 自我诊断：按相关 Skill 和训练目标找出具体问题，说明影响。
5. 修订产出：给出修订版或更稳妥的备团方案。
6. 对照说明：展示关键变化，指出尚未解决的问题和判断不确定处。
7. 迁移记录：提出是否值得更新 Prep 或 Runtime Skill，以及验证计划。

不应每做一个小步骤就向用户索取反馈。用户反馈集中用于校准关键样本、评价标准和阶段性成果。可在用户方便时展示代表性样本、前后对比或不确定的判断。

### 主要训练方法

- **近距离阅读**：拆解小说片段中的信息、动作、焦点、对白和节奏。
- **对照实验**：同一场景改变一种变量，例如 NPC 情绪、叙事焦距、细节密度或信息顺序。
- **转换练习**：把小说片段的叙事效果转换成 GM 描述、NPC 可演方向或互动场景。
- **即兴模拟**：由玩家采取非预设行动，测试 GM 能否保持人物和世界逻辑。
- **缺陷修复**：针对真实复盘问题重写，比较修订前后的可观察差异。
- **冷启动与连续性测试**：在中途恢复场景，检验能否准确续接而不重演、不漏记、不串线。
- **跨场景验证**：更换人物、地点、模组或叙事类型，测试方法是否仍有效。

## 五、备团能力与带团能力的职责分离

### 备团可以提前完成的工作

- 把模组事实、GM 改编、推断与未知分层。
- 建立重要 NPC 的目标、顾虑、策略、权限、知识边界和关系。
- 准备重要地点的空间锚点、显著感官细节、动态变化和互动入口。
- 准备线索来源、关键事实的合理获取路径、验证条件和信息门槛。
- 整理时间线、事件触发条件、NPC 行动机会和世界因果。
- 为重要场景准备可调用的表现素材、首次接触卡和简短运行索引。
- 为非预设行动预留世界逻辑与资料入口，而非写死玩家分支。
- 生成 Preflight 所需的初始状态与交接快照。

### 必须在带团过程中完成的工作

- 根据玩家实际行动选择描述焦点和细节密度。
- 让 NPC 对玩家真实说过的话和实际行动作出回应。
- 在玩家改变计划时更新 NPC 策略、世界状态和事件条件。
- 根据玩家视角交付信息，区分观察事实、角色推断和隐藏真相。
- 判断展开、压缩、停顿、切场和交还行动权的时机。
- 维护当前时间、位置、在场者、物品持有人、人物知识、资源和事件状态。
- 面对错误或冲突时停止沿错误状态推进，查明偏离点并修复。

备团素材是可调用资源，不是固定台词稿。玩家行动优先于预写演出。

## 六、训练成果如何进入正式 Skill

训练成果使用“候选—验证—集成—回访”流程，不把全部练习、小说摘录和分析笔记塞进运行 Skill。

### 训练方法成熟度（T0—T4）

为避免与 NPC 的 L0—L3 角色维护层级混淆，训练成果成熟度使用 T 编号：

- **T0 观察**：发现一个有效技巧、缺陷或疑似规律；只记录训练日志。
- **T1 候选方法**：能写出适用条件、具体操作、限制和预期效果；放在训练记录或候选池。
- **T2 重复有效**：至少在两个相互独立的场景或样本中有效，保留反例或适用边界；准备试用于实战。
- **T3 Skill 集成**：明确写入对应的正式 Skill，内容包含触发条件、执行方法、边界、反模式和检查方式。
- **T4 实战验证**：在实际跑团中多次有效，且未造成明显副作用；可作为稳定方法继续维护。

文档集成不等于能力晋级。单次表现、单篇小说分析或一次用户认可，不能单独证明稳定掌握。

## 七、训练评价与阶段晋级

评价以可观察表现为依据，不以练习篇数、文档长度或回复速度判断进步。

每个训练单元记录：

- 训练目标与所用样本；
- 初稿中最具体的一个或两个问题；
- 修改后实际发生的变化；
- 用户反馈与自我判断的分歧；
- 适用边界、反例和未验证假设；
- Prep / Runtime / Continuity 中的归属；
- 是否进入候选池、正式 Skill 或暂不沉淀；
- 下一次验证场景。

能力状态采用：初步掌握、重复有效、实战验证、稳定掌握、证据不足。跨场景验证前，不宣称稳定掌握。

A 阶段的晋级重点不是追求独特文风，而是：不同场景下的事实准确、表达清晰、人物自然、玩家行动响应、信息公平、节奏合适和连续性可靠。只有这些能力足够稳定后，再讨论 C 阶段的创造性与个人审美发展。

## 八、连续性训练的特别说明

上下文稳定性不能只靠写作训练或延长思考解决。训练能提升执行检查的能力，但事实与状态必须由权威记录、运行快照、事件日志和恢复协议提供外部锚点。

连续性至少包含：时间顺序、空间位置、在场者、物品持有人、角色知识、玩家已知信息、资源、关系、承诺、事件阶段与场景是否已经发生。

训练应包含多轮模拟、跨对话冷启动、事件回滚和信息差测试；但实际跑团仍以《07_RUNTIME_CONTROL_PROTOCOL.md》的状态机制为准。不得用“我记得”替代最新有效状态，也不得把模型摘要当作事实来源。
