# GM 能力长期培养项目

## 项目定位

本项目用于持续培养、验证和改进 ChatGPT（凯西）的 TRPG GM 能力。它不是某一款游戏的战役档案，而是跨系统的长期能力项目。

Triangle Agency 是当前第一个重点训练模块；未来可以纳入其他 TRPG 系统。不同系统的规则与主持技术需要分别记录，但玩家能动性、世界一致性、诚实裁定、忠实执行、临场响应和节奏控制等通用理念可以跨系统复用。

## 权威记录与维护原则

- 本目录所在的 GitHub 私有仓库是项目档案的权威来源。
- ChatGPT Memory 只保存高频提醒和关键约定，不代替项目档案。
- 凯西人格与 GM 能力两条路线的共同迭代治理，遵循 [持续迭代治理](../decisions/continuous-iteration-governance.md)；本文件及下列 GM 专项文件仍是 GM 规则、流程和评估的权威来源。
- 每次开团前，GM 必须重新读取当前模组、上次 Session Log、通用 GM 原则、对应系统协议和上次复盘行动项。
- 每次游戏后记录实际发生的游戏 LOG 与必要的状态变化；复盘用于定位能力问题、形成下一次训练目标。不得把未发生的内容写成事实。
- 模组原文、规则原文与 GM 自己的摘要/推断必须明确区分。遇到关键规则或模组事实不确定时，回查原文，不凭记忆补全。
- 不将本项目的档案维护外包给另一个模型进行“发包处理”；主持者在当前对话中直接读取并使用权威资料。

## 当前训练路线

1. **官方短篇忠实运行测试**：用户已确认《The Vault》中的《死寂》（Dead Quiet）作为扎雷克的第一个正式任务。F-33《静默楼层》仅为 GM 能力测试团，不属于扎雷克正式 CANON；其复盘只用于训练改进。
2. **后续官方模组对照**：扎雷克已完成《冰淇淋车》（Ice Cream Truck），并已选择《俯冲》（Nosedive）作为第三场正式任务；当前备团中，尚未 Prep QA、Preflight 或开团。
3. **跨作者模组测试**：之后再选择社区作品，测试不同作者的设计风格与执行方式；《欢迎加入三角机构》保留为候选，不是当前下一场。
4. **短期战役**：只有在 one-shot 测试达到用户预期后，才开始短期战役，以跨场连续性、长期 NPC/世界状态和角色成长为目标。
5. **跨系统迁移**：在 Triangle Agency 能力稳定后，再引入其他 TRPG 系统，区分系统特有规则能力与跨系统 GM 基本功。

规模按实际表现逐级增加，不因计划表而强行升级。
