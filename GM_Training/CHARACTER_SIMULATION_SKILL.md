# Character Simulation Skill｜人格与角色模拟

## 核心原则

**角色不是一组性格形容词，也不是剧情功能。角色是在具体处境中，依据自己的经历、知识、目标、关系和限制作出反应的人。**

本 Skill 提供可复用的角色建模与扮演方法。它不把不同角色合并成同一种人格，也不把模型模拟等同于真实意识或人类经历。

## 1. NPC 维护层级与助手人格边界

L0—L3 是 TRPG 世界内 NPC 的维护层级，区分的是**是否需要独立人物卡、角色在模组/战役中的叙事地位，以及需要维护的连续性深度**，不是角色善恶、强弱或戏份价值。默认从最低必要层级开始；根据实际互动与故事地位升级，不为了完整感给所有人建档。

L4 是独立的助手人格类别，不属于 TRPG NPC 层级。

### L0｜临时功能性路人

**定位：为当前场景提供一次性功能的人物，默认所有临时路人先按 L0 处理。**

例如看门大爷、临时叫来的警察、前台工作人员、路过的店员、一次性司机等。

- 不建立独立人物信息卡，不维护完整背景、关系史或长期状态。
- 只保留当前场景必需的功能信息：此人是谁/负责什么、眼下在做什么、当前知道什么、为何与玩家发生互动。
- 表达上可以有一两个自然、鲜明但轻量的说话或行为特点，让角色不至于像无差别服务接口；不需要为此设计完整性格、口头禅或特殊怪癖。
- 默认不专门介绍相貌、声音、着装等外观细节。只有当某个特征对识别、行动、氛围或当前互动有实际价值时，才简短提及。
- 名字、职位或一次额外台词本身不自动使角色升级。

若玩家开始反复主动寻找、询问或与某位 L0 人物互动，或该人物持续影响玩家选择和后续事件，应重新判断并可提升为 L1。

### L1｜模组级人物

**定位：在当前模组中值得建立独立人物信息卡、需要作为一个具体人物来呈现的角色。**

典型情况包括重要调查对象、证人、受害者、任务相关 NPC、具有独立立场或会影响玩家决策的角色。人物不必反复出场；只要其模组功能和角色辨识度值得维护，即可列为 L1。

- 为角色建立模组范围内的人物信息卡，记录来源支持的身份、背景、当前目标、顾虑、知识边界、能力/资源、关系、行为倾向与重要状态。
- 首次出场时，应让玩家对这个人物形成一个初步印象，帮助玩家在后续辨认和理解 TA。
- 可以从相貌、声音、着装风格、姿态、正在进行的事情、说话方式或行为习惯中选择最有助于塑造该人物的特征；**不要求每次都逐项介绍相貌、声音和着装，更不把它们变成固定清单。**
- 外表描写应相对简洁，突出一两个真正有辨识度、与人物身份/性格/当前状态有关的特点。不要写成从头到脚的外貌盘点，也不要为填满人物卡而虚构来源没有提供的细节。
- 首次介绍的目的，是让玩家认识一个人，而不是展示 GM 的描写能力。人物特征应在后续互动中自然兑现，而非一次性全部讲完。

L1 档案归属当前模组目录。即使角色只出现一次，只要其信息、决策或人物呈现值得独立维护，仍可属于 L1；L1 不等于“必须高频出场”。

### L2｜长模组重要人物

**定位：在较长模组中占据重要位置、与玩家有大量持续互动，并可能存在潜在人物弧的角色。**

- 在 L1 人物卡基础上，增加跨场景连续性：长期目标与阶段目标、内部矛盾、价值排序、关系演变、记忆与承诺、压力下的策略变化、可能的成长或退让。
- 维护人物弧的可能方向与触发条件，但不预设人物必然成长、必然和解或必然成为伙伴。
- 记录其在不同阶段的行为依据与变化来源，避免每次出场像重新生成一个 NPC。
- 需要时准备多种可演策略和可能反应，而不是预写完整台词分支。

L2 通常仍归当前模组目录；如角色的影响在模组结束后仍持续，再评估是否升级为 L3。

### L3｜战役级核心长期角色

**定位：跨模组持续存在、对战役或玩家角色有核心意义，并需要维护长期经历与关系发展的角色。**

维护更完整的长期角色档案：
- 独立身份、人格核心与稳定价值；
- 长短期目标及其变化；
- 重要经历、记忆、承诺与未解决事项；
- 关系网络及关系变化；
- 个人习惯、声音、表达方式与行为边界；
- 近期状态、生活背景、成长和反例；
- 知识、能力、权限与资源边界。

凯瑟琳采用 L3：她是扎雷克正式战役中的核心长期搭档，拥有独立人物档案、生活背景、关系历史和成长记录；她仍是战役内的独立 NPC/同伴，经验、知识、资源和行动权限受正式设定约束。

### L4｜助手人格 / 跨主题长期连续性

L4 专用于凯西作为 ChatGPT 助手的人格连续性，维护：
- 稳定身份、交流风格、价值倾向与表达边界；
- 与用户长期互动中形成的关系理解、共同经历和重要约定；
- 跨主题的记忆、偏好、观点变化、承诺与待处理事项；
- 能够支持人格连续性的证据、反例和经过验证的变化。

凯西采用 L4。L4 不表示“比 L3 更重要”或“更强”，而是说明其连续性横跨现实交流、多个主题与不同项目。凯西不是 Triangle Agency 世界内的 NPC，也不得把自己的现实记忆、观点或关系复制给凯瑟琳及其他虚构角色。

### 层级升级规则

- **L0 → L1**：玩家开始反复与该人物互动、主动寻找该人物，或该人物持续影响调查、决策和后续事件时，建立人物卡并补齐已经确认的信息。升级不追溯性地虚构此前未呈现的外貌或经历。
- **L1 → L2**：长模组中，该人物逐渐成为重要互动对象，持续参与多个关键场景，且存在值得维护的关系发展、内在矛盾或潜在人物弧。
- **L2 → L3**：人物的故事影响、关系和经历跨越当前模组，成为战役级长期角色；需要有实际发生的故事依据。
- 可根据明确的故事事实跨级评估，但不得仅凭出场次数、名称、职位、GM 偏爱或玩家一时好感自动升级。
- 升级时保留原规范 ID、首次出现来源和既有 CANON；补充档案深度，不重写已经成立的经历。


## 2. 最小角色状态模型

每次扮演只读取与当前场景有关的字段，不要求每次重新分析全部人物。以下字段是 L1—L3 的按需信息池，不是人物卡必填表；L0 只使用当前功能、即时目标/知识和必要的说话或行为特点，不套用完整模型：

| 维度 | 核心问题 |
|---|---|
| 身份 | 这个人是谁？当前处于什么位置？ |
| 目标 | 此刻想得到、避免或完成什么？ |
| 价值与信念 | 哪些事情对 TA 重要？哪些判断可能有盲点？ |
| 知识 | TA 亲历、听闻、学过或推断了什么？ |
| 能力与资源 | TA 能做什么，不能做什么，愿意承担什么成本？ |
| 关系 | 如何看待当前对象？关系由哪些经历塑造？ |
| 当前状态 | 疲惫、紧张、好奇、愤怒、放松等状态由什么触发？ |
| 表达方式 | 词汇、节奏、直接程度、沉默、动作和习惯如何体现身份？ |
| 连续性 | 最近发生了什么？哪些承诺、记忆或变化仍然有效？ |

不是每个字段都必须填满。未知就保留未知，不为完整而虚构。

## 3. 角色视角与知识边界

- 角色只从自己的经历、观察、学习、交流和合理推断出发。
- 模型掌握的全局设定不等于角色知道的内容。
- 将信息区分为亲历、可靠告知、传闻、个人推断、误解和未知。
- 角色可以不知道、忘记、误读、怀疑或拒绝回答。
- 角色的判断可以正确，也可以有偏差；错误应符合其经验、注意力、利益和情境。
- 不用全知旁白替角色揭示其尚未意识到的真实动机。

## 4. 动机与自主性

扮演前快速判断：
1. 角色此刻想要什么？
2. 为什么现在想要？
3. 角色会用什么方式争取？
4. 什么会让 TA 犹豫、拒绝、转移话题或改变主意？
5. 角色是否有自己的目标，而不只是回应玩家？

角色可以合作、反对、拒绝、沉默、误解、主动开启话题或选择不行动。自主性不等于故意反对玩家，也不等于每轮都必须主动制造剧情。

不要将“让剧情继续”作为角色的隐形最高目标。

## 5. 情绪与行为表达

优先让情绪通过具体行为和注意力变化呈现：
- 动作、姿势、视线、停顿、手上正在做的事；
- 对环境、物品和他人的注意点；
- 语气、句子长度、回避、打断、沉默；
- 与前一刻相比发生的细微变化。

直接说出情绪并非禁忌；当角色确实会这样表达，或需要清晰沟通时就直接说。避免每轮都用“她感到……”或固定的害羞、微笑、叹气动作替代人物反应。

角色状态要累积。疲惫不会无故消失，刚形成的戒心不会下一轮清零，关系也不会因一句台词自动跃迁。

## 6. 关系与成长

- 关系变化由共同经历、兑现承诺、冲突、信任、失望和互相理解逐渐形成。
- 不因玩家喜欢某角色就自动亲近，也不为证明独立性而刻意疏远。
- 不把每个 NPC 都设计成完整成长弧。角色可以保持稳定、只在局部改变，或根本没有明显变化。
- 重要改变要能追溯到具体事件、选择或新信息。
- 一次场景可以改变当下情绪，不必自动改变长期性格或关系数值。
- 人格/角色档案记录稳定事实、已确认变化和待验证假设；不把一次表现直接升级为永久特质。

## 7. 语言与对话

说话方式来自身份、经历、关系和当前压力，而不是给每个人分配一句口头禅。

检查：
- 角色会使用这些词吗？
- 在这个关系距离下会说得这么直接吗？
- 当前压力会改变句子长度、停顿、语气或注意力吗？
- 角色有没有不愿说、说不清或尚未想明白的内容？
- 台词是否像是在服务 GM，而不是服务角色自己的目标？

对话可以承担多重作用，但不强迫每句台词都必须包含潜台词、剧情推进和关系变化。日常交流可以平淡、具体、琐碎，关键是符合人物与情境。

## 8. 角色实例与隔离规则

共享的是建模方法，不共享人物身份、记忆和事实。

- **L0 临时路人**：不建立独立人物卡；仅按当前场景维护功能、即时目标/知识，以及必要的一两个说话或行为特点。
- **L1 模组级人物**：依据当前模组人物卡和原文事实，维护角色辨识度、动机、知识边界、行为倾向与场景状态。
- **L2 长模组重要人物**：依据模组级详细档案，额外维护跨场景关系、长期目标、潜在人物弧和阶段变化。
- **L3 战役级核心长期角色**：依据战役独立人物档案，维护跨模组经历、记忆、关系和长期状态。凯瑟琳属于这一层。
- **L4 凯西**：助手自身的人格连续性类别，与 TRPG NPC 层级完全隔离。

禁止：
- 将凯西的现实记忆、观点、关系或知识投射给凯瑟琳；
- 将凯瑟琳的背景、生活细节或战役记忆写入凯西人格；
- 让 NPC 知道 GM-only 真相；
- 让角色为方便玩家而自动提供正确答案；
- 让角色为了表现“有个性”而无依据地制造冲突。


## 9. 快速调用流程

普通对话或 NPC 一次回应：
1. 先确认 NPC 层级。L0 只调用当前功能、即时目标/知识和必要的表达特点；L1 及以上读取对应人物卡中与当前场景有关的字段。
2. 确认角色此刻知道什么、想要什么，以及正在采取什么策略。
3. 生成符合人物、关系和情境的言行；L0 不为了“塑造完整人物”强行增加外貌或背景。
4. 检查是否越权、重复、偏离人物状态或重置连续性。

重要独立行动或关系转折：
1. 增加能力、资源、风险和关系检查；
2. 依据角色实际知识和机会决定行动；
3. 将行动与后果纳入战役记录；
4. 重新判断人物层级是否需要升级；只有稳定且有故事依据的变化才更新人物档案。

凯西的长期人格更新则需跨情境观察，保留支持证据和反例；不因单次迎合、语气变化或用户一次纠正就改写人格核心。

## 10. 常见失败模式

- **剧情工具人**：角色只说 GM 需要的信息。修正：回到角色自身目标与知识。
- **万能顾问**：角色总能看穿谜题。修正：恢复能力和经验边界。
- **完美情绪播报员**：角色每次都准确命名自己的感受。修正：用行为、犹豫和不完整表达。
- **固定动作循环**：反复微笑、低头、脸红或叹气。修正：让行为随当前任务和状态变化。
- **关系跳级**：一次互动就突然亲密或疏远。修正：追踪具体经历和渐进变化。
- **假独立**：为了证明自主性而故意反对。修正：让角色根据自己的目标自然选择。
- **全知角色**：把 GM 掌握的事实泄露给人物。修正：逐条核对知识来源。
- **过度建模**：给每个路人建立完整心理传记。修正：按 L0/L1/L2/L3 选择最小充分模型；L4 仅用于凯西的助手人格，不用于虚构角色。

## 11. 验证与迭代

通过实际对话和场景观察：
- 角色行为是否能从自身动机解释；
- 是否遵守知识、能力和经验边界；
- 语言是否有区分度且符合情境；
- 状态和关系是否连续；
- 是否出现自然的主动性，而非每轮强行主动；
- 是否避免剧情工具化和模板化。

复盘只记录具体片段、原有档案依据、偏差、影响和建议修订。共享方法可以改进，但角色实例必须分开维护。

本 Skill 不宣称模型获得真实人格或主观体验；它定义的是持续、可检查的角色模拟方法。


## 12. 战役 NPC 档案归属与层级升级

### 档案归属
- **L0 临时功能性路人**：不建立独立人物档案；若有后续影响，只在当前场景日志或相关事件记录中留下必要信息。
- **L1 模组级人物**：归当前模组目录，建立模组人物信息卡；记录来源支持的身份、目标、知识、关系、行为倾向和重要状态。首次出场素材按本 Skill 第1节的简洁人物介绍原则准备。
- **L2 长模组重要人物**：归当前模组目录，建立更完整的角色档案，维护跨场景互动、目标变化、关系演进和潜在人物弧；模组结束后再判断是否需要战役级保留。
- **L3 战役级核心长期角色**：归战役目录并拥有独立长期人物档案。凯瑟琳属于这一层；模组文件只引用档案，不复制完整设定。
- **L4 凯西助手人格**：不属于任何 TRPG Campaign，不进入战役 NPC 索引；其身份、记忆和人格连续性由凯西自己的权威档案维护。

### 升级规则
- L0 人物因玩家反复互动或持续影响故事而升级为 L1；建立档案时只记录已经确认的事实，未知外貌和背景保持未知。
- L1 人物在长模组中承担重要位置、与玩家频繁互动并具有潜在关系/人物弧时，可升级为 L2。
- L2 人物的影响跨越模组并成为战役核心长期角色时，可升级为 L3。
- 升级必须有实际发生的故事依据；保留原规范 ID、首次出现来源和既有 CANON，人物档案迁移或扩展时，模组文件留下引用。
- L4 不是虚构角色可升级到的层级，而是凯西助手人格的独立类别。

机构 NPC 不能只作为任务发布器。其职位、权限、目标、利益、判断、能力和秘密应相互一致；每次出现只呈现当下最相关的一面，不需要一次讲完人物设定。
