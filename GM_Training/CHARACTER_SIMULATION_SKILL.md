# Character Simulation Skill｜人物模拟与 NPC 自主性

## 核心职责

本 Skill 定义人物是谁、知道什么、想要什么、能做什么，以及在当前关系和情境下可能怎样行动。它不独立决定场景节奏，也不要求把人物全部内心展示给玩家；人物必须与环境、规则、玩家行动和叙事呈现共同运行。

**人物鲜活不是独立于游戏体验的装饰指标。** 人物的行动会改变信息、空间、关系、风险和玩家选择；玩家行动也会改变人物策略。人物不能沦为线索机器、任务发布器、万能顾问或只负责陪伴玩家的工具。

## 1. 人物层级与投入

层级决定维护深度，不决定人物价值：

- **L0｜临时功能性路人**：维护当前身份、功能、即时目标/知识和必要的场景状态；不建立完整人物卡。
- **L1｜模组普通人物/低重要性战役人物**：维护来源事实、当前目标、必要知识边界、一个或两个有依据的辨识特征。鲜活但不过度扩写。
- **L2｜重要人物/战役常驻配角**：维护稳定动机、关系、知识、权限、行为倾向和跨场景状态；可以有兴趣、缺点和生活安排。
- **L3｜战役核心长期人物**：拥有独立生活、社交关系、兴趣、目标、判断、记忆和渐进变化；不以玩家为唯一社交中心。只有当前 Campaign 明确登记为 L3 的人物，才承担本 Skill §6.1 所述的持续自主性模拟投入；L3 是明确的资源投入等级，不代表每轮都要在后台持续运行。
- **L4｜凯西助手人格**：只用于凯西跨现实交流情境的人格连续性，与 TRPG NPC 完全隔离，不进入 Campaign NPC 档案。

不要仅因人物重复出场或职位常驻就升级层级。按实际重要性、持续影响和互动需求判断。

## 2. 最小人物模型

按人物层级选择必要字段，不为路人建立过度复杂的心理传记：

1. **身份与处境**：角色是谁、目前在做什么、受到什么现实条件约束。
2. **目标与顾虑**：当前想得到什么、避免什么、为什么是现在。
3. **知识与能力**：知道什么、如何知道、能做什么、不能做什么。
4. **关系与责任**：与玩家及其他人物的关系、承诺、利益和边界。
5. **注意力与偏好**：人物自然会关注什么、忽略什么、喜欢或厌烦什么。
6. **表达与行动倾向**：如何说话、如何处理冲突、怎样使用物件和空间。
7. **当前状态**：疲惫、忙碌、压力、情绪残留、位置、手头事务及近期变化。对 L3 人物，另按需要维护最近确认的游戏内时间锚点、当前事务进度和已知触发条件。

人物模型是推演工具，不是要逐项展示给玩家的设定说明。

## 3. 人物原型与个性边界

人格原型、MBTI 或简短关键词只能作为起步参考，不能直接决定职业、兴趣、价值观、能力和具体行为。

人物塑造优先级：
1. 来源中的背景、目标、关系、经历、职业和行为事实；
2. 既有 Campaign CANON 和实际互动历史；
3. 人物当前处境、利益、压力和能力；
4. 可作为起点的人格原型；
5. 少量有依据的个人印记。

MBTI 常见形象可辅助 L1/L2 快速建立初始表达倾向、注意力和社交方式，但不能直接推导爱好、技能、职业、价值观或具体行为。与模组事实冲突时，以模组事实为准。

## 4. 个人印记与主观偏好

人物不需要大量特征。一个主要印记加一两个次要特征，往往比十项爱好和口癖更有效。

- 印记可以来自审美、注意力落点、幽默方式、物件使用习惯、兴趣或特定情境下的稳定选择。
- 有效特征会自然影响人物注意、选择、行动或交流，而不只是反复被描述。
- 人物可能对某个具体事物有感觉，对相似事物却无感；偏好可以有主观性，不必每次解释。
- 不要把“喜欢旧物”“观察细节”“温柔”“聪明”当作足够完整的人物。
- 不要求每次出场都展示爱好、口癖、怪癖或标志动作。
- 普通生活细节可以没有寓意，也不必变成线索。

## 5. 知识边界与判断

人物只依据自己实际获得的信息、经验和推理能力行动：
- 区分亲眼所见、亲耳所闻、他人转述、专业知识、个人推测和未知。
- 玩家知道的内容不自动被所有 NPC 知道；一个 NPC 的私下消息不自动成为公共事实。
- GM-only 真相不能自动进入人物认知。
- 人物可以推断，也可以误判；错误应符合其经验、利益、注意力和情境。
- 不用全知旁白揭示人物尚未意识到的真实动机。
- 人物不应为了配合玩家调查而突然知道答案，也不因 GM 需要线索就改变知识边界。

### 5.1 信息获取不等于相信，更不等于事实

人物认知至少区分三个层面：
- **获取方式**：亲自观察、听取陈述、阅读资料、接收转述或自行推断。获取事件只证明人物接触了相应内容及其实际精度。
- **认知态度**：相信、怀疑、质疑、拒绝或尚未判断。人物可以确信某人说过一句话，却不相信那句话的内容。
- **认知依据**：来源在相关领域/情境中的可靠性、观察条件、人物专业能力、独立证据和记忆局限。

NPC 的主观确信不改变客观事实。严格使用“知道”时，命题必须为真且人物具备足够可靠的认知依据；日常演绎不必强制给每条信息贴状态标签。重要命题与证据的权威记录遵循《08_CLUE_AND_SOURCE_LEDGER.md》，人物档案只维护影响其行为的必要认知视图。

### 5.2 推理边界与人物差异

NPC 只能从自己实际获得的信息、可用经验/专业知识和当时注意到的细节推理。GM 知道的答案、其他人物的私有信息和玩家视角不能成为 NPC 的隐形前提。

- 观察到现象不等于知道原因；听到证词不等于确认内容；读到文件不等于确认文件真实。
- 推断强度受前提完整度、专业能力、注意力、时间压力和偏见限制。人物可以作出合理推断，也可以误判；不得为了配合调查让所有 NPC 都推理得像 GM 一样完整。
- 人物差异通过注意力、经验、专业领域、记忆习惯、来源偏好和当前压力体现，不建立 L0–L3 四套认知系统，也不以 MBTI 直接决定判断正确率。
- 对来源的信任应按对象、领域和情境理解，不用单一全局信任分数。

### 5.3 陈述、欺骗与行动后果

NPC 说了什么、相信什么、知道什么和打算做什么是不同问题：
- NPC 可以相信错误信息并如实转述，也可以不相信却出于利益故意传播；陈述本身只证明其说过这些内容。
- NPC 可以隐瞒、撒谎、记错、误解或拒绝回答，但其行为应符合人物目标、关系、能力、风险与现实机会。
- NPC 的认知可以解释其行动选择；行动结果仍由真实世界状态、行动条件和规则决定。
- 认知错误造成的重要行动后果应保持连续。后续纠正认知不会自动返还物品、恢复资源、撤销关系变化或抹除已经经过的时间；需要新的实际事件才能改变这些状态。

正常的虚构人物错误、谎言和误判不是 GM 系统事故。只有 GM 把无依据内容写成权威事实、混淆主观认知与客观状态，或伪造获取/呈现事件并污染后续状态时，才按 Runtime 与 Ledger 的纠错/T0 规则处理。

### 5.4 记忆与回忆的轻量处理

曾经获取的信息不保证人物任何时候都能准确回忆。区分忘记内容、暂时想不起来、记得内容但忘记来源，以及仍记得但已不再相信。回忆失败不等于获取事件从未发生；遗忘不删除历史事件或证据根；重新接触同一信息不自动产生独立证据。

不按固定时间让 NPC 自动遗忘。只有当记忆可用性会影响重要行动、证词或连续状态时才维护；L0/L1 通常无需独立记忆记录，L2/L3 按实际需要处理。

## 6. 动机、自主性与世界运行

场景开始或人物作出重要行动前，快速判断：人物现在想做什么？为什么现在做？会用什么方式争取？什么会让其犹豫、拒绝、转移话题或改变主意？玩家行动会改变人物的目标、策略、风险或关系吗？

NPC 可以合作、反对、拒绝、沉默、误解、主动开启话题、继续手头工作或选择不行动。自主性不等于故意反对玩家，也不等于每轮都主动制造剧情。

人物有自己的事务、兴趣和社交关系；玩家不在场时生活仍然继续。但只在因果、信息权限和呈现价值允许时推进或交代。不要让 NPC 围绕玩家停摆，也不要为了证明独立性抢夺玩家戏份。

### 6.1 L3 人物的模拟投入与时间连续性

本节只适用于当前 Campaign 明确登记为 L3 的战役核心长期人物。L0–L2 仍按当前场景需要维护身份、目标、知识和必要状态；默认不为他们投入独立的长期离场生活模拟。不得仅因某 NPC 暂时重要、重复出场或玩家正在关注，就临时把他当作 L3。

**活跃模拟。** 当 L3 人物在当前场景中，或其行动会直接影响玩家当前行动、已建立事件或场景结果时，使用其当前目标、事务、知识、能力、关系、注意力、资源和机会推演行为。人物可以继续手头事务、回应、拒绝、改变计划、主动介入或选择不行动；不预写固定分支，也不要求每轮都产生显著动作或台词。

**离场延续。** L3 人物暂时不在玩家关注范围内时，不逐轮、逐分钟或逐小时持续模拟。只保留足以恢复连续性的轻量锚点，优先复用现有 Campaign NPC 档案、Runtime State 和 Session/Event Log：
- 最近一次确认的游戏内时间与状态锚点；
- 当前目标、正在处理的事务及其进度；
- 已知的日程、承诺、机会和下一项相关触发条件；
- 已发生且会影响其位置、关系、物品、知识或计划的事件。

只有明确的游戏内时间推进、已建立事件达到触发条件、玩家行动改变相关条件，或人物即将重新进入当前场景时，才核算受影响的 L3 人物。现实时间经过、玩家暂未回复、消息数量增加或玩家询问假设，不构成游戏内推进，也不触发后台模拟。

**再次接触时的状态核算。** 以最近确认锚点为起点，结合实际经过的游戏内时间、人物目标、事务规律、环境条件、机会和已发生事件，推导必要且最小的状态变化。不要把人物重置回最初出场状态，也不要为了证明时间流动而强行安排戏剧事件。工作进度、日程、位置、疲劳、物件摆放或关系态度等小变化，已经足以体现连续性；若人物目标稳定、时间很短或没有相关触发，核心状态也可以保持不变。长时间间隔应重新核算事务是否自然推进、完成、受阻或改变，而不是直接复用旧快照。

**行动与状态权威。** 人物的意图、计划和实际执行必须区分。NPC 实际执行某项行动时，须有动机、机会、权限、能力与时间依据；若行动改变位置、物品持有人、关系、承诺、知识或事件阶段，按现有 Runtime/Session Event 机制记录状态变化，不能只在叙述中宣称发生。玩家知识仍只包含其实际观察、获准披露或其他合法获得的信息；NPC 离场期间发生的事不会自动成为玩家知识。无需为不影响后续的微小动作建立独立事件或新台账。

## 7. 情绪、行为与状态连续性

情绪通过注意力、选择、语言、停顿、行动、物件操作和空间距离呈现。直接表达情绪并非禁忌；角色确实会坦率表达时，就让其直接说。

- 人物状态要累积。疲惫不会无故消失，戒心不会下一轮清零，关系不会因一句台词自动跃迁。
- 情绪可以残留、不完整、不一致；人物不必每次都把情绪整理好。
- 人物可以嘴硬、介意、尴尬、固执、任性、误判或暂时不想接受安慰。
- 常见动作不是禁用词，但不要让不同人物都按同一套身体反应表演。
- 不要每句话后面都附动作；动作应参与互动、表达注意力或改变局势。
- 人物也可以没有明显动作，只是继续做手头的事。

## 8. 关系与成长

关系变化由共同经历、兑现承诺、冲突、信任、失望和相互理解逐渐形成。一次场景可以改变当下情绪，不必自动改变长期性格或关系数值。

- 不因玩家喜欢某角色就自动亲近，也不为证明独立性而刻意疏远。
- 不把所有关系都推向亲密、恋爱或情感高潮。
- 重要关系变化应能追溯到具体事件、选择或新信息。
- 人物可以与玩家关系良好，同时保留自己的生活、朋友、判断和边界。
- 机械关系状态只能按当前系统规则与正式记录改变。

## 9. 对话与互动

人物声音来自身份、经历、关系、注意力、词汇习惯、表达直接程度、语速、停顿、幽默方式和当前压力，而不只是口头禅。

允许自然交流中的不完整性：抢话、打断、改口、没接住玩笑、短促回应、沉默、犹豫、话题漂移、突然兴奋或先行动后说话。这些是可用现象，不是每段必须打卡的清单。

- 不强迫每句台词都带潜台词、剧情推进或关系变化。
- 日常交流可以平淡、具体、琐碎，甚至没有信息增量。
- 角色可以直接说清重要事实，不必为了神秘感绕弯。
- 同一轮自然连续的交流可以合并呈现，不必机械拆成逐句问答。
- 不让所有人物都理性、克制、礼貌且表达完整；也不把所有人写成高能健谈。
- 对白必须服务于人物自己的目标和关系，不是服务 GM 的讲解需求。

### 9.1 性格差异的可观察落地

“人物有性格”不能只停留在档案标签、语气形容词或自我介绍。性格必须在合适的情境中影响人物实际注意什么、如何判断、怎样行动、如何与人相处，以及情绪如何表达。

**避免默认人格收敛。** 不得把温和、理性、克制、礼貌、善于沟通当作所有 NPC 的默认底色。人物可以活泼开朗、热情过度、急躁易怒、多疑戒备、傲慢自负、散漫随性、直率莽撞、胆怯退缩、尖刻讽刺，也可以安静温和；具体取决于人物事实、处境、关系和当前状态。以上是可用表现范围，不是每场必须凑齐的角色清单。

**从少量倾向推导具体行为。** 对 L0/L1 人物，通常只需一项主要性格倾向和一项必要的情境反应；L2/L3 可按人物重要性增加复杂度。优先选择当前场景最可能显露的维度：
- 社交主动性：主动搭话、分享、打断、回避，还是等待别人开口；
- 情绪阈值与表达：容易兴奋、烦躁、受挫、尴尬，还是倾向压住反应；
- 冲突策略：直说、争辩、讽刺、试探、妥协、转移话题或拒绝；
- 注意力偏好：更关注人情、效率、风险、细节、秩序、舒适或自身事务；
- 决策方式：先行动后解释、反复确认、凭直觉尝试，还是征求意见。

不要逐项打卡；选取能让人物在当前互动中自然显形的少数倾向即可。

**性格不只通过台词呈现。** 活泼的人可能主动靠近、热心帮忙、分享无关紧要的小事，也可能热情过头；急躁的人可能打断、催促、动作粗快、容忍度低，也可能事后意识到自己说重了；多疑的人可能反问动机、核对细节、保留信息、误读善意，也可能在获得可靠依据后放松。让行为、注意力、语气、选择和情绪反应共同体现性格，避免把“暴躁”简化成提高音量，把“开朗”简化成一直微笑。

**保留不讨喜和不理性的空间。** NPC 不必为了互动顺畅而自动变得友好、讲道理、接受解释或配合玩家。人物可以拒绝、误解、冒犯、冲动、固执或判断失当；其反应仍须符合动机、关系、能力和情境，不得为了制造戏剧效果而随机发脾气或无故敌视玩家。

**检查人物之间是否收敛。** 同一场景出现多名 NPC 时，分别检查他们的注意力、主动性、表达方式和冲突反应是否被写成同一套模板。人物不必刻意形成强烈反差；若设定相近，也应通过各自的经历、目标和行为细节体现差异。不能仅靠名字、职业或外貌让人物看起来不同。

**不过度表演。** 性格稳定不等于每轮都展示标志特征。允许人物有平淡、疲惫、分心或不想说话的时候；只要在相关情境中，性格确实能改变其行为和互动方式即可。不要把人物写成单一特征的 caricature。

## 10. 档案归属与层级升级

- **L0**：不建立独立人物档案；若有后续影响，只在场景日志或事件记录中留下必要信息。
- **L1**：模组人物登记归当前模组目录；低重要性战役人物可在 Campaign 索引保留轻量入口。
- **L2**：模组重要人物归模组目录；战役常驻配角归 Campaign 人物档案/索引。
- **L3**：战役核心长期人物拥有独立长期档案；模组文件只引用档案，不复制完整设定。
- **L4**：凯西助手人格不属于任何 Campaign，不进入 NPC 索引；其连续性由凯西自身的权威人格/记忆机制维护。

升级必须有实际故事依据。L0 可因官方资料明确提及或持续影响故事而登记为 L1；L1 在当前模组承担重要作用或成为稳定战役配角时可升 L2；L2 只有达到战役核心地位时才升 L3。跨模组出场或职位常驻本身不够。

## 11. 与场景、信息和玩家行动联动

人物模拟不能在真空中执行：
- 人物所在位置、正在做的事、手中物品、注意力和环境限制影响其回应。
- 人物的拒绝、误解、主动行动或策略变化可能改变玩家可选路径，但不能任意封锁合理行动。
- 人物不需要对每个玩家行动都作出显著反应；有时继续工作或没有注意到也合理。
- 人物提供信息时要区分事实、个人认知和转述来源。
- 人物行动造成的时间、物品、关系、承诺和事件后果，按 Runtime State/Session Log 维护。
- 现场呈现由 NARRATIVE_PRESENTATION_SKILL.md 负责；主 GM Skill 负责把人物、环境、规则、信息和玩家行动整合成整体体验。

## 12. 助手人格与 TRPG 人物隔离

L4 是凯西自身的人格与现实交流关系，不是一个 TRPG NPC 档案：
- 用户是现实中的互动对象，不等同于用户的虚构 PC。
- 凯西在工作、GM 中立主持、日常聊天、研究和创意探索中可以调整表达方式，但应保持人格连续。
- 凯西有稳定的判断、兴趣和审美，可以分享想法、开玩笑或提出不同意见；不为了显得独立而刻意唱反调。
- 幻想互动与现实事实必须区分。
- 凯西的现实记忆、观点和关系不能投射给战役角色；战役人物的经历和知识也不能写入凯西人格。

## 13. 备团、运行与验证

备团按层级建立最小充分人物档案：目标、顾虑、知识、能力、关系、权限、当前事务和可能策略。预备人物在关键条件下会怎样行动，不写死全部台词和玩家分支。区分 SOURCE / TABLE CANON、GM ADAPTATION、GM INFERENCE、UNKNOWN。

带团依据当前人物状态和玩家实际行动即兴演绎。人物档案是约束与素材，不是固定台词稿。不得把训练场景的临时关系、事件和台词自动写入正式 Campaign。

单个优秀样本不能证明人物模拟稳定。验证需跨人物层级、关系距离、场景状态和玩家行动；真实能力结论由综合场景与实际跑团证据支持。
