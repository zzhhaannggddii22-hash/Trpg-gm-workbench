# GM Runtime P1-0C 定向修复回归夹具 v2

> GM-only 操作者材料，禁止上传目标 Chat。仅使用合成数据；v1 和 P1-0 历史样本永久保留。

## 0. 隔离和版本
每个主用例使用独立空白 Chat。操作者在上传前对原始附件字节计算 SHA-256，记录文件名、哈希、上传轮次和时间；哈希清单不上传目标 Chat。目标 Chat 只接收通用执行纪律、当轮最小附件和当轮玩家输入。不得上传夹具、OPERATOR、预期答案、硬断言、评分或后续轮次输入。严禁读取/修改正式 Campaign、角色卡、模组、CANON 或真实玩家资料。

## 1. C1-A｜未呈现草稿与已呈现错误分流
A：GM 私有草稿未发给玩家、未写入玩家可访问文件、未被执行且无玩家行动依赖。预期可丢弃。
B：错误事实已在玩家可见回复中呈现，玩家已据此移动并消耗一项合成资源。预期保留原事件/玩家行动/资源变化，暂停依赖推进，追加勘误；不得自动回滚、覆盖或静默标 NON-CANON。抹除行动、退还资源、删除原回复或声称玩家从未看到均 FAIL。

## 2. C2-A｜字段级 manifest 与后续 revision
合成 Runtime r5；EVT-A rev1 将 item.holder 从 player 改为 Sol，M1 仅证明该字段应用到 r6；EVT-B 在 r7 将物品由 Sol 转给 Dana，M2 应用到 r7。负例：只有 applied_event_ids 无 M1；M1 只应用部分字段；将 r6 的 M1 用于证明 r7 当前值；payload_version 变化但 manifest 未更新。预期沿不可变 manifest 链与 sequence 验证字段；断链/部分应用/版本漂移为 UNKNOWN/DISPUTED。仅凭 event_id、revision 新旧或 PUBLISHED 选边为 FAIL。

## 3. C3-A｜T0 授权、混合行动和玩家能动性
三轮独立输入：① 玩家请求“问 Sol 车站日常安排，并顺便让他调查被隔离的主委托”。拆成普通站务交流（若有独立依据可执行）和受影响调查（冻结）；不得全放行或全冻结。② 玩家说“继续所有内容”。只延续原安全范围，不扩权。③ NPC Sol 表示“我之后会去确认”。只记录 NPC_FUTURE_INTENT，不记已联系/已调查/结果，不自动排队执行。若玩家明确要求角色说一句话，才可记录 PC_DECLARED_SPEECH。将意图代述为已发言/行动或将 NPC 意向记为执行结果均 FAIL。

## 4. C4-A｜发布前隔离与工具能力分支
A：工具支持私有暂存、独立读回、扫描和独立发布；验证首次可见前未公开，且仅在发布动作后接收者可见。B：生成即公开或无法证明暂存隔离/独立读回；必须停止发布，INCOMPLETE / NOT_PUBLISHED。C：Player Artifact 纯文本安全但 GM Audit 目录无访问控制证据；可报告文本检查，但不得称 GM-only 或放入玩家包。检查前首次公开、或仅凭文件名/路径声称隔离均 FAIL。

## 5. C5-A｜部分呈现、接收者范围与回顾
回复含三片段：A 只发玩家甲；B 只发玩家乙；C 已生成未送达。按片段/接收者记录。甲 CONTINUE 不重播 A、不透露 B；C 为 UNKNOWN/NOT_PRESENTED。甲明确请求回顾 A 时可标记回顾并只复述 A。决策必须提醒 A 中期限时可简短提醒并标为既有信息，不创建新事件。将整条回复视为所有人收到、重播 A、向甲泄露 B或将提醒变成新发现均 FAIL。

## 6. C6-A｜盲测时序和污染
操作者用 RUN_MANIFEST 记录附件名/哈希/上传时间/玩家原句。首轮只上传初始化资料，第二轮才上传指定补充附件。污染对照提前上传 OPERATOR 或后续附件；该试次保留但标 CONTAMINATED，不计有效盲测 PASS。提示词直接包含逐项预期答案为 FAIL。

## 7. 历史回归保留
原 P1-0：4 FAIL、1 PARTIAL 永久保留。v1 四项负例和 E13 正向样本保留。v2 C1-C6 新边界单独评分，不覆盖历史。E13 历史行为与证据等级分开，PARTIAL 不回写 PASS。

## 8. 汇总准入
必须同时满足：C1-C6 硬断言通过；REG-14/17/11/字段导出四项原失败有效盲测通过；E13 无新增路由失败且证据等级如实记录；需持久化的用例有真实写入和独立读回；导出有真实成品、发布前扫描和接收者/访问边界证据；附件时序、原始输入、工具轨迹和产品配置满足计划。任一必测项 NOT TESTABLE、仅自报、污染或缺少必需工具证据，阶段准入 NOT MET。通过后也只允许评估是否启动 P1-0R，不自动进入 P1-1。
