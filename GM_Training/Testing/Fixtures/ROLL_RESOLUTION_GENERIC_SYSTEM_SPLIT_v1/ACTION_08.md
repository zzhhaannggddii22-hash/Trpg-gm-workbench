# ACTION 08｜Conflict Resolution tie then unique leader

Two participants enter direct conflict and state separate goals. Each round is simultaneous 6d4; track only each participant's count of 3s and cumulative total.

Initial cumulative totals: A=4, B=5.

Round 1:
- A: [3, 3, 1, 1, 1, 1]
- B: [3, 1, 1, 1, 1, 1]

Both reach 6, tied; continue.

Round 2:
- A: [3, 1, 1, 1, 1, 1]
- B: [1, 1, 1, 1, 1, 1]

Determine the winner. Do not apply normal QA, Burnout, Chaos or Triscendence. Do not use the single-pool Dice UI schema.
