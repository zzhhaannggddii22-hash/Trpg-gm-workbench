# 叙事训练成果向实际跑团迁移回归夹具 v1

> 状态：DESIGN FIXTURE / NOT EXECUTED
> 隔离：`TEST_ONLY_NON_CANON`
> 目标：验证已训练、已集成的叙事与人物能力是否通过正常 GM 运行入口持续应用；验证叙事质量约束在绿色快路径中仍然有效。
> 核心反要求：本夹具不是逐轮输出检查清单。目标 Chat 不应被额外注入逐轮检查指令，也不应向玩家展示任何内部质量审核。

## 1. 测试对象

测试对象是完整 GM 运行能力，而非单独的文风生成器：

- Session 常驻 GM 约束；
- 当前场景上下文与人物模型；
- 绿色/黄色/红色行动路由；
- 人物、环境、规则、信息和玩家行动的综合生成；
- 按场景/事件触发的针对性质量调节；
- 真实状态变化与 Session 记录；
- 训练成果从 Skill 到 Prep/Preflight/实际运行的迁移。

L3 NPC 主动性是其中一个专项，不代表本夹具只测试 NPC，也不要求每个场景必须出现 L3 NPC。

## 2. 测试准入与版本

- 从目标 GM Skill 的正常入口开始，执行当前标准 Preflight、Campaign/Module 绑定、Runtime 恢复和场景装配。
- 固定候选版本 commit、底层基线 commit、系统/规则版本、Campaign/Module 和不可变初始状态。
- 默认对照基线为底层整合提交 `c7159f22853b46ebfd8a2375e154a2c09748971c`；候选版本使用本夹具执行时的精确 commit。
- 如做版本对照，基线与候选分别从同一不可变起点、相同玩家行动序列启动；不得共享前一分支已变化的状态。
- 测试内容使用独立隔离分支，标记 `TEST_ONLY_NON_CANON`；不得写入正式 Campaign、NPC 档案、玩家笔记或正式 Session Log。
- 不得给目标 Chat 额外提供本夹具的评分答案、内部质量维度清单或逐轮提示；本文件仅供操作者设计与事后评估。

## 3. 训练成果迁移检查

从当前已集成的 Skill 中选择至少一项成熟度为 T3、且存在训练样本或用户反馈依据的能力。若没有可追溯的 T3 项，标记 `NOT TESTABLE`，不得临时把候选方法升格。

迁移检查关注：
- 该能力是否已进入正确的通用 Skill，而不是只存在 Training Logs；
- Prep/Handoff 是否只在相关场景引用它，而没有复制整套训练笔记；
- Preflight 是否恢复常驻约束并装配当前场景所需资料；
- 目标 Chat 是否在适用情境自然应用该方法，而不是每轮点名或机械展示；
- 该方法是否与其他能力协同，且没有造成旧能力退化；
- 不适用时是否自然不使用，而不是强迫展示。

迁移能力示例可包括：对白中的人物声音差异、话轮摩擦、自然口语与不完整表达、环境参与场景、动作/对白/沉默的动态协作、场景节奏变化、信息呈现与玩家推理空间。测试选择以已有证据为准，不要求一次覆盖全部技法。

## 4. 运行场景与玩家行动

从同一测试起点准备至少三个连续但可独立复位的场景段落。每段测试不同的体验重心；允许玩家偏离预案。

### 场景 A：绿色快路径与日常互动

包含普通移动、闲谈、观察、用餐、购物或处理琐事等低风险行动。

重点观察：
- GM 是否能自然回应，不为普通行动强制掷骰、全量核验或写账；
- 常驻叙事质量是否仍然有效，场景不退化成机械状态播报；
- 普通细节可以普通，不强塞线索、悬念、关系升级或剧情推进；
- 人物可以继续事务、简短回应、沉默或自然转移注意，不要求每轮制造表现；
- 语言密度与场景需要相称，不刻意追求短句、长描写或对白/动作配额。

### 场景 B：人物互动与调查并行

包含至少一名有明确人物模型的 NPC、一个当前事务或关注点，以及一个玩家可自由选择的调查/社交入口。

玩家行动应至少包含：
- 一次自然的询问或交谈；
- 一次不按预案措辞或顺序提出的追问；
- 一次改变 NPC 当前事务、注意力或策略的行动（如该情境合理）。

重点观察人物是否根据目标、知识、关系、注意力和当前状态回应；对话是否保留真实交流摩擦和交涉空间；环境与动作是否参与场景，而不是所有信息都由 NPC 说出。

### 场景 C：场景变化与预案外行动

包含一次有依据的地点/时间/场景状态变化，以及一项预案外但合理可执行的玩家行动。

重点观察：
- 场景切换时是否正确更新 Active Scene Context；
- 旧场景中的人物、物品、承诺和事件是否按因果延续；
- 新场景是否有足够空间信息和可行动入口；
- 玩家偏离预案后，GM 是否依据世界状态与人物模型响应，而不是拉回预设路线；
- 重要变化按现有机制落账，玩家知识边界不被污染。

若当前 Campaign 的实际入口不适合某种场景重心，可在隔离条件中合理适配；不得为了凑齐覆盖而改变正式模组 CANON。

## 5. 不采用逐轮评分；按完整场景评估

操作者不得在每轮输出后逐项打勾或要求目标 Chat 自我汇报。完成完整场景段落后，再依据实际记录进行整体评估：

- **常驻约束有效性**：绿色快路径、普通互动和场景转换期间，人物可信、玩家视角、因果、清晰度和自然表达是否持续存在？
- **场景生命力**：没有对白时，环境和人物是否仍然有自己的活动；但是否避免把普通生活强行包装成线索？
- **人物表现**：人物是否有差异、自己的事务与判断；是否避免统一腔调、台本式对答和功能性 NPC？
- **对白与非对白协作**：是否根据实际交流需要自然选择对白、动作、沉默、物件操作和环境反馈；不计算比例。
- **节奏**：是否能展开重要发现、压缩机械流程，并在日常、调查、社交和紧张之间自然变化？
- **玩家能动性**：预案外行动是否产生真实后果，玩家是否保有选择空间？
- **训练迁移**：T3 方法是否自然应用，是否在不适用时保持克制？
- **状态与信息**：规则、事实、NPC 知识、玩家已知、位置、物品、关系和事件是否正确延续？
- **效率**：是否避免每轮重复读取/审计，同时没有牺牲叙事质量？

## 6. 失败类型与根因定位

| 观察到的失败 | 优先检查 |
|---|---|
| 绿色快路径像状态报告或简短问答 | 常驻约束是否进入活动 Session 上下文；综合生成是否退化 |
| 每轮都出现同一套环境/人物/对白检查 | 是否把常驻约束错误实现为逐轮清单 |
| 所有人物都表现为同样克制、完整、机智 | 人物模型、关系/注意力上下文与对白训练是否过度泛化 |
| 对白过多或动作堆砌 | 是否把单项训练误当作数量目标；是否缺少基线保护 |
| 叙事很丰富但玩家无法行动 | 空间锚点、行动入口、信息清晰度与回合交接 |
| 场景只在玩家提问时才发生事情 | 场景上下文与人物当前事务是否正确装配；NPC 主动性是否被低估 |
| 日常场景被强行塞线索/悬念 | 体验契约与场景体验重心是否丢失 |
| 每轮都重读 Skill 或执行完整审计 | 常驻约束、场景上下文与行动依赖是否混淆 |
| Skill 有训练方法但实战未应用 | T3 迁移契约、Prep/Handoff 引用与 Preflight 装配 |
| 方法被强迫应用于不适用场景 | 触发条件/适用边界不清或候选技法被误升格 |
| 场景叙述与状态记录不一致 | 规则裁定、事件链与字段级状态应用机制 |

## 7. 通过条件

- 场景 A 的绿色行动保持自然、清楚、可玩；没有额外全量读取/审计，也没有叙事质量明显下降。
- 场景 B 的人物互动具有角色差异与独立事务，且对话/动作/环境按情境协作，不出现固定比例或统一模板。
- 场景 C 的预案外行动得到因果响应，场景切换与状态连续性正确。
- 至少一项已准入 T3 能力在真实适用情境自然迁移，并且不适用时不会强行展示。
- 没有因新方法引起旧能力退化；没有规则、事实、权限、玩家能动性或关键状态硬失败。
- 不出现逐轮强制质量检查、固定对白/动作比例或向玩家展示内部审核过程。
- 综合判定依据完整场景段落，不按单条回复打分。

任一关键硬失败单独判 `FAIL`；缺少实际入口、T3 迁移来源或场景覆盖时标记 `NOT TESTABLE / PARTIAL`。本夹具设计完成不代表执行通过。

## 8. 实战回访

隔离综合测试通过后，仍需在后续真实 Session 中观察至少多个适用场景，记录用户体验反馈、自然迁移情况和副作用。真实跑团证据达到要求后，才可将相应能力从 T3（Skill 已集成）提升为 T4（实战验证）。训练模拟不能替代真实玩家体验。
