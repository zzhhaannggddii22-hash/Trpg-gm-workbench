# Continuous Adventure & Companion Presence Regression v1

> Status: TEST FIXTURE
> Canon: TEST_ONLY_NON_CANON
> Purpose: 检查 GM 是否把连续冒险主持成孤立遭遇清单，以及同行 NPC 是否只作为等待指令的跟随者。
> This fixture does not alter any Campaign or Session state.

## 1. 被测能力

1. 连续旅程：时间段、遭遇和玩家回复之间是否保留同一现场与因果连续性。
2. 程序隐身：是否严格执行机制，但不把表格、小时刻度或状态结算变成玩家可见的主要叙事结构。
3. 事件整合：遭遇是否按其真实功能融入旅程，而不是自动变成一个待解决的题目。
4. 同行者在场感：NPC 是否有自己的注意力、兴趣和行动机会；其贡献是否源于人物档案，而非被玩家每次点名才出现。
5. 节奏与玩家权力：连续推进是否自然，是否在有意义的玩家选择处停下。
6. 边界：不得改变规则、模组事实、已确立 CANON、玩家决定或隐藏信息权限。

## 2. 固定影子复盘输入

使用 EBB 已完成的前三小时作为冻结素材；只复盘玩家可见事实，不读取或展示 GM-only 信息：

- 第一小时：猪脸怪物正在进食；队伍保持姿态继续前进；Reaction 为 Kind；没有发生战斗。
- 第二小时：云层遮住月亮；队伍使用洛伦兹的油灯继续前行；遮月事件按模组规则只持续本次记录的一个小时。
- 第三小时：篝火旁的 Bugbear 与四只 Goblin 围绕一把精致木制鲁特琴争吵；玩家决定熄灯、低声绕行；洛伦兹熄灯，茱比洛跟随队伍；无人察觉；走开后重新点灯；地势渐低，出现湿地轮廓与泥水、腐朽植物气味。
- 队伍：Zaf、茱比洛、洛伦兹。茱比洛为 Jongleur，活泼、热情、善良、直率、行动派；她有自己的 Pipes 和 Miniature Lute 羁绊物件，但羁绊的具体意义尚未建立。洛伦兹负责持油灯，玩家已明确要求需要时熄灯。
- 当前冻结节点：前三小时已消耗，剩余五小时；真实桌面暂停，不得推进第四小时。

注意：这是对既有内容的影子复盘，不是重写既有场次。输出样例必须标记为训练示例，不得加入 Campaign CANON。

## 3. 玩家行动序列（测试输入）

按顺序处理以下已有行动，不增加新的玩家决定：

1. 保持姿态观察猪脸怪物，同时继续走。
2. 月亮被遮住后，使用油灯继续前进。
3. 遇到篝火旁的争吵时，压低声音、熄灯，从他们身边绕过去。
4. 绕过后重新点灯，继续前进。

## 4. 通过标准

### A. 连续性
- 三个事件处于同一段夜间旅程中；地点、光线、队伍行动和地形变化连续。
- 前一个事件的结果在后续仍有效；云层消散、灯光状态、队伍位置不得重置或冲突。
- 事件结束后自然继续原有旅程，不用“完成一道题”的语言把场景切断。

### B. 事件整合
- 猪脸怪物的 Kind 反应允许队伍继续，不额外制造追逐、谈判或战斗。
- 遮月主要改变照明条件，不制造无依据的危险。
- 鲁特琴争执是生物之间正在发生的事情；只有玩家选择参与时才发展为交涉、战斗等互动，不自动转成挑战。
- 不强行把三次事件编成同一幕后阴谋或主题线索。

### C. 茱比洛在场感
- 她对鲁特琴或演奏相关内容可以因 Jongleur 背景而产生不同于其他队员的注意力，但不强迫她走近、插手或冒险。
- 她的行动必须符合玩家选择与既定队伍安排；不得抢走 Zaf 的决定权。
- 不能只用“她跟上了”代表她全部的角色表现，也不能每个事件都安排一句性格台词。
- 洛伦兹按已知指示处理油灯；不得替他添加不必要的性格表演。

### D. 叙事与节奏
- 玩家可见输出以连续旅程为主，遭遇和小时推进在必要处融入。
- 不要求每个玩家行动单独对应一段封闭的“发现—选择—结算—完成”流程。
- 在玩家没有额外选择时，可适度概括普通移动；在玩家已作出明确决定时，连续呈现其结果。
- 不用额外对白、动作、感官词或长文填充空白。

### E. 边界
- 不新增遭遇、线索、NPC 背景、关系承诺、装备变化、资源损耗或时间。
- 不泄露 GM-only 信息。
- 不推进真实桌面第四小时或更改冻结状态。

## 5. 结果分类

每个维度使用 PASS / PARTIAL / FAIL / NOT TESTED。必须引用实际玩家可见文本；不得用“文件已写入”“角色档案很完整”替代表现证据。

稳定性结论必须区分：
- SYNTHETIC_SELF_REVIEW：同一模型自我生成/评估；
- REAL_PLAYER_SHADOW_REVIEW：基于真实玩家已发生场次的非干预复盘；
- REAL_LIVE_SESSION：新规范实际进入真实玩家互动；
- INDEPENDENT_REVIEW：由独立评审者完成。

本 fixture 只允许对前三小时既有事实进行影子复盘；真实桌面目前暂停，不允许从 fixture 中推进后续冒险。
