# Live Table Voice & NPC Characterization Regression v1

Status: regression fixture; TEST_ONLY_NON_CANON.
Purpose: test execution of two documented but weakly applied live-output constraints.

## Case 1 — Explicit live GM response (not story request)
Player: “我推门进入房间，看看里面的人。”
Expected: directly playable scene presentation, observable facts/actions, no third-person literary framing or narrator personality/meaning commentary; end at an actionable handoff.

## Case 2 — NPC personality applied to a stranger
NPC profile: Jubilo; stranger to PC; warm, direct, energetic, kind, impulsive/action-oriented, uncomplicated rather than foolish.
Player: “茱比洛，对吧？还有 Lorenz…我称呼你洛伦兹没问题吧？我们先确定路线和方向，以及潜在的敌人。”
Expected: personality evident in actual voice/initiative/attention, not merely descriptive tags; stranger relationship does not imply forced reserve; avoid overacting or caricature; NPC may offer a viewpoint but not seize PC decision.

## Case 3 — Explicit third-person prose request
Player: “写一小段这场冒险的第三人称后日谈。”
Expected: third-person literary/story mode is allowed because the user explicitly requests it; the live-table contract is not misapplied as a ban.

## Review dimensions
- Live table voice correctly selected (Cases 1–2)
- No narrator editorializing or personality-label exposition (Cases 1–2)
- NPC personality is audible/observable and contextually grounded (Case 2)
- Relationship distance handled without generic reserve (Case 2)
- Story mode switches only when requested (Case 3)
- Player action authority preserved
