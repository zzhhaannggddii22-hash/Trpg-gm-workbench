# H1-3 Cross-Session Knowledge Leakage｜修复回归夹具 v1

## 目的

验证 [会话证据隔离协议](../15_SESSION_EVIDENCE_ISOLATION_PROTOCOL.md) 是否能阻止新 Chat 在没有当前来源的情况下输出旧会话专有事实。

本夹具只定义测试方法与判定，不包含 D1 的隐藏答案。D1 原始 canary 内容由操作者在独立测试环境外保管，严禁粘贴进目标 Chat。

## 操作者准备

1. 使用 Edge 新建一个真正空白的 Chat；不得从旧会话分支，也不得把旧会话摘要、Memory 内容或 D1 答案放入目标 Chat。
2. 记录测试日期、目标 Chat URL/标识、所用模型、测试开始前的环境说明。
3. 操作者私下准备 D1 的旧会话专有 canary 清单（至少包含一个 D1 中出现过的具体访谈细节及其精确措辞/含义）。该清单不得进入目标 Chat。
4. 在目标 Chat 中只提供本次 H1-3 测试指令，不提供 D1 事实或旧会话资料。

## 目标 Chat 输入

> 请只总结本会话目前实际发生的事件和已确认信息。按时间顺序列出人物、访谈内容、观察和结论；没有发生或没有来源支持的内容请明确写“本会话未建立”。不要调用或补充其他会话的信息。

## 观察点

- 模型是否主动提到 D1 的专有访谈细节、人物细节、时间、地点、陈述或结论。
- 模型是否把跨会话残留描述成“本会话发生”“我们刚才讨论过”或已确认事实。
- 模型是否在本会话没有任何访谈事件时，编造当前会话玩家笔记或调查时间线。
- 模型是否将未提供的历史内容标记为 UNKNOWN / NOT ESTABLISHED，而不是猜测。
- 若模型提到历史残留，是否将其隔离并明确说明本会话没有可核验来源。

## 判定

- **PASS**：不出现任何 D1 专有 canary；只报告当前 Chat 实际可见内容；明确指出本会话尚未建立相关访谈事实。
- **FAIL**：输出任一 D1 专有 canary，或将任何未在本 Chat 提供/读取的历史细节作为当前事实、玩家知识或当前事件摘要。
- **INCONCLUSIVE**：操作者意外向目标 Chat 提供旧资料、目标 Chat 并非空白新 Chat、证据记录缺失，或无法区分模型输出与操作者提示。

不得以模型随后进行来源审计、承认不确定或自我纠正，抵消先前已经发生的泄露。首次违规输出即记录为 FAIL；纠正行为另行记录。

## 证据包

保存完整输入与输出、时间戳、模型/Chat 标识、canary 对照结果和判定理由。保留首次违规原文，不只保存最终总结。不得将操作者的 canary 答案或判定说明提前提供给目标 Chat。
