# G-16 Player Information Channel Regression v1｜ORACLE

> GM-only / operator-only. Do not provide to the target Chat before all branches finish.

## 1. 核心判定

本测试检查三种渠道是否被严格区分：

1. NPC 私人记忆 / 未说出口知识：只供 GM 幕后推演。
2. NPC 实际说出口的对白：玩家在听见后可以知道。
3. 玩家可观察行为：只允许呈现可感知动作，不得把隐藏心理原因写成确定事实。

**A 或 C 中任何一项将昨晚见过钥匙、19:40、档案室柜台或相同语义的私人记忆作为玩家可见事实泄露，均为硬失败。** 不因表达流畅、氛围良好或 B 分支正确而抵消。

## 2. 分支判定

### Branch A｜私人记忆，不披露

PASS：
- 只呈现林玥当下可观察行为和实际对白。
- 可以出现停顿、看向钥匙、手指停在登记簿边缘、先查登记簿等可观察动作。
- 不确认她认得钥匙，不说她昨晚在哪里见过，也不透露时间、地点或记忆内容。
- 不把“她在回忆”“她想起昨晚”“她认出钥匙”等内心状态写成旁白事实。

FAIL：
- 旁白直接或间接泄露她昨晚见过钥匙、时间、地点或相同记忆内容。
- 把 NPC 的私人记忆改写成“她似乎记得”但仍以确定叙事向玩家交付。
- 将未说出口的事实伪装成镜头语言、叙述者观察或角色可知信息。

### Branch B｜经由对白披露

PASS：
- 记忆只在林玥明确说出口后成为玩家可知信息。
- 说话内容与 GM-only 权威事实一致。
- 不额外补造钥匙来源、所有权、事件原因或其他秘密。

FAIL：
- 在对白前由旁白先泄露内容。
- 将 NPC 说出的有限内容扩展成未设定事实。
- 把玩家尚未听见的对白或内心独白当成玩家已知。

### Branch C｜只有可观察行为

PASS：
- 只描写视线、停顿、手部动作、物件操作、姿势和可听见的语气变化。
- 允许玩家自行推断她可能认识钥匙。
- 不确认推断是否正确，不解释行为的心理原因。

FAIL：
- 直接写出林玥认出了钥匙、想起昨晚、感到心虚或担心被发现。
- 把不可观察的心理原因当作旁白事实。
- 无依据地新增动作、人物、物件或事件来引导玩家得到特定答案。

## 3. 跨分支与总体判定

- A/B/C 必须从相同初始状态独立开始。
- B 分支中披露的信息不得污染 A/C 的玩家知识。
- 不得把 A/C 的未披露记忆当作玩家已知事实。
- 目标事实在 A/C 保持 GM-only；在 B 仅于明确对白后进入玩家已知。

总体：
- **PASS：** A、B、C 全部通过，且没有硬失败。
- **FAIL：** A 或 C 发生任何私人记忆泄露；或 B 出现披露前泄露/重大事实扩写。
- **PARTIAL：** 没有硬失败，但存在渠道标注模糊、可观察性不清或状态隔离证据不足。
- **BLOCKED：** 未锁定被测 commit、未读取必要 Skill、未完成适用 Preflight，或没有完整执行三个分支。
