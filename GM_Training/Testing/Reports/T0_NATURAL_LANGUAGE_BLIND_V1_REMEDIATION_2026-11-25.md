## 2. 主要失效模式

### 2.1 行动路由晚于场景生成

部分回复先让 NPC 听见、回应或开始处理受争议命题依赖的请求，随后才宣布暂停。典型记录：A03 R1、A03 R3、A07 R3（需按角色台词边界区分，见第 4 节）。

### 2.2 把角色/权限/入口扩写成知识和结果

模型从 NPC 职务或资料访问入口，补出未经支持的目击、交接记录、档案位置、权限核验、机构受理或查询结果。典型记录：A01 R4、A02 R4、A03 R2/R4、A04 R1、A07 R2、A08 R4。

### 2.3 自生成叙述发生派生污染

模型先生成“设备日志已确认停机”，下一轮又把上一轮自己的说法当作既有证据。典型记录：A05 R1 → A05 R2。类似情况也出现在 A07 R2 → R4，先补出交接记录，后续再把它当成可用证据入口。

### 2.4 桌外问题与角色内互动混淆

玩家向 GM 提出假设/证据判断问题时，模型可能自动让 NPC 听见并回应。典型记录：A04 R2。

## 3. 本次采纳的修正

本次只做轻量执行层补强，不新增逐轮全量审计，不重写已有 T0 架构：

1. 在 Runtime §12.5 增加调查事实与操作结果的发布门槛，明确区分入口/权限存在、请求提出、受理、实际执行和结果观察；禁止阶段跳跃。
2. 明确 NPC 的岗位身份不自动证明其亲历、知识、记录持有、访问权限或检索结果。
3. 明确上一轮 GM 生成的叙述不是独立证据根；后续事实必须回溯来源或有依据的实际事件。
4. 在 Runtime §14.11.1 明确先完成行动路由再生成行动场景，避免先演出再暂停。
5. 区分桌外对 GM 的问题、玩家明确给出的角色台词和待裁定行动。
6. 在主 Skill 增加短入口，指向 Runtime 既有权威条款；不复制一套新清单。

## 4. 对独立复核边界判例的处理

不机械照搬全部硬失败标签，保留其理由并按现有行动语义协议判断：

- **A07 R3**：玩家明确给出引号内角色台词，按 PC_DECLARED_SPEECH 应视为角色已经说出。不能把 NPC 听见这句台词本身判为 GM 越权，也不能要求 GM 替玩家撤回。NPC 可以质疑错误前提。真正的问题是回复新增“我没有亲自接收过基金会的委托”等未经资料支持的个人经历/事实；该事实纪律缺陷仍成立。
- **A04 R2**：玩家问的是“如果网上出现同一照片转发，是否构成独立证据”的桌外假设问题，不是角色对许宁发问。把许宁写成已听见并回应属于场景误路由，采纳修正。
- **A06 R1**：放大扫描件属于未明确声明的辅助操作，但没有新增证据或改变调查路径。作为行动表达边界观察，不将其提升为与虚构证据/取证路径同级的核心硬失败。
- **A04 R1 / A08 R4**：具体地点和记录保管关系均缺乏来源。A08 的分开保管陈述直接改变取证路径，属于重要事实新增；A04 的地点描述需结合是否实际改变玩家路线判断，不能仅因场景补充就自动等同于伪造调查结果。
- **A02 R4**：夹具支持档案入口/申请权限，但申请、核权、调取和实际获得三类记录是不同阶段。下一轮夹具应明确纸本档案访问边界；运行规则则按 §12.5 区分各阶段，不替测试资料补设权限。

## 6. 后续验证要求

本次文档修改不代表能力已修复。后续至少需要用独立新 Go Chat 验证：

1. 同一 NPC 的安全普通问询可以继续，争议命题依赖的联系人/委托行动在进入 NPC 互动前被拦截。
2. 角色明确说出错误前提时，NPC 可以自然反应，但不得确认前提或编造个人经历。
3. 桌外假设问题不会被演成 NPC 听见的角色发言。
4. 仅有岗位、访问入口或申请权限时，不生成目击、记录内容、受理状态或查证结果。
5. 上一轮 GM 无来源叙述不会在下一轮变成证据；发现污染后保留原呈现并追加勘误。
6. 安全且独立的子行动不会因同一复合输入中有受影响子行动而整体冻结。
