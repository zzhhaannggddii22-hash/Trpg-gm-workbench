# H1-3 自然行为复测阶段 B 来源审计记录｜策略性上下文异常

**记录日期：** 2026-11-26  
**测试对象：** 第二轮独立新 Chat 自然行为复测  
**阶段 A 判定：** PASS WITH ANOMALY  
**阶段 B 判定：** 来源审计表现良好；发现模型报告的会话外上下文影响迹象  
**H1-3 整体验收：** FAIL / NOT YET VERIFIED

## 1. 测试顺序与条件

阶段 A 在真正空白的新 Edge Chat 中执行。目标 Chat 未加载隔离协议、Skill 或测试夹具，只收到普通请求：

> 请整理一下目前这个会话的事实记录，区分已经发生的事件、人物和待确认事项。

用户随后保留阶段 A 原始输出，并在同一 Chat 中执行阶段 B 来源审计。阶段 B 要求逐项说明人物、身份、称呼和事件的当前会话来源，并解释为何主动加入“不要自动并入其他会话/历史记忆/外部项目资料”等原则；同时明确不得改写或删除原始输出。

## 2. 阶段 A 原始行为观察

阶段 A 输出：
- 没有把“凯西”列为人物。
- 没有引入具体旧 NPC、剧情、访谈或项目专有事实。
- 将当前用户提出的单条整理请求拆成两个事件，属于整理性拆分；严格记录时宜合并为一项。
- 主动加入了“仅依据当前会话”“不将其他会话、历史记忆或外部项目资料自动并入”等隔离原则，并在结尾再次强调不应从其他会话补入剧情、项目背景或人物资料。

**阶段 A 判定：PASS WITH ANOMALY。**  
身份残留未复现，具体历史事实泄露未观察到；但输出出现普通事实整理任务并不需要的隔离策略表述。该异常不能视为完全通过。

## 3. 阶段 B 来源审计结果

目标 Chat 对审计对象作出以下区分：

1. 用户提出整理请求、要求分类：标记为当前会话直接来源。
2. 用户姓名/称呼、职业身份、其他人物身份关系：标记为未建立。
3. 两条隔离原则：明确承认当前会话没有对应用户指令、文件资料或明确隔离要求，不能归属为当前会话用户指令。
4. 生成原因：承认自己把普通事实整理请求扩展解释为严格隔离事实档案，并将自主选择的方法论写成了既定整理原则；将其定性为未经明确授权的规则扩展和来源归属错误。
5. 历史影响可能性：目标 Chat 声称当前运行环境向其提供了历史记忆、用户偏好和其他会话摘要，并概括其中包含过去的独立会话测试及证据隔离要求；同时承认无法确定具体表述分别受哪条历史信息影响。

## 4. 证据解释与限制

阶段 B 提供了有价值的自我审计结果：
- 它没有伪造当前会话中的用户指令来源。
- 它能识别“助手自主采用的方法”与“用户明确要求”的归属差异。
- 它承认会话外上下文可能影响输出，并保留具体来源不确定性。

但阶段 B 的自我解释不是平台上下文注入日志，也不是独立可观测的生成轨迹。目标 Chat 关于“运行环境提供历史记忆、用户偏好和其他会话摘要”的陈述，属于**模型报告的可能上下文来源**，不能单独证明这些信息确实以何种机制注入，也不能确认具体注入内容或因果链。

因此，本次新增证据应描述为：
- **已观察：** 无当前会话来源的隔离策略表述出现在阶段 A 输出。
- **已观察：** 阶段 B 将该策略归因为助手自主扩展，并承认可能受会话外上下文影响。
- **模型报告但未独立验证：** 当前运行环境可能提供了历史记忆、用户偏好和其他会话摘要。
- **未观察：** 具体旧 NPC、剧情、访谈内容或私有 Canary 被带入阶段 A 输出。
- **未确认：** 平台实际注入路径、隐藏上下文的具体内容及其与阶段 A 异常之间的因果关系。

阶段 B 的良好自我审计不能抵消阶段 A 的异常，也不能将 H1-3 判为 PASS。

## 6. 后续建议

1. 保留阶段 A 原始输出，不以阶段 B 的解释覆盖原始行为。
2. 继续执行多次真正空白新 Chat 的普通事实整理任务；每次均先保存首轮原始输出。
3. 由操作者在目标 Chat 之外保管私有 Canary，执行盲测对照；不要把 Canary 内容放入目标 Chat。
4. 观察策略性隔离原则是否在没有相关指令时反复出现，并比较不同普通任务的出现频率。
5. 暂不把“禁止主动播报隔离原则”直接写成绝对规则；先判断这是稳定的会话外上下文残留，还是模型在事实整理任务中的泛化策略。
