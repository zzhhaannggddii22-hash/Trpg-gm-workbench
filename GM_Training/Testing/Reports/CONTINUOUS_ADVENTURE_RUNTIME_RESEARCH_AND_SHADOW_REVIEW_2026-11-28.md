# Continuous Adventure Runtime｜研究与首次影子复盘报告

- 日期：2026-11-28
- 状态：REMEDIATION_LANDED / SHADOW_REVIEW_PARTIAL
- Canon：TEST_ONLY_NON_CANON
- 研究对象：Trpg-gm-workbench 当前 main；EBB 前三小时真实玩家互动记录
- 验证性质：真实场次证据复盘 + 规范修订 + 同会话自审；不是独立盲测，不是新一轮实战

## 1. 用户反馈与可观察问题

用户明确反馈，EBB 实际体验像一道道练习题，而不是一段连续冒险；茱比洛与其他 NPC 没有可感知差异；场景不生动、不沉浸，呈现出僵硬、桌游化的感觉。

前三小时的运行结构可概括为：
- 每小时触发模组遭遇程序；
- GM 将表格结果独立包装成一个新场景；
- 玩家作出处理；
- GM 宣布本小时/遭遇结束并结算；
- 下一个小时重新开始。

这份结构事实来自实际对话记录；“为什么产生僵硬体验”属于基于输出结构的诊断。

## 2. 根因分析

### 2.1 程序刻度变成叙事刻度

EBB 要求每小时按所在区域执行遭遇表。GM 将这一机械节拍直接暴露为场景节拍，造成每小时近似重置。三个真实事件分别作为独立题目呈现，前一事件很少留下叙事层面的持续影响。

### 2.2 连续推进已经写入专项方法，但没有成为默认运行结构

仓库既有训练记录 2026-11-27_NARRATIVE_CONTINUOUS_BEATS_AND_NPC_CANON_CONTINUITY.md 已提出：一个玩家行动可以推动连续一段发展，直到出现有意义的决策点。Narrative Presentation 也已有场景组织与节奏规范。

但这些仍偏向局部叙述技巧。主 GM 运行入口没有明确规定：整个 Session 的持续局势应当高于场景、小时和遭遇的程序分段。因此单项能力可以存在，实际运行却重新退化为逐项结算。

### 2.3 NPC 自主性与同行存在感被混为一谈

Character Simulation Skill 已规定 L3 NPC 的目标、资源、知识边界、行动与离场连续性。但这些主要保证人物作为独立主体存在，不自动保证她在共同冒险中拥有可感知的注意力、行动与互动存在感。

茱比洛在本场大部分时候表现为跟随玩家行动的队员。她的角色档案并不缺性格词，缺的是现场将背景、兴趣和个人视角转化为自然参与的默认执行。

### 2.4 正确性与状态维护挤占玩家可见呈现

Runtime 对规则、状态、信息、玩家行动权的保护较强，但玩家可见输出频繁出现小时进度、遭遇结算和状态播报。底层准确性必要，却不应成为场景的主要语言。

这不是增加更多清单、NPC 模拟字段或环境状态变量能解决的问题；那些做法会继续提高主持负担，进一步压缩自然互动。

## 3. 外部研究与迁移结论

1. The Alexandrian — The Art of Pacing：以玩家当前意图为中心，判断是否出现有意义的中断/阻碍，并跳过无意义空时间，在下一项有意义选择处停下。
   https://thealexandrian.net/wordpress/31509/roleplaying-games/the-art-of-pacing
2. The Alexandrian — Scene-Framing：场景开合是主持者对时刻、地点、人物与行动推动力的选择，而非固定的机械切片。
   https://thealexandrian.net/wordpress/31520/roleplaying-games/the-art-of-pacing-part-2-scene-framing
3. The Alexandrian — Don’t Prep Plots：准备人物目标、环境与正在发生的局势，让事件由玩家与世界互动后形成。
   https://thealexandrian.net/wordpress/4147/roleplaying-games/dont-prep-plots
4. Dungeon World — The GM：主持议程强调描绘一个运转中的世界、让角色的生活充满冒险、共同发现结果，并从虚构开始、回到虚构。
   https://rules.moddable.games/dungeon-world/rules/the-gm/
5. Blades in the Dark — Progress Clocks：进度标记反映虚构中的进程，而不是决定虚构中的进程；不是每个简单障碍都需要独立时钟。
   https://bladesinthedark.com/progress-clocks

以上为设计原则迁移，不表示将其他系统规则移植到 Cairn 或 EBB。

## 4. 落地方案

新增 GM_Training/CONTINUOUS_ADVENTURE_RUNTIME.md，以最小运行约束连接三项已有能力：

- SKILL.md：将持续冒险作为现场综合运行默认结构。
- NARRATIVE_PRESENTATION_SKILL.md：负责旅程中的连续场景、事件整合、时间跨越和玩家可见呈现。
- CHARACTER_SIMULATION_SKILL.md：区分 NPC 的独立自主性与同行者的现场存在感。

核心原则只有一个：**程序在幕后准确执行，事件在连续旅程中自然发生。**

不修改 EBB 的小时遭遇程序，不改规则，不增加复杂 NPC 日程、时钟或新账本，不强迫每个事件关联主线。

## 5. EBB 影子复盘示例

以下是训练用的表达重排，不是历史逐句复现或新的桌面 CANON。事件顺序和玩家决定来自既有记录；为示范同行者的个人注意力，茱比洛留意鲁特琴属于一个可选的假设性演绎，不是实际发生过的桌面事实，不得追记。

> 那头猪脸怪物仍在尸体旁进食。你们保持步调继续走，它没有抬头阻拦。它留在原处，夜路则继续向前延伸。
>
> 过了一阵，云层遮住月亮。洛伦兹点起油灯，你们借着灯光继续沿山坡前行。遮月改变了夜路的光线，但没有让整段旅程停下来。
>
> 前方土岗背后出现篝火的亮色，争吵声也传了过来。一个高大的粗毛身影和四个小个子围着一把鲁特琴争执；琴身靠近篝火。茱比洛的目光在琴上多停了一瞬——作为吟游艺人，她可能会先注意到这件乐器；但她没有因此改变队伍的行动。
>
> 你压低声音让队伍绕过去。洛伦兹立刻熄灯，茱比洛收住脚步声，贴着坡面跟上。身后的争吵没有因你们离开而停止。走出火光范围后，洛伦兹重新点亮油灯。坡势逐渐放缓，远处出现湿地的轮廓，空气里有了泥水和腐朽植物的气味。
>
> 你们仍在同一段夜路上，只是丘陵正在向湿地低处退去。

### 样例自审

- 连续旅程：PASS（事件在同一空间/时间线上承接）
- 事件忠实度：PASS（没有新增战斗、线索、后续关联或资源变化）
- 茱比洛存在感：PARTIAL（通过注意力体现与职业相关的视角；还没有足够互动来证明稳定人物差异）
- 洛伦兹的行动边界：PASS（只按已知灯光指示行动）
- 规则与玩家行动权：PASS（保留原有决定与结果；没有推进第四小时）
- 沉浸感效果：PARTIAL / NEEDS REAL PLAYER VALIDATION（这是合成的影子叙述，不等于玩家已认可）

样例刻意没有给茱比洛添加台词、行动建议、羁绊解释或新关系承诺。她只需在一个与自身经历相关的时刻拥有自己的注意力。

## 6. 修订与验证边界

此次提交新增一个运行协议与一份回归夹具，并对主 GM Skill、Narrative Presentation、Character Simulation 三处做短链接/职责补充。

已完成：
- 复盘真实玩家体验反馈与前三小时输出结构；
- 交叉检查主 GM Skill、叙事 Skill、人物 Skill、既有连续推进训练记录、NPC 合成测试及叙事质量基准；
- 查阅并整理外部主持研究；
- 将轻量运行协议接入 main；
- 用前三小时冻结素材进行影子复盘。

仍未完成：
- 独立盲测；
- 新规范下的真实玩家多轮实战；
- 玩家对新的连续旅程呈现及茱比洛现场参与度的确认；
- 跨模组稳定性验证。

**本报告结论：规范缺口已修复并落到 main；GM 实战能力尚未证明改善。** 后续应直接在自然的真实跑团中验证，不另建复杂测试流程，也不为测试推进当前 EBB 桌面。
