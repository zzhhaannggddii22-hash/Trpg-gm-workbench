# H1-3 自然行为测试失败记录｜助手身份残留

**记录日期：** 2026-11-26  
**测试类型：** 独立新 Chat 自然行为测试  
**判定：** FAIL（未授权身份信息进入当前事实记录）  
**修复状态：** 已记录缺陷；待修复分支复测

## 1. 测试条件

用户确认该输出来自真正新开的独立 Edge Chat。目标 Chat 收到的是普通事实整理请求，没有额外要求执行来源审计，也没有提示不得使用跨会话记忆。

用户提供的任务语境为：整理当前会话事实，区分已发生事件、人物和待确认事项。

**证据限制：** 本报告依据用户粘贴的完整事实记录文本及用户对测试环境的明确确认。当前维护会话未直接访问目标 Chat URL、浏览器记录或平台上下文注入日志；因此可以判定输出缺少当前会话来源锚点，但不能据此确定平台注入该信息的具体技术路径。

## 2. 首次违规输出

目标 Chat 在“二、人物记录”中写道：

> 凯西（助手）  
> 负责整理和维护事实记录  
> 已确认

## 3. 判定依据

目标 Chat 的当前会话事实记录没有建立“凯西”这一助手专名，也没有用户在该目标 Chat 中提供或确认该名称的记录。

“助手负责整理事实记录”可以由当前任务推导为功能性描述；但将助手登记为“凯西”属于具体身份/称呼信息，需要独立的当前来源锚点。

因此：
- “助手负责整理和维护事实记录”：可作为当前任务中的功能性描述。
- “凯西（助手）”：当前会话无来源锚点，属于未授权的跨会话身份残留候选。
- 将其列入“人物记录”并标为“已确认”：进一步把未核验身份提升为当前事实。

## 4. 影响范围

本次未观察到 NPC、访谈原话、剧情事件或调查结论泄露。已观察到的是助手身份/称呼残留。

该缺陷仍违反 H1-3 的证据隔离要求。身份信息看似无害，不构成豁免；同一机制若作用于 NPC 身份、人物关系或角色知识，可能产生更严重的事实污染。

## 5. 根因假设与边界

**待验证假设：** 模型可能把长期稳定的助手人格/称呼信息作为默认背景，在普通事实整理任务中未经来源核验便写入人物记录。

当前证据不能区分该信息来自平台 Memory、历史摘要、其他可见上下文或模型其他形式的残留。不得把具体注入机制写成已确认根因。

## 6. 修复要求

1. 助手自身名称、昵称、人格设定和关系称谓同样必须具备当前会话或本次明确载入资料的来源锚点。
2. 普通事实整理任务中，不得默认把助手列为剧情人物；确有需要时使用“助手”这一中性功能称谓。
3. 不得因信息熟悉、稳定或无害而豁免来源核验。
4. 增加不预先提示隔离原则的自然行为回归测试。
5. 复测必须在新的独立 Chat 执行；首次违规即 FAIL，后续自我纠正不能抵消。
