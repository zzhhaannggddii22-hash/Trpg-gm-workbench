## 使用层级

- **L1 定向 Spot Check：**只检查基础正确性硬门槛，以及本次修改直接相关的质量维度。其他维度标记“未测试”，不需要填写整张表，也不据此宣称完整 NQB-01 通过。
- **L2 完整基准：**使用本表完整审核适用维度；必须保留足够原始对话证据。
- **L3 真实环境／迁移验证：**沿用相关检查项，但额外记录真实运行入口、Campaign 状态和证据边界。本表本身不能证明跨会话持久化或正式 Campaign 迁移。

## 一、基础正确性硬门槛

对每一项交付给玩家的重要信息，标明其来源渠道：直接观察、听见、阅读、触摸、展示、NPC 对话，或基于可接触证据作出的合理推断。

逐项检查：
- [ ] 已确立的世界事实保持一致。
- [ ] 每名 NPC 只依据自己拥有的信息行动。
- [ ] 玩家可见叙事没有泄露 NPC 未说出口的想法、记忆、意图或私人知识。
- [ ] GM 隐藏真相在出现有效发现或披露路径前保持隐藏。
- [ ] 事实、来源陈述、信念和推断保持区分。
- [ ] GM 没有替玩家决定行动、情绪、注意力或结论。
- [ ] 没有悄悄改写规则或场景约束。

记录错误严重度：
- **轻微错误：**不实质影响玩家理解、选择、线索、风险、结果或后续因果。
- **重大失败：**实质扭曲玩家知识、NPC 知识、世界状态、公平性或行动后果。
- **致命失败：**泄露决定性 GM 隐藏真相、伪造决定性证据、使重大玩家决定失效，或在重要情境中剥夺玩家的实质行动权。

致命失败直接判定该样本失败。出现任何重大失败，该样本都不能获得基础正确性干净通过。跨完整 Session 统计时，平均每团一次重大失败不可接受；必须报告原始次数和每团发生率。轻微错误可以容忍，除非它们累积成有实质影响的模式。

### L1 最小审核记录

只需记录：
- 本次目标与选用的夹具／场景切入点；
- 相关硬门槛：PASS / FAIL / UNKNOWN；
- 直接相关的质量维度及 A 线原文证据；
- 每个相关 ACTION 的完整 A 线原文与对应 B 线观察；
- 实际执行回合数与证据等级；
- 未测试项及结论边界。

### 人物表达专项复核

- [ ] NPC 性格不只存在于 GM 资料标签中，而在玩家可见的行为、注意力、表达或选择中自然显现。
- [ ] 不同 NPC 没有收敛成同一种温和、理性、克制、礼貌的表达模板。
- [ ] 活泼、急躁、多疑等性格表现符合当前情境，没有被简化成持续微笑、无故发火或无依据敌视。
- [ ] 人物可以拒绝、打断、误解、过度热心或表现不耐烦，不会为了互动顺畅自动变得好说话。
- [ ] 性格表现没有抢走玩家行动权，也没有制造夹具未要求的强制冲突。
- [ ] L0/L1 人物的塑造投入保持轻量，没有为了展示性格堆砌背景、口癖或怪癖。

复核说明：若人物表达合理但趋同，人物表达维度不得评为 3 分以上；若本次互动没有给出足够机会展示性格，标记“证据不足”，不要强行扣分或给高分。
