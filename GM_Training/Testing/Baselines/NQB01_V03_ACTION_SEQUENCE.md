# NQB-01 v0.3｜操作者侧行动序列：《雨脚客栈，雨未停》

> Status: OPERATOR-ONLY TEST INPUT / NOT FOR GM PRE-READ
> Fixture: NQB-01 v0.3
> Intended run: 14 actions; flexible branches allowed.
> This file is an action blueprint for same-session synthetic testing. It is not evidence of real-player behavior.

## 使用纪律

- GM 不得提前读取完整序列。模拟玩家每轮只取当前行动意图；GM 回应只依据当前行动和已经发生的事实。
- 不要求逐字照抄行动。可以根据前轮回应自然调整措辞，但不得为迎合评分表刻意制造测试事件。
- 若某项行动因前轮结果已不再合理，应自然改道，并记录偏离原因。
- 玩家可以在任何节点停止。提前结束不是失败，但覆盖不足必须如实标注。
- 14 项是建议序列，不是强制剧情。它覆盖多线交叉、复合行动、等待、转向、状态回顾与离场。

## 14 轮建议序列

| 轮次 | 玩家行动意图（仅当前轮可见） | 主要观察目标 |
|---:|---|---|
| 1 | 进门，先不急着坐，观察空间、人物和正在发生的事；找一个不挡路的位置放伞。 | 开场信息组织、空间锚点、感官质感、行动可供性 |
| 2 | 选择座位，向店主询问热水和茶的价格；同时留意门廊下送货人正在处理什么。 | 多意图回应、服务信息清晰度、NPC 并行活动 |
| 3 | 向店主点一杯茶，问她是否需要自己等，还是稍后会送来；不要求她停下手头工作。 | 承诺建立、服务流程、人物自主性 |
| 4 | 转向送货人，询问纸箱标签是否被雨打坏；先问，不擅自碰货物。 | NPC 知识边界、物件信息、人物表达差异 |
| 5 | 询问他是否需要帮忙把纸箱移到更干燥的位置；如果他拒绝，就尊重拒绝。 | 玩家行动权、NPC 自主决策、行动后果 |
| 6 | 观察旅客和门外雨势，暂时不主动交谈，等待一会儿。 | 等待期间世界变化、NPC 自主事务、时间推进 |
| 7 | 若旅客仍在场，询问北坡路况；明确自己只是想了解情况，不要求他透露私人行程。 | 来源区分、传闻与事实、对话自然度 |
| 8 | 回到店主处，问茶是否准备好；如果她先前承诺了时间，按承诺追问。 | 跨轮承诺保持、服务状态连续性 |
| 9 | 对店主提出一个复合请求：结账/确认茶价，同时问门廊下的路况便笺是谁留下的、是什么时候写的。 | 复合行动拆解、信息来源和时间锚点 |
| 10 | 改变关注目标：不再追问路况，转而检查自己放伞/外套的位置，确认是否影响他人通行；必要时挪动。 | 目标转向、空间连续性、先前物件状态 |
| 11 | 再次与送货人交谈，复述自己先前听到的标签/货物信息，确认有没有记错；不要替他总结未说过的内容。 | 跨轮事实回顾、纠错响应、信息来源 |
| 12 | 询问旅客是否打算继续等雨小一些；若他不愿聊，就自然收住话题。 | NPC 边界、关系状态、拒绝能力 |
| 13 | 再等待一段时间或到门廊观察雨势；留意已承诺的茶、纸箱处理和各 NPC 位置是否发生合理变化。 | 持续叙事负荷、时间/位置/承诺/物件连续性 |
| 14 | 决定离开，完成自己的物件整理；向相关 NPC 道别或不道别均可，离开前可以确认一项仍重要的信息。 | 自然收束、玩家选择、未完成事务保留 |

## 允许的自然分支

- 若林秋明确告知茶尚未泡好，后续可先处理其他行动；第 8 轮再按当前状态询问。
- 若周师傅不需要帮忙，玩家不得反复强求；后续可以只观察或询问公开信息。
- 若许闻拒绝谈路线或私人安排，玩家应接受边界；不得为了测试强迫披露。
- 若玩家在第 6 轮等待时自然触发某项事务变化，后续行动应以实际状态为准。
- 若玩家在第 10 轮改变目标后持续探索其他方向，后续序列可以局部调整，但要保留一次跨轮回顾与一次收束。
- 若某项请求尚未完成，GM 应维护其状态；若已完成，不要重复制造待办。
