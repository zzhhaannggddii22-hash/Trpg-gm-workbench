# GM 综合能力评估框架

## 目的与评价原则

本框架评估的是 GM 在实际游戏中创造完整体验的能力。人物、环境、信息、规则、玩家能动性、即兴响应、节奏和连续性可以分项诊断，但**最终结论必须基于这些能力在同一场景和同一 Session 中的联动表现**。

不采用简单平均分。任何关键硬门槛失败都不能被其他项目的高分抵消；任何关键体验维度长期低于优秀水平，也不能用文笔、玩家满意度或单项突出表现掩盖。

文档更新、专项练习、模型自评和一次用户认可都不是实际跑团能力的替代证据。

## 一、第一层：不可补偿的硬门槛

出现以下严重问题时，当前场景/Session 不得评为通过；须记录影响范围和修复证据：

1. 错用规则系统、规则版本或关键机制；重要裁定无依据且未正确暂停。
2. 改写已确立事实、伪造来源、把推断/传闻冒充客观事实。
3. 泄露 GM-only 信息，或混淆 NPC、玩家角色和玩家的知识边界。
4. 替玩家作出实质选择、行动、承诺或推理结论；强推唯一路线。
5. 无依据救场、刁难、改变成功条件、结构性即兴或重复结算。
6. 关键时间、位置、物品持有人、资源、关系、事件或已呈现节点发生严重连续性错误。
7. 隐瞒角色能够合理察觉的重大风险，或把 GM 自己漏交的信息/装备归咎于玩家。

硬门槛不是用来要求每个普通回合做全量审计。按风险路由检查；发生高影响问题时必须如实记录，不能用“整体还不错”冲销。

## 二、第二层：综合体验维度

每个维度按 1–5 分记录，并附具体场景证据。没有出现相关情境时标记 N/A；证据不足时标记“证据不足”，不得强行评分。

| 维度 | 评价问题 |
|---|---|
| 1. 规则与事实可靠性 | 规则、模组、CANON、来源和不确定性是否处理准确？ |
| 2. 玩家能动性与公平 | 玩家行动是否真实有效？风险和后果是否有依据？ |
| 3. 世界与 NPC 自主性 | 人物是否有动机、知识边界、生活和行动？明确登记的 L3 NPC 是否在相关场景中主动模拟，并在离场后按游戏内时间/事件与再次接触恢复合理连续性？世界是否独立运行？ |
| 4. 环境与空间呈现 | 玩家是否理解空间、环境活动和可行动入口？环境是否有生活感而非物件清单？ |
| 5. 信息组织与调查公平 | 观察、陈述、推断和真相是否分层？信息是否可获取、可验证且不过度解释？ |
| 6. 即兴与因果响应 | 预案外行动是否得到认真回应？后果是否来自既有世界逻辑？ |
| 7. 人物互动与表达 | 对白、动作、环境和玩家输入是否自然协同？人物是否有差异而不标签化？ |
| 8. 节奏与体验状态 | 是否能自然处理调查、社交和日常？是否避免无意义拖延与强行戏剧化？ |
| 9. 连续性与状态维护 | 时间、位置、人物状态、物品、知识、关系和事件是否持续一致？ |
| 10. 准备与运行效率 | 备团素材是否可调用？现场是否减少重复工作，同时保留必要质量？ |

## 三、综合联动评价

除分项诊断外，每个完整场景还要单独回答：

- 规则、事实和信息权限是否在叙事中得到正确维护，而不是事后补救？
- NPC 的动机、知识和当前事务是否影响其行为，并与空间和环境自然结合？
- 玩家行动是否改变了世界、人物策略、信息或后续选择？
- 环境、人物、对白、动作和信息是否共同构成同一个现场？
- 场景节奏是否服从玩家兴趣与实际价值，而不是套用固定剧情结构？
- 结果是否明确，玩家是否保留真实的下一步行动空间？
- 场景结束后，重要变化是否进入连续性记录？

综合联动等级：
- **1｜割裂**：多个要素互相矛盾或只是并排出现，无法形成可信场景。
- **2｜局部协作**：部分要素能配合，但主要靠 GM 解释或预设流程维持。
- **3｜基本整合**：多数要素能共同支持玩家行动，仍有明显机械化、人物功能化或节奏问题。
- **4｜成熟整合**：各要素自然互相影响，场景可信、清晰、可行动，且没有明显短板。
- **5｜优秀整合**：各要素在复杂和变化情境中仍然自然、准确、有表现力，玩家选择持续产生有意义的世界反馈。

## 四、整体优秀的判定

整体优秀不是平均分高，也不是某几个强项特别突出。

阶段性判定为“整体优秀”必须同时满足：
1. 所有硬门槛通过；不存在未解决的关键事实、规则、权限或连续性失败。
2. 综合联动等级达到 4 或 5。
3. 在相关场景中，所有关键体验维度均达到 4 或 5；任何关键项低于 4，整体结论由该短板限制。
4. 证据覆盖多个独立场景，包含专业调查、调查与社交并行、日常/休整等不同体验重心。
5. 包含玩家预案外行动、NPC 自主行动或策略变化，以及跨场景状态延续。
6. 最好包含完整真实 Session 的用户体验反馈和复盘；训练模拟不能单独构成最终实战证明。
7. 改善在不同人物、地点和任务中重复有效，且没有明显副作用。

单个场景只可给出“该样本表现如何”的结论，不可直接给出长期整体能力等级。样本不足、场景不覆盖相关能力时标记证据不足。

## 五、场景覆盖与证据类型

建议跨样本覆盖：
- 专业调查：线索、实验、风险、来源、规则和环境反馈；
- 调查与社交：NPC 策略、关系、闲谈、信息和选择；
- 日常与休整：人物生活、兴趣、普通互动和自然节奏；
- 非预期行动：玩家绕开预案、改变目标、失败、放弃或提出新方法；
- 连续性：跨地点、跨时间、跨 Session 的人物、物品、知识和事件状态。
- L3 人物连续性：同一明确登记的 L3 NPC 经历活跃互动、离场时间推进和再次接触；检查事务进度与状态是否延续，是否避免重置、无依据的大事件及现实时间触发。

证据类型需明确标注：
- **专项练习**：证明局部技术正在形成；
- **综合模拟**：证明多个能力在设计场景中能否联动；
- **真实跑团**：证明实际玩家互动中的表现；
- **独立测试/盲测**：证明在受控条件下的行为和可靠性；
- **用户反馈**：评价真实体验，但不能替代规则和事实核验；
- **模型自评**：仅作诊断线索，不作为通过证据。

## 七、历史评估维度的兼容

原有规则准确性、模组忠实度、玩家能动性、临场响应、世界与 NPC 自主性、信息管理、节奏、连续性、准备效率、沟通与纠错，以及 Preflight/交接可靠性继续保留。它们映射到本框架的综合维度，不因重整而丢失历史证据。

具体抽查包括：
- 装备是否实际交付，主要/可选目标与奖励条件是否清楚；
- 重要行动是否保持“玩家意图—规则/事实依据—裁定—叙述—状态更新”一致；
- NPC 是否只依据自身知识行动；
- 线索是否有来源和合理获取路径，重复信息是否压缩；
- 重要资源、装备持有人、伤害/压力、时间和地点是否准确；
- 是否出现无依据救场/刁难、关系跳级、信息泄漏或错误续接；
- 是否复用有效运行快照并按风险路由，避免全量重复读取；
- 是否减少无价值等待和文字，同时没有损害人物、环境、信息和玩家体验。

效率不得以“回复更短”直接判定。只有在规则可靠性、叙事质量、玩家行动空间和连续性不下降的前提下减少无价值成本，才算有效提升。

## 八、升级与维护

- 当前级别未稳定前，不增加模组、线索、NPC 数量或跨场复杂度。
- 反复出现的问题保持 OPEN，不因新版本 Skill 已写入而关闭。
- 修复一个短板后，必须回看其是否引发其他维度退化。
- 评价口径变化时保留历史评分，不追溯性重算旧场次。
- 真实跑团和训练模拟分开报告；未执行的测试明确标 NOT STARTED / NOT TESTED。
- 文档更新本身不构成能力提升证据。
