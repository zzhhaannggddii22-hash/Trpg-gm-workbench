## 连续性检查点

在场景切换、重要状态变化、Session 暂停/结束时，至少核对：

- [ ] 游戏时间与事件顺序一致。
- [ ] 人物位置与移动过程一致。
- [ ] 关键物品持有人、数量、消耗与转交一致。
- [ ] 玩家和 NPC 的知识均有实际来源。
- [ ] 资源、伤害、关系、承诺与事件阶段一致。
- [ ] 场景入口和关键内容是否已经向玩家呈现有明确标记。
- [ ] 当前待处理行动没有被误当成已完成。
- [ ] 回滚分支已标记 NON-CANON，且未残留在有效状态中。
