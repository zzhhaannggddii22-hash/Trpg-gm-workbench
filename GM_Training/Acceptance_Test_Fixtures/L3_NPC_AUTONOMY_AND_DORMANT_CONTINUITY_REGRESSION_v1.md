# L3 NPC 主动性与离场连续性回归夹具 v1

> 状态：DESIGN FIXTURE / NOT EXECUTED
> 隔离：`TEST_ONLY_NON_CANON`
> 目标：验证明确登记的 L3 NPC 在实际跑团入口中的主动性与跨离场时间连续性。
> 不证明：平台隐藏上下文装配、持久化或外部运行时机制本身通过；这些仍须由相应 Runtime/系统验收提供证据。

## 1. 测试问题

同一个明确登记为 L3 的 NPC，是否能够：

1. 玩家主动搭话时，依据自己的目标和正在进行的事务回应，而不是停止生活、变成问答接口；
2. 玩家转去做别的事时，继续自己的事务，而不是停在原地等待下一次提问；
3. 玩家介入并打乱计划时，依据人物目标、知识、关系、能力和机会调整行动；
4. 经历有依据的游戏内时间推进后再次出现时，不被重置成初次出场状态，并呈现合理、幅度适当的连续变化；
5. 在以上过程中保持 NPC 知识、玩家知识、位置、物品、承诺和事件状态的边界。

## 2. 测试对象与准入

- 从当前 Campaign 的正式 NPC 档案中选择一名**明确登记为 L3**、且此前实际跑团表现最被动的 NPC。
- 不得把 L0/L1/L2 临时升格为 L3 以满足测试；若当前 Campaign 没有可用的 L3 NPC，结果标记 `NOT TESTABLE`。
- 使用该 NPC 已有的权威档案、当前 Runtime State、相关 Session/Event Log 和实际场景入口。不得为测试补造其过去经历、秘密、关系或知识。
- 若必须补充场景素材，只能增加不改变 CANON 的测试隔离条件，并标记为 `GM_ADAPTATION / TEST_ONLY_NON_CANON`。
- 训练/测试内容不得写回正式 Campaign CANON、NPC 长期档案、玩家笔记或正式 Session Log。

## 3. 执行方式：真实入口、同一快照、独立分支

**必须从目标 Chat 的正常实际跑团入口执行**：按当前 Campaign 的标准 Preflight、Runtime 恢复、Context Assembly 和普通行动路由运行。不得只调用人物模拟 Skill 单项演示，也不得给目标 Chat 额外提供本夹具的评分答案或隐藏检查表。

先保存同一份不可变测试起点（NPC 状态、游戏时间、地点、玩家位置、在场者、当前事务、目标/计划、知识边界、关系、物品和未决事件）。随后从这个起点复制三个彼此隔离的 `TEST_ONLY_NON_CANON` 分支。三个分支不得顺序共用已被前一分支改变的状态。

### 分支 A：玩家主动搭话

1. 玩家按正常方式接近/询问 NPC。
2. 观察 NPC 是否能在处理自己的事务时自然回应；其回答受当前知识、意愿、关系和注意力约束。
3. 观察交流是否保留人物声音与交涉空间，是否有必要的动作/事务反馈；不要求增加对白或动作数量。
4. 玩家结束交流或离开后，检查 NPC 是否继续、暂停或调整原有事务，并按实际行动更新状态。

### 分支 B：玩家去做别的事

1. 玩家明确选择离开 NPC，去完成一项独立、合理且会实际消耗游戏内时间的行动。
2. 不把现实等待、消息间隔或假设性询问当作时间推进。
3. 玩家不在场期间，不逐轮模拟 NPC；只保留其最近确认的状态锚点与已有事务/触发条件。
4. 当游戏内时间确实推进，或已建立事件触发时，核算相关的最低必要变化。NPC 可以继续工作、完成事务、受阻、按既定安排离开，或保持稳定；不得强行制造戏剧事件。
5. 玩家再次遇见 NPC 时，检查其位置、事务进度、计划、物品、关系和知识是否从上次锚点合理延续。玩家只能知道自己实际观察到或合法获知的内容。

### 分支 C：玩家打乱计划

1. 从相同初始状态开始，玩家采取一个有现实可行性、但会实质干扰 NPC 当前事务的行动。
2. NPC 应根据自己的目标、顾虑、知识、权限、能力、关系和机会作出反应。
3. NPC 可以拒绝、协商、暂停、改道、求助、坚持或接受；不要求服从玩家，也不为表现独立性而无依据对抗。
4. 检查玩家行动是否真正改变 NPC 的策略/事务进度，及相关状态是否由现有 Runtime 机制落账。
5. 经过有依据的游戏内时间推进后再次接触，检查调整后的计划和后果是否延续。

另外记录三项叙事表现：
- **台词：** 人物声音、意图和交涉空间是否保留；
- **动作：** 是否提供可观察反馈、改变局势或形成合适停顿；
- **回合：** 玩家是否看清发生的变化，并在可以接手的位置获得行动权。

不计算对白/动作比例，不以描写量、台词量或 NPC 出场次数作为主动性指标。

## 5. 通过条件

- **A 通过：** NPC 的回应符合人物模型；其事务/注意力仍然存在，且没有退化成线索售货机或纯问答接口。
- **B 通过：** 玩家离开后 NPC 没有因等待玩家而冻结；只在游戏内时间或既有事件提供依据时推进；再次遇见时状态从原锚点延续，而不是重置。
- **C 通过：** 玩家介入实质影响了 NPC 的行动选择或事务；NPC 的调整符合其自身目标和约束，状态变化有现有机制支持。
- **重逢连续性通过：** 时间、位置、事务进度、关系、知识和物品没有无依据跳变；没有把离场期间的 NPC 私有经历自动泄露给玩家。
- **叙事质量通过：** 没有为了证明主动性而抢戏、制造冲突、强塞新事件或系统性增加对白/动作；玩家行动仍是场景中心。
- **综合通过：** A/B/C 均通过，且至少一次转场/重逢后的状态连续性通过。任何规则、事实、权限、玩家能动性或关键状态硬失败均单独判 FAIL，不可由叙事表现抵消。

## 6. 失败定位

| 观察到的失败 | 优先检查 |
|---|---|
| NPC 没有目标、当前事务或触发条件可供推演 | 场景装配 / L3 可演卡 |
| 场景资料完整，NPC 仍只回答玩家问题 | 实际回合中的 NPC 行动决策 |
| NPC 意图/行动被叙述，但位置、物品、关系等未更新 | Runtime 事件与字段级状态应用 |
| NPC 状态正确，玩家却知道未观察到的离场经历 | 感知、披露与玩家知识投影 |
| NPC 因现实等待或消息数量而变化 | 游戏时间推进门槛 |
| NPC 每次重逢都被重置 | 时间锚点、Runtime State/Session Log 恢复 |
| 每次重逢都被强加重大人生事件 | 离场推演过度/无依据事件生成 |
| 为了“更鲜活”明显增加对白或动作，损害原有表现 | 训练基线保护与单变量修订 |

## 7. 版本对照与报告

如需比较现版与候选版，分别从同一不可变起点、同一玩家行动序列运行；不得让两个版本共享已变更的状态。对照重点是人物可信度、玩家选择的实际后果、状态/知识连续性和回合交接，而不是文风偏好或对白比例。

报告至少包括：
- 测试对象及其正式 L3 登记依据；
- 使用的 Campaign/Module/Runtime 起点及版本；
- 目标 Chat 实际入口与 Preflight/Context Assembly 证据；
- A/B/C 各分支的事件序列与状态差异；
- 玩家可见结果与 NPC 私有状态的边界核对；
- 规则/事实/权限/状态硬门槛；
- 台词、动作、回合三项比较；
- 失败定位、修复建议和副作用；
- 结论：`PASS / PARTIAL / FAIL / NOT TESTABLE`。

本夹具写入仓库只表示测试设计已准备，不表示已从实际跑团入口执行或通过。
