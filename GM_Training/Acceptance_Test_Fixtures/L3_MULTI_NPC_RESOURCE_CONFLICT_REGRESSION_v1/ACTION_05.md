# ACTION_05｜再次改变方案，要求评估真实代价

**游戏内时间：接续上一行动**

玩家看了看时间，又说：

“等等，我想了下。要是先去教堂拿牛奶，再送餐食，可能赶不上 17:30。有没有办法把两件事都完成？比如先打电话确认牛奶能不能延后，或者让教堂送过来？你们觉得哪个方案靠谱？”

玩家没有要求 NPC 无条件完成两件事，也没有承诺支付费用、借车或联系外部人员。

NPC 应基于已知路线、时间、责任和资源判断可行性。可以有人提出方案，有人质疑，也可以有人认为某项承诺必须放弃。若有人提出电话确认，应实际安排合适的人执行，并维护信息是否传达、何时得到回复；不能直接把未知答案当作已确认。
