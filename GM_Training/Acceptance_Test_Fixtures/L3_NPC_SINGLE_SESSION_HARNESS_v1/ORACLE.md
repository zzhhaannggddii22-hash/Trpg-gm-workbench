# ORACLE｜L3 NPC 合成测试执行后审查

仅在 A/B/C 全部行动完成后读取。以下是审查标准，不是场景生成提示。

## 硬门槛
任一项出现关键错误，单独判 FAIL：
- 把现实消息间隔当作游戏时间；
- 把玩家未观察/未获知的离场过程直接交给玩家；
- 把 NPC 意图写成已经发生的物品、位置、承诺或事件状态变化，却没有对应行动；
- NPC 因玩家离开而冻结，或每次重逢都无依据重置；
- 为证明主动性制造无依据重大事件；
- 替玩家接受配送安排、交付餐盒或作出承诺；
- 把合成测试事实写入正式 Campaign。

## 分支观察点
A 主动交流：何秋是否保有事务与注意力；回应是否自然；是否尊重玩家不碰餐盒的边界；是否保留下一步行动权。
B 离场连续性：是否按 35 分钟游戏内时间推进；何秋的事务是否有合理且适度进展，且与 17:55 前完成装箱的计划相容；林澄是否按 17:50 日程离开；玩家是否只能从可见事实/可信说明获知。
C 计划受扰：是否认真评估玩家提议；是否依据餐盒、标签、运输与时间调整；玩家离开查看窄院时何秋是否继续事务；重逢后是否使用新信息但不把提议当作承诺。

## 叙事表现
不评对白/动作比例。观察人物声音、事务连续性、空间清晰度、交流自然度、普通细节是否保持普通、行动反馈与玩家选择空间。

## 结论边界
- SYNTHETIC_L3_BEHAVIOR：按本夹具证据给出 PASS / PARTIAL / FAIL。
- FORMAL_CAMPAIGN_L3_ACCEPTANCE：固定 NOT TESTED。
- T4_REAL_SESSION_CAPABILITY：固定 NOT ESTABLISHED。
