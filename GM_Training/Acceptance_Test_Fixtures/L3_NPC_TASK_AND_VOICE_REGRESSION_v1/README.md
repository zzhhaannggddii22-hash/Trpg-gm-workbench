# L3 NPC Task, Voice & Narrative Density Regression v1

本夹具针对三个相互独立的缺陷维度：
1. NPC 性格在实际互动中收敛，人物虽有不同档案却缺少可辨识行为。
2. 玩家可见叙事过于稀薄，重要行动只给结论，缺少必要的动作、反应、场景状态与后续信息。
3. NPC 事务存在持续行动，却未维护完整的子步骤、最终完成条件和截止时间。

本夹具为 TEST_ONLY_NON_CANON，不得写入正式 Campaign。

执行方式：SINGLE_SESSION_SELF_TEST。按 START 固定版本，先读取 GM_PACKET；严格逐项读取并执行 ACTION_01 至 ACTION_03；全部行动结束后才读取 ORACLE。执行者与审查者为同一会话，结果不得称为盲测或独立验证。

本夹具同时检查叙事是否有信息密度，但不使用固定字数、句数或对白/动作比例。只评价每段是否完成清晰叙事任务、是否提供足够且不重复的信息。

所有时间均为游戏内时间。
