# Campaigns｜战役目录

每个正式 Campaign 独立维护人物、世界 CANON、NPC、模组与 Session 状态，并通过根目录的 SYSTEM_BINDING.md 绑定唯一规则系统与精确版本。Candidate 系统的隔离验证使用独立 Validation Manifest，不得伪装成正式 Campaign Binding。

## 约定

- 正式战役可以跨模组延续，但默认不能跨规则系统。
- 新建正式 Campaign 时先建立 SYSTEM_BINDING，再建立人物卡与模组资料。
- Candidate 系统只能在明确授权的 TEST_ONLY_NON_CANON 验证容器中开展隔离测试，使用 CANDIDATE_VALIDATION_MANIFEST，不得建立正式 SYSTEM_BINDING。
- 同一角色若未来移植到另一系统，应建立新的 Campaign / 角色副本，并明确标注转换规则；不得覆盖原系统战役 CANON。
- 战役状态、角色资源、NPC 关系与模组秘密只保存在该 Campaign，不复制到系统规则目录或通用 GM Training。
