# Campaigns｜战役目录

每个 Campaign 独立维护人物、世界 CANON、NPC、模组与 Session 状态，并通过 SYSTEM_BINDING 绑定规则系统与精确版本。系统成熟度与 Campaign 是否获准进入受控运行是两个独立维度。

## 约定
- 正式战役可以跨模组延续，但默认不能跨规则系统。
- 新建 Campaign 时先建立 SYSTEM_BINDING，再建立人物卡与模组资料。
- Candidate 系统的资料恢复不代表系统已通过激活门槛。
- 同一角色移植到另一系统时应建立新的 Campaign/角色副本，不覆盖原系统 CANON。
- 战役状态、角色资源、NPC 关系与模组秘密只保存在对应 Campaign。
