# Campaigns｜战役目录

每个战役独立维护人物、世界 CANON、NPC、模组与 Session 状态。战役目录不拥有规则本体；每个 Campaign 必须通过根目录的 `SYSTEM_BINDING.md` 绑定唯一规则系统与精确版本。

## 当前战役

- [Zarek / 扎雷克](./TA01_Zarek/README.md) — `TA01_Zarek`；绑定 `triangle_agency`，规则版本为《三角机构》中文 v22。

## 约定

- 战役目录命名统一遵循根目录 [CAMPAIGN_NAMING.md](../CAMPAIGN_NAMING.md)。不得按系统随意采用角色名、模组名或世界名作为战役目录名。

- 战役可以跨模组延续，但默认不能跨规则系统。
- 新建 Campaign 时先建立 SYSTEM_BINDING，再建立人物卡与模组资料。
- 同一角色若未来移植到另一系统，应建立新的 Campaign / 角色副本，并明确标注转换规则；不得覆盖原系统战役 CANON。
- 战役状态、角色资源、NPC 关系与模组秘密只保存在该 Campaign，不复制到系统规则目录或通用 GM Training。
