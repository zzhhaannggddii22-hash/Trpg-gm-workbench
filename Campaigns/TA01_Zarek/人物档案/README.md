# 人物档案

- [扎雷克｜正式人物卡](./扎雷克_正式人物卡.md)：Session 边界上的正式状态快照。
- [扎雷克｜当前场次副本](./扎雷克_当前场次副本.md)：《冰淇淋车》历史副本（LEGACY），仅供追溯，不用于新 Session 运行。
- [凯瑟琳｜长期独立角色档案](./凯瑟琳_长期人物档案.md)：NPC 人格、生活、知识边界、关系与连续性。

每场开始时读取正式人物卡作为角色状态快照。Session 中所有资源变化只写入当前模组 Resource Ledger；Session Log 记录事件，Runtime State 只保留必要的场景与关键物品快照，不另建资源流水。每次 Session 结束后，GM 对照 Resource Ledger、Session Log 和规则完成对账，再一次性更新正式人物卡。历史场次副本不得作为当前余额来源，也不得覆盖正式人物卡。

- [机构常驻 NPC 索引](../战役记录/机构常驻NPC索引.md)：跨模组反复出现的机构人员与战役级配角；人物档案集中维护，模组只引用。

- [机构常驻 NPC 索引](../战役记录/机构常驻NPC索引.md)：跨模组反复出现的机构人员与战役级配角；人物档案集中维护，模组只引用。
