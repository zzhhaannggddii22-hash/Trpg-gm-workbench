# 《死寂》｜异常分析（GM-only）

## 正式报告字段

- **Alias：** Dead Quiet / 静默者（工作代号；沿用模组标题）
- **Behavior：**
  - 对噪音高度敏感，追捕社区中制造噪音的来源。
  - 能够吞没/压制声音，令电子设备失声。
  - 能利用被剥离声音的电线形成 Wirelings，并通过混沌效果改变其类型或扩大寂静。
  - 将 Kaye 的安宁需求内化为保护行为；在 Kaye 感到威胁时回应并攻击潜在噪音源。
  - 可将声音与寂静扩展为对区域内生命的致命威胁。
- **Focus：** Kaye Renfield 通过控制周围环境获得安宁的强烈愿望。
- **Domain：** 227 Ashran Drive，Kaye 公寓内的隔音地下室。
