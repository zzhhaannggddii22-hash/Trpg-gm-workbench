- 中文精翻个别位置出现 Jahnavi Reddy / Jahnavi Reddi 拼写差异；英文原书核验前保留为同一实体的待核别名，不创建第二个 NPC。

- 任何新增实体先判断是否 SOURCE、TABLE CANON 或 GM ADAPTATION，再分配 ID。
- 开团前对本表中英文名分别搜索，确保命中同一 ID。
