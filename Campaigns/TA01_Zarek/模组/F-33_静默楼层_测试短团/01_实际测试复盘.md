# Session Review｜F-33《静默楼层》实际 one-shot

- 复盘整理日期：2026-11-19
- 系统：Triangle Agency 中文 v22
- 桌面：1 名玩家特工 + 1 名总经理（GM）
- 模组：原创任务 F-33《静默楼层》
- 状态：已完成实际玩家测试；本文件是事后复盘，不是对原模组的追认或修订。

> **CANON 边界：F-33 仅为 GM 能力测试团，不属于扎雷克正式战役经历。** 用户已决定将扎雷克时间线回退至已加入三角机构、尚未接取第一个任务；《死寂》将成为首个正式任务。本复盘保留为 GM 训练记录，不把其中的奖励、处分、资源消耗、关系变化或世界后果继承到正式战役。
>
> **资料边界：**本复盘依据当前可访问的聊天上下文、玩家明确反馈、已有 Session/GM 资料和项目长期档案整理。没有取得本场历史对话的完整逐字导出，因此不声称逐句重建全部过程。未实际发生的骰子、状态变化或未被玩家看到的秘密，不补写为游戏事实。

## 1. 实际发生的结果（事实记录）

- 玩家调查 Meridian Tower 的员工失踪事件，查阅 HR、安保、物业、维修和财务记录，发现与不存在的第 33 层及 QWF 工作流程相关的异常线索。
- 玩家利用毛线、安保人员的配合和电梯信号异常进入 F-33；在 Domain 内探索走廊、办公室与 QWF 系统。
- 玩家通过喊话提出成为代理主管，发现系统会把该说法转为正式申请；接受临时主管权限后，按三个员工各自的工作单逻辑处理状态。
- 玩家联系妮娅并让她提交离岗申请；罗文与德夫的工作约束也分别被解除。三名员工全部返回实体楼层。
- 玩家与三名员工一起乘电梯撤离。
- 任务结束时，F-33 未被收容或中和，QWF 新受害者流入仍未阻断；异常状态按任务结果记录为仍在活动/逃脱。
- 本场未出现可核实的真实掷骰场景。不得补造 6d4 骰面，也不得假称发生过 QA、Burnout、Chaos 或 Harm 结算。

## 2. 玩家体验反馈（明确反馈）

| 环节 | 玩家评价 | 复盘含义 |
|---|---|---|
| 探索开放办公室 | 还行 | 环境与探索方向成立，但没有形成特别强的体验峰值 |
| 独立办公室查阅资料 | 普通；不太清楚下一步 | 线索可用性或阶段目标感不足，需要检查信息呈现与可选方向 |
| 发现“喊话可以成为申请” | 小高峰；意料之外、情理之中 | 规则与异常逻辑通过环境互动被玩家自行发现，是本场有效设计 |
| 逐份处理文件 | 差 | 已知、重复、机械处理不应拆成大量逐项点击，应以叙事蒙太奇表达 |
| 与妮娅电话交谈 | 普通、平淡合理 | 平淡互动本身可以成立，不必强行制造戏剧冲突 |
| 依次指挥员工到电梯并撤离 | 一般偏差 | 在没有新风险、选择或变化时，重复指令和等待应快进 |
| 整体 | 有潜力，但后半段拖沓 | 主要问题是节奏和信息价值，不等于任务主题或办公室氛围失败 |

玩家认可办公室氛围，不希望每个模组都被改造成地狱般的高压场景。玩家也明确指出，选择误判后产生平淡后果可以接受；不需要 GM 为维持戏剧性暗中救场。

## 3. 有效处理与值得保留的设计

1. **环境探索可以自然带出机制。** “喊话可以成为申请”这一发现是本场最明显的正向体验点：它从玩家尝试与世界沟通而来，不是 GM 直接告知答案。
2. **异常主题具有潜力。** 把行政流程、工作完成、离岗资格和无法结束的任务与异常本体连接，是可继续探索的设计方向。
3. **平淡 NPC 互动无需升级。** 妮娅电话交流普通但合理，不应仅为追求高潮而临时加入危险或反转。
4. **开放路线有价值。** 玩家能通过调查和制度操作逐步改变员工状态；不应把临时主管身份或某一条工作单设计成唯一通关路线。

玩家关于“未完成工作不能离开”“超时后被重置”等想法，是对未来异常设计的例子，不是本场已经建立的 F-33 规则，不能写入本任务 CANON。

## 4. GM 失误与影响

### 4.1 严重装备交接遗漏

角色与备团资料列有以下应交付物品：
- 常规公文包（异常收容工具）；
- 涟漪枪（可中和任务目标异常）；
- R&D 初始补给橡皮鸭（Rubber Duck）。

本场 GM 没有在开场实际交付这三样装备。玩家实际持有的物品以本场已确认记录为准：私人手机、机构工作手机、员工证、便携对讲机，以及后来使用并回收的毛线；没有公文包、涟漪枪或橡皮鸭。

**影响：**这不是玩家忘记使用装备，而是 GM 的准备和交接错误，直接剥夺了玩家选择常规收容/中和路线及使用初始补给的能力。本场不能事后责怪玩家没有中和异常，也不能为修复错误而在结局临时变出装备或回滚场景。

### 4.2 任务目标与可选目标的说明不足

任务目标应清楚区分：调查异常、救出员工、阻止新增受害者、收容/中和异常，以及它们各自的可选奖励条件。虽有玩家简报档案保存了相关文本，但档案中写有不等于 GM 已在本场明确向玩家宣示。当前可访问记录无法证明本场所有目标与可选奖励均已清楚说明。

**影响：**不得事后因玩家完成某个目标而追加此前没有清楚告知的可选奖励；也不得把玩家未选择收容/中和解释为其主动放弃已充分知情的目标。

### 4.3 机械流程占用过多实际互动

逐份处理已知文件、重复下达员工移动指令、等待队伍会合等步骤，没有持续提供新信息、决策或风险。GM 把这些过程拆成多次互动，造成后半段拖沓。

**改进：**只在有新的文件差异、操作选择、风险变化或人物回应时展开；其余用清楚的叙事摘要或蒙太奇推进。快进不等于剥夺选择，玩家仍可随时要求细演或提出新行动。

### 4.4 终端交互的价值不足

玩家希望关键电脑界面能提供可阅读、可操作的真实信息，而不是 GM 只概括结果。本场后来提供了 QWF 界面，但部分文件与已有线索重复，界面交互没有充分产生新发现或新选择。

**改进：**保留重要终端界面的可读性和操作感；每个页面、按钮或文件必须提供独特信息、可执行动作或可验证状态。没有增量价值的重复内容应合并。

### 4.5 奖励结算尚未可靠

此前曾给出总嘉奖 9、处分 3 的结算，但该结果不应直接视为最终 CANON：
- R&D 三项 Sanctioned Behaviors 是否逐项满足规则条件，需要根据实际行动和角色记录复核，不能凭整体印象自动给满额。
- GM 曾自动给出任务报告 +3，但玩家没有实际填写/审阅完整报告；该奖励缺乏可靠依据，不应直接保留。
- 三名员工全部获救这一可选目标虽存在于档案文本中，但本场是否事先清楚公开奖励条件尚未证实，不能事后追加。
- Escaped 的 +3 Demerits 与异常逃脱导致分部 Loose Ends +7 是规则结果；但应与 GM 漏交装备的责任分开记录，不把路线受限归咎于玩家。
- 本场没有真实骰子记录；未核实的 QA、Burnout、Chaos、Harm 与其他数值变化保持待核，不补造。

## 5. 对 GM 能力的阶段判断

- **玩家能动性：**玩家提出“代理主管申请”并自行推导流程，GM 接纳了非预设行动；这是有效处理。
- **世界与规则响应：**工作单与员工状态分别变化的概念有潜力，但实际执行需要更清晰的因果呈现和状态核对。
- **节奏管理：**后半段是明确弱项；需要减少重复操作，把时间留给探索和有意义的选择。
- **准备与执行可靠性：**装备漏交是重大失败，优先级高于叙事润色。
- **任务简报与公平性：**目标和可选奖励必须在行动前清楚说明；GM 不应让玩家承担信息/装备缺失造成的代价。
- **奖励与规则复核：**前次结算过于宽松，当前总奖励不作为已核实最终值。

## 6. 当前玩家偏好假设（供设计与选模组参考，不是永久定论）

- 探索、未知发现和通过观察理解规律是重要乐趣来源。
- 推理更适合作为探索与对抗的辅助工具；不以纯侦探式谜题考试为默认中心。
- 氛围应随模组变化；玩家不要求每次都是高压恐怖或战斗。
- 重要 NPC 对话、环境实验和新机制发现值得展开；机械重复、重复信息和无新选择的来回操作应快进。
- 玩家接受顺利完成的行动，也接受误判产生的平淡后果；不需要 GM 每次制造阻碍或强制戏剧反转。

5. **严格记录规则和奖励。** 没有掷骰就不制造骰面；没有核实的奖励不写成最终数值。
