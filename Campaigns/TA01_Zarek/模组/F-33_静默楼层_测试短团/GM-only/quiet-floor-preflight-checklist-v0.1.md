- [x] 停止新派单、救出单名员工、关闭 QWF、收容、中和、撤退分开追踪。
- [x] 玩家不必担任主管，不必完成全部工作单，不必接受 NPC 方案。
- [x] 玩家可以拒绝电梯、拒绝 Domain、疏散建筑、撤退或提出新方案。
- [x] 返回路径需要可辨认；不使用未预示的永久封出口。
- [x] 涟漪枪非目标用途处分必须在射击前说明。
