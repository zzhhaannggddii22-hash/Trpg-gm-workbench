# GM ONLY｜《静默楼层》单人 One-shot 适配说明 v0.1

> 状态：已按玩家决定采用的桌规；仅适用于本次单特工 one-shot，不是官方规则。
> 设计目的：避免把多人比较与长期成长机制强行套给唯一玩家，同时保持本次任务目标、资源与风险不被暗中软化。

## 1. 适配范围

本次只处理任务评优（Mission Superlatives）。以下内容仍按官方规则执行：
- 6d4、QA、Burnout、Triscendence、Stability、Chaos 与异常能力。
- Harm、Life Insurance、涟漪枪、常规公文包。
- Captured、Neutralized、Escaped 三类任务结果。
- 任务报告奖励、可选目标奖励、最终申诉。
- Loose Ends、Weather Events 与分部状态。

不因只有一名玩家而增加 QA、降低异常强度、删除失败后果或增加 NPC 代打。

## 2. 任务评优适配

官方印刷页 134 的多人评优是 Probation → Mission MVP → Participant，每名特工最多获得一项。本 one-shot 不执行其中依赖多人相对排名的 Probation 与 Mission MVP。

本桌结算：
1. 玩家获得 Participant 参与奖绶带。
2. 玩家可以选择一段关系，使其连接增加 1 点；若角色卡或相关规则对该项存在适用限制，则按具体规则核对。
3. 不授予 Probation，不发放 Red Flag of Disrepute，不触发其异常轨迹额外标记收益。
4. 不授予 Mission MVP，不发放 Socks of Success，不触发其职能轨迹额外标记收益。
5. 该适配不改变任务结果、报告或可选目标奖励。

这是一项玩家已明确选择的 one-shot 桌规，不需要在开团时重复让玩家选择；开团说明中简短告知即可。

## 3. 成长与长期构筑

本次作为 one-shot，不预设第二项任务，不预先分配职业生涯成长，也不为未来战役储存未发生的升级。若玩家日后决定把角色带入长期战役，届时再按完整战役规则重新评估成长与评优；不能把本次适配自动扩展成长期战役规则。

## 4. 公开结算顺序

1. 确定任务结果：Captured / Neutralized / Escaped。
2. 发放任务结果对应的嘉奖／处分。
3. 完成任务报告：完整 +3 或详尽无误 +6，二者不叠加。
4. 结算已公开的可选目标。
5. 进行最终申诉。
6. 按本文件的单人适配处理任务评优：Participant。

## 5. 透明度

GM 必须在任务简报或魔法圈阶段明确说明：本次 one-shot 不进行 Probation / Mission MVP 多人排名，只按 Participant 的关系连接奖励结算。不得等任务结束后才解释，也不得在结算时临时恢复官方多人排名。
