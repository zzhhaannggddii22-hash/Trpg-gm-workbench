# 《俯冲》｜单人桌适配与 Session 计划（GM-only）

## 1. 适配原则

- 系统规则仍以 Triangle Agency 中文 v22 为唯一权威；本文件只记录本桌主持组织方式，不改写规则。
- 扎雷克是唯一玩家特工。凯瑟琳是长期独立 NPC/同行搭档，不是第二名 PC，不获得异常能力、玩家行动经济或主动特工检定。
- 凯瑟琳保留用户授予的 9 QA，仅用于她本人实际受到 Harm 时按本桌约定防护；不得拿来替扎雷克调整骰子。
- 不因单人桌而自动减少原作 NPC、削弱异常威胁或替玩家作决定。
- 如需要机构支援，按战役既有“有限、必要、规模相称、来源清楚”的原则；本模组不默认配备行动组。

## 2. 单人桌的主要压力点

1. 线索量与人物数量：避免让玩家必须同时记住五位成员和所有外围人物。按玩家当前关注点调用资料。
2. 社交信息密度：NPC 不排队说明背景。一个场景只让当下自然相关的信息浮现。
3. 行动覆盖：不让凯瑟琳替代队友分工。她可观察、提出个人判断、独立处理自己合理能做的事，但可能误读或不知道。
4. 能力风险：不要为了让扎雷克能力适用而篡改其触发条件；Absence 的 Negatives、Unbound、Missed! 按正式人物卡与中文 v22 执行。
5. 关系信息：玩家可使用自己的 Relationship 或已建立渠道，但不能默认任意社群关系自动存在。

## 3. 角色能力与模组互动（待规则交叉核验）

- Negatives：可检查某物曾存在的位置，观察失去的历史。可能用于调查被移走的设备/物件或现场痕迹，但不得变成全知扫描。
- Unbound：穿越实体障碍；不能自动穿越非实体的域界边界。进入异常域界的方式须根据原文与规则核验。
- Missed!：只在某物可能触碰/伤害扎雷克时触发，不能当作自由传送。
- A3 补给「Scoop 的小小心意」：每场正式任务可用一次；效果是获知指定对象喜欢的一件普通、容易获得的日常物品，不生成物品、不强迫目标改变行动。若扎雷克使用，按物品既定媒介和规则执行。
- 橡皮鸭：每场任务一次，描述想实现的结果后获得三个步骤；不要自动替玩家使用。

## 4. 多 Session 结构建议

建议按自然进度分为 2–3 个 Session；不是硬性分段，不为测试连续性而拖长任务。

### Session 01：机构简报、受害者与定位
目标：建立电击伤模式，选择一条或多条调查路径，定位 Nosedive。
自然结束点：扎雷克找到 La Cave / 确认派对当晚位置，或已经进入派对并建立第一段关系。
不得强制完成全部三名受害者调查。

### Session 02：派对与成员关系
目标：体验 Nosedive 的社群规则，接触不同成员，理解 Leyden 与成员的风险和分歧。
自然结束点：核心成员愿意与扎雷克进行严肃讨论，或冲突已自然触发。
可在同一 Session 内进入谈判；不要为“每场必须一个高潮”人为打断。

### Session 03：谈判/遭遇与任务后果（视实际需要）
目标：处理 Leyden 与 Nosedive 的未来，执行玩家选择，完成任务报告与结算。
若 Session 02 已自然抵达并解决核心冲突，不需要 Session 03。

## 5. 跨 Session 连续性测试字段

每次结束必须记录：
- 真实游戏内时间、地点、当前场景、在场人物；
- 扎雷克 QA/Harm/资源/装备/持有人/补给使用情况；
- 凯瑟琳 QA/Harm、物品、行动、获知信息和独立承诺；
- 五位成员的位置、轨道视觉状态/实际规则状态、健康/转化状态、计划和对扎雷克的态度；
- 玩家已知信息与信息来源；
- 已建立的信任、承诺、分歧、未完成事项；
- 已发生事件、未发生但已触发的后台行动、下一步自然可能发生的行动；
- 任何 GM ADAPTATION 与规则待核项。

新对话 Preflight 必须重新加载本次所需资料，不以旧 Preflight 状态代替资源恢复。

## 6. 叙事与场景呈现：Show, don't tell

### 行动优先
- 先呈现人正在做什么，再决定是否需要台词。
- 用人物站位、视线、动作、物件使用、停顿、打断、回避和选择呈现关系。
- 用环境变化呈现异常影响；不先告诉玩家“这里很危险/这个人害怕”。

### 对话控制
- 台词必须来自角色目标、知识、关系与当前情境。
- 不让 NPC 轮流向扎雷克解释人物背景；让信息从观察、追问、冲突和交叉验证中出现。
- 沉默、答非所问、转移话题和不完整表达都可用，但不能为了神秘而无故拒绝合理信息。
- 不把 GM 的交互维护语句塞进 NPC 台词。

### 描写密度
- 重要场景提供空间、显著变化、可行动信息和少量感官细节。
- 普通流程压缩；重要发现、选择、风险、关系变化展开。
- 不替扎雷克指定感受、想法或决定。
- “展示”不等于堆砌长段落；每个细节应承担氛围、判断、关系或行动价值。

## 7. 未经授权不得做的适配

- 不把 Leyden 直接写成恶意反派。
- 不强迫扎雷克选择机构收容；保留原文结局选项。
- 不把 Venice、Mimi 的立场改成可轻易说服。
- 不把凯瑟琳变成第二名特工。
- 不为达成多 Session 测试人为增加支线、时间压力或额外敌人。
- 不提前补齐原文未提供的特殊战斗规则；标记 UNKNOWN 并回查。
