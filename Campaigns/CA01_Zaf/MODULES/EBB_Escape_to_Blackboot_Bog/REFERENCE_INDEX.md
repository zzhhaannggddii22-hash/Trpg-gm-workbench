## 特殊机制提醒
- **Bernhildi**：Critical Damage 不会结束战斗；只有 STR 降至 0 才真正死亡。除非头部被酸、火或强大魔法处理，否则 d4 天内完全再生。
- **Sieger's Whip**：3 charges；可安抚或激怒非智能野兽；recharge 需用鞭子勒死一只无辜生物。
- **Warhound Critical**：目标须通过 DEX save，否则犬只撕开其喉咙。
- **Martelhardt**：厌恶火；尸体留在森林且未焚烧/移走会慢慢再生；Critical 会让苔藓与枝条从伤口生长。
- **Night Cat Critical**：开始啃食仍活着的目标，造成 d4 STR damage。
- **Dryads**：Befuddle 每轮 WIL save；橡果袋 3 uses，每颗种下长成 20 英尺橡树；送橡果给 Gertrud 得 Bog +1 clue。
- **Moon Druids**：大锅恢复 d6 STR、去除 1 Fatigue；随后 d4 小时所有攻击 impaired、攻击它们的人攻击 enhanced。
- **Lute of the Accomplice**：Auditory Illusion 不加 Fatigue；3 charges；演奏并得到路人小费可 recharge。
- **Werepig Charm**：目标服从至 Werepig 死亡；每轮 WIL save 可解除。
- **Bog clue**：每条小屋位置线索 +1；携带测绘图另 +2。
- **Shambling Mound**：若逃跑持续追逐；被杀或吞下一名 PC 前不重掷结果 3；之后再出 3 即追上。
- **Will-o-Wisp**：成功 WIL save 且给出精神性献礼后可带路；Bog +1。
- **Gertrud 信件分支**：条件严格为“If she does not read the letter”，不是“未收到信”。
