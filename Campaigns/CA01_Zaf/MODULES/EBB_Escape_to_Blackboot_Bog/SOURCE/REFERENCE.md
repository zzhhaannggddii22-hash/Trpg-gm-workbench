## Source discrepancy
Path 7 has two different travel times in the same PDF:
- Page 5 Summary of Paths: 1 hour.
- Page 8 River scene: 2 hours.

This is retained as a source discrepancy, not a silent transcription correction. The player has ruled that this Campaign uses 1 hour. See MANIFEST and GM_ONLY_PREP.
