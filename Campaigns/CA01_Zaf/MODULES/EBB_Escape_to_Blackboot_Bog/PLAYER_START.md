# EBB｜Player Start

> 玩家可见资料。不要在此文件加入 GM-only 真相、隐藏 NPC 动机或未揭示遭遇表内容。

## 委托
Broedingen 城门之外，Chamberlain Wigand 将年轻的 Viscount Lorenz 托付给你们。你们要护送他前往 Blackboot Bog 深处 Auntie Gertrud 的小屋，并在日出前抵达。

Wigand 会交给队伍一张区域地图，以及一封写给 Gertrud 的密封信。小屋位于沼泽深处，具体位置尚不明确；途中可能有人愿意提供线索，但没有人能保证旅途安全。

## 时间压力
从出发起，你们有 8 小时。主持人会清楚告知已经过去的时间与剩余时间。恰好第 8 小时抵达仍算及时。

## 路线选择
离开城外后，可以考虑：
- **道路**：直接且较快，但更容易遇到正在搜查道路的军队。
- **森林**：阴暗、路线不明，需要考虑光源；当地流传着森林精灵出没的传闻。
- **丘陵**：路程艰难，已知有敌对类人生物活动。

之后还可能通过河流、桥梁、田野、湖泊与沼泽寻找前进路线。路线选择由玩家决定，主持人会根据角色实际观察到的信息描述风险。

## 地图
玩家地图使用官方 PDF 第 4 页区域地图。图例与路线摘要在第 5 页。地图标出区域和路线关系，不会替玩家揭示隐藏遭遇或小屋确切位置。
