# Bower Street｜Session Log Index

当前没有实际发生的 Session。

新建每场记录时使用 `Sessions/SESSION_01.md`、`SESSION_02.md`……按编号追加，不覆盖历史记录。

每份 Session Log 只记录：
- 玩家实际声明并执行的行动；
- GM 实际呈现的环境、NPC 陈述与事件；
- 实际取得的线索及其获取来源；
- 实际掷骰、规则裁定、QA/Burnout、Harm、Chaos 与装备变化；
- 场景、时间、位置、NPC 知识与状态变化；
- Session 结束快照与未完成事项。

不得将备团中预设的线索、NPC 对话或计划事件写成已经发生。每次 Session 结束后同步更新 `03_RUNTIME_STATE.md`。
