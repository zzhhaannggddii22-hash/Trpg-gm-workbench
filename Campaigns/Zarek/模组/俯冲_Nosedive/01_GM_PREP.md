# 《俯冲》（Nosedive）｜GM Prep

> **GM-only。含完整模组真相、异常机制、NPC 秘密、调查答案与结局条件。**
> 事实标签：SOURCE=中文 v22《密库》母稿；GM INFERENCE=主持推断；GM ADAPTATION=本桌单人桌适配；UNKNOWN=待核。

## 1. 来源与核心定位

SOURCE：Haunted Table Games，《The Vault: Missions for Triangle Agency》，Caleb Zane Huett 编写、Marie Enger 插画。中文 v22 母稿定位：源 PDF 102–110，印刷页 198–215。

五名年轻共振者在特尔尼恩市（Ternion City）的派对街区维持游牧派对 Nosedive，为当地酷儿社群提供空间。机构因多起异常电击伤追查到 Nosedive。其成员之一 Leyden 已因过度使用异常能力完全转化为异常；她的电力能力持续保护派对，但焦点逐渐收窄，安全执念正威胁整个团体。其余四名成员也在过度使用能力后逐渐逼近转化。

任务核心不是“找出坏人并击败”，而是处理一个真实存在的危险、一个具有自主意志的社群，以及他们对 Leyden 未来的不同判断。机构提供的收容方案与成员的关系和自主意愿可能发生冲突。

## 2. 固定事实基石（SOURCE）

### 2.1 五位成员

- Venice（ve/vem/veirs）：团体领袖；与价值异常结合，身体皮肤已被闪粉取代，拥有强烈吸引注意力的效果。
- Wodge（he/him）：身体可分裂成受控部件，细至原子层面；能通过舞池连接形成低强度蜂群共情。
- Mimi（they/them）：触摸肉体即可重塑；害羞，持续使用能力已接近转化。
- Feast（she/her）：与汲取异常结合后获救，身体布满嘴巴；能吸收接触到的化学物质及其他物质，常用于帮助过量或不适的来客。
- Leyden（she/her）：电力异常；已完全转化，主要以电流存在，可借技术设备投影人类外表。她的焦点是 Nosedive 的安全，也是本模组唯一能使用混沌的成员。

其余四人是共振者；Leyden 已是异常。不要把五人都描述为同一种状态。

### 2.2 Nosedive 的运作方式

- 派对地点不断移动；本晚地点为 La Cave，一家高档三层酒吧。SOURCE：派对在哪里，域界就在哪里；今晚 Nosedive 的 Domain 位于 La Cave。Venice 通过闪粉幻象买下该场地。该 Domain 属于目标异常 Leyden（GM INFERENCE：她是本任务唯一有焦点、能使用混沌的异常）。按中文 v22 核心规则，异常在自身 Domain 内的混沌效果有特殊费用规则：费用不高于 3 的效果免费显现；实际花费的混沌按三倍计算。该规则如何与本模组“Leyden 是唯一能使用混沌”及域界移动结合，现场按规则原文核对；不可把此收益自动套给其他四名无焦点共振者。
- 派对安静时无法定位；人群会像浪潮一样涌来，La Cave 在几分钟内超员。
- 手机必须关机收起；禁止拍摄。
- 不许暴力、不许制造坏气氛；来客需要帮助时可找 Feast。
- 派对免费；只要不伤害现场的人，成员尽量不拒绝来客。
- 闪粉会改变服装的视觉呈现，但不改变衣物的物理性质；效果纯视觉。

### 2.3 异常状态与焦点

Leyden 的焦点：Nosedive 的安全。她把电力能力用于保护 Nosedive，甚至防范很小的威胁。她只能通过吸引注意力到自己的焦点来维持生存；让 Nosedive 变得不安全，会直接威胁她的生命。其他成员没有焦点，因为他们仍是共振者。

孤立共振者每次使用异常能力都会让异常更强。机构与 Urgency（译名待核）能够稳定盟友，让他们继续保持与原本自我的联系。没有稳定力量，结合者最终会完全转化为异常。绝望时，共振者可以从另一个异常或常人身上汲取稳定性，但目标会死亡。

### 2.4 成员独特轨道

SOURCE：官方样章 PDF 第 17 页（印刷页 202–203）清楚展示四条九格轨道的预填格。结合紧邻规则“每花费 1 Chaos，在对应 Host 的轨道上标记一格”，这些填色格就是任务开始时已经标记的轨道进度。未标记格为可继续标记的剩余空间。图示与规则相互印证；这不再是 UNKNOWN。原文没有进一步交代每个预填格对应的具体过往事件，因此只记录机械上的开场进度，不编造其叙事来源。

|---|---:|---|
| Feast | 0/9 | 九格均空；剩余 9 格 |
| Venice | 1/9 | 第 1 格已标记；剩余 8 格 |

## 3. 任务开场与调查入口

### 3.1 任务简报

机构收到报告：Ternion City 多家医院出现奇怪电击伤。三名受害者地址可供调查：
- Cass Gilmore：Foxglove Apartments。
- Gabriel “Gabe” Knox：Downtown Apartments / Big Cheesy。
- Julie Bennett：Ternion General Hospital。

### 3.2 早间会议可用场景（SOURCE）

- 扎雷克生活中的某个人经历了剧烈且自愿的身体变化，并对此感到高兴。
- 有人花高价购买一件被闪粉覆盖、实际毫无价值的垃圾；常人认为它极其值钱，异常效果对特工不起作用。
- 市中心企业或银行遭遇重大黑客攻击，账户被清空，造成轻微不便或迫使其关门。
- 政客把过去一年药物过量与相关住院人数下降的功劳归于自己。
- 一群年轻酷儿在咖啡店不说话，吧台人员却准确制作各自饮品并知道他们要付多少钱。

这些是可选晨会素材，不是必须发生的 CANON 事件；只在自然相关时使用。

### 3.3 受害者与实际经过

**Cass Gilmore**
- 表面伤势不明显；接触导电材料会遭受疼痛电击。
- 实际上她因与 Mimi 争论派对成员是否应帮助更多人而被某位成员电击警告；持续静电已减弱。
- 她隐瞒 Nosedive 参与经历；信任建立后可透露自己是 Mimi 的朋友、曾自愿接受身体改变，也认为 Nosedive 对酷儿社群有价值。
- 她认为其他成员误以为她要曝光 Nosedive，但她不会这么做。

**Gabe Knox**
- 双臂对称灼伤、黑眼圈与瘀伤来自派对中的斗殴。
- 他喜欢 Venice；对自己的性取向困惑，担心自己没有时间处理这一问题。
- Cody 是供货人，可能帮助联系 Nosedive；回复可能要等到午夜左右。
- 若特工给予支持，Gabe 后续会尝试在社群中找到自己的位置，而不只围绕 Venice。

**Julie Bennett / Julie Bean**
- 知名内容创作者，独立音乐人；手机过热并灼伤双手。
- 她在拍摄 Nosedive 时，屏幕出现 Leyden 的脸并警告“NO PHONES”，随后手机失控。
- Leyden 会监视她；若特工显得威胁且 Julie 泄露过多信息，Leyden 可进入正在播放的电视节目，借角色大喊让 Julie 闭嘴，并让护士把特工带离。若特工没有伪装，Leyden 会记住他们；其后续质询的语气会明显受特工行为与提问方式影响。
- Julie 乐于分享信息；若特工看起来像警察，她会提醒他们换装，以免引起注意。

### 3.4 找到 Nosedive

可用路径：
1. Cody（经 Gabe）、Julie 的线上观众、Cass 发给 Mimi 的短信；预计约午夜得到回复。
2. 联系属于酷儿社群或熟悉当地派对场景的 Relationship；对方已计划参加，等朋友通知。
3. 在市中心探索：La Cave 周边年长富裕酒吧客人会抱怨派对扰乱夜晚。
4. 使用异常能力。

不要让玩家必须走完三名受害者的完整调查才找到派对。不同路径应独立可行。

### 3.5 可选目标（SOURCE）

- 辨认某样闪闪发光的东西其实是金子：每名特工 +1 Commendation，每人最多 3 次。
- 参与编排好的舞蹈：每名特工 +6 Commendations，一次。
- 每写出一句使用自嘲措辞的句子：+1 Demerit。

具体如何判定“自嘲措辞”需在实际发生时按原文语义公平裁定；不可为了惩罚玩家任意扩大范围。

## 4. La Cave 与派对场景

### 4.1 门口

Charles 是 La Cave 员工，担心超员、噪音和酒精；Charlie 是 Feast 的朋友，负责协助管理入口。Venice 已向酒吧老板支付高额费用，确保没人赶走派对。

Charlie 会说明派对规则。特工到达时，一组三位朋友正请求进入；其中一位清醒者显得紧张，Charlie 让人群让开。刚才醉酒的朋友离开时已清醒，显示 Feast 的帮助效果。

### 4.2 场地结构

- 三层、狭长向上的高档鸡尾酒吧。
- 底层：主舞池、白色大理石桌与金色椅子；彩色玻璃天花板投下彩色光影。
- 二层：吧台、较疏的人群与闲聊者。
- 三层：Venice 的 VIP 法庭/仰慕者区域。
- 屏幕与扬声器临时固定在金色栏杆；Leyden 的投影在不同屏幕间跳动。
- 三楼有强光与闪粉落下的视觉迹象。

### 4.3 视觉与场景锚点

- 派对审美参考 Club Kids 运动及受其影响的现代时尚：服装不实用、色彩强烈、强调主题、新奇与冲击，而非传统美感。
- 入口附近有一只装满闪粉的大玻璃碗；来客撒上闪粉后，整套服装会发生夸张的纯视觉变化。衣物本身不会因此被撕裂、弄脏或触碰；效果不改变物理性质。
- 舞池是低强度群体连接的中心；二楼是较安静的吧台与闲聊区；三楼是 Venice 的 VIP 法庭。

### 4.4 场景入口

- 舞池与 Wodge：人群同步移动，舞蹈带来温柔的连接感；Wodge 位于人群中心。
- Venice 的法庭：需要创造性地使用闪粉或主动寻求关注。
- Mimi 的变形：Wodge 是最直接的引荐方式，但不是唯一方式。
- Feast 的插曲：有人因 Ketamine 过量倒地并抽搐时，音乐停止、屏幕切到 Leyden，提示人群让开；Feast 从二楼栏杆跃下，由 Mimi 迅速长大接住并轻轻放下。Feast 用嘴巴接触该男子，数秒后他平静下来；Nosedive 鼓掌，派对恢复。
- Leyden 的审问：二楼与三楼之间，屏幕里的 Leyden 质询特工；她会通过设备持续监控。

### 4.5 手机与行为规则

禁止拍摄；手机关机收起。暴力或制造坏气氛者会被立即赶走，并可能触发遭遇。派对规则是社群边界，不是供 GM 任意惩罚玩家的理由；先让玩家看见规则与后果，再按原文触发。若玩家不知道 Mimi，Charlie 不会主动进一步解释她；知道 Mimi 后，仍应通过 Wodge 或其他合理渠道接触。

## 5. 五位成员的行为基线

完整人物动机、知识边界和对话行为见 [03_NPC_BEHAVIOR_LEDGER.md](./03_NPC_BEHAVIOR_LEDGER.md)。关键关系：
- Venice 与 Leyden 不愿分开；Venice 最重视 Nosedive 的完整性。
- Feast 与 Wodge 可被说服机构可能保护 Leyden，但他们不了解密库研究细节。
- Mimi 已察觉自己也开始难以维持固定形态，对继续帮助他人感到不确定。
- Wodge 愿意信任别人，通常能成为社交入口。
- Feast 关注成员的安全，可能愿意为他人牺牲。
- Leyden 会把可疑者视为威胁，保护派对是她的首要反应。

## 6. 遭遇与谈判

遭遇可以由以下情况触发：
- 全体成员被召集开会；
- 事件升级为暴力；
- 特工在未达成共识时试图捕获 Leyden；
- 特工直接攻击或破坏 Nosedive。

若特工采取攻击性行动，直接进入 Fighting it Out。若只是紧张或可疑但无暴力，Venice 可能召集成员讨论。

### 谈判选项（SOURCE）

- 让 Leyden 进入常规公文包：理论上可以说服所有成员，但 Venice 最难说服；若成功，Venice 会永远憎恨特工。Leyden 只有在所有成员都认为应当如此时才自愿进入。
- 让成员加入 Urgents：最终可以说服所有人，但 Wodge 只有在其他所有人都去的情况下才会去。
- Feast 与 Wodge 可以成为特工；Venice 与 Mimi 永远不会。
- Feast 与 Wodge 可被说服让 Leyden 去 Vault，前提是他们不知道密库研究的真实细节。若特工把 Vault 描述为安全之地，或谎称机构可能帮助 Leyden 恢复人形，他们会最先同意；这是玩家可选的欺瞒，不替玩家预设。
- 若谈判破裂或 Nosedive 被扰乱，所有成员会动员把特工赶走；Leyden、Venice、Feast 坚守，尝试让两个年轻成员逃走。

不要预设唯一正确结局。选择会产生持续关系和派系后果。

## 7. 余波与任务结算

- 至少一名共振者被捕获、进入公文包、成为新员工或被消灭，则该人视为目标异常。
- 若没有异常被捕获或消灭，目标异常视为逃脱。
- 报告其他成员存在时，每名逃脱成员可能带来相应惩罚；额外捕获或招募成员则获得捕获奖励。
- Nosedive 若获得外部支持和保护，即使 Leyden 状况不变，也可能长期存续。
- 若成员不加入机构或 Urgents，仍有完全转化风险。
- 若 Nosedive 延续，可能发展为拥有自身理想与利益的派系：他们可能想把派对扩展到单一场地之外，或庇护不愿加入 Agency/Urgency 对抗的其他异常与共振者。若成员逃脱且玩家能够与他们交朋友、创造新补给，或从被消灭的成员身上获益，原文允许将每名成员分别视为一个异常处理相应后续。

详细任务奖励、报告、Loose Ends 和任务结果按中文 v22 原文重新核对；不可仅凭本摘要结算。

## 8. 结局后续与可解锁内容（SOURCE）

### Vault Requisition：Additional “Urgents”

若成员转化为机构成员，他们不是普通 Requisitions，而是加入 Urgents 清单；只有解锁 Playwalled Document W8 的特工才能使用其能力，且须遵循该文档的规则。能力记录如下，当前仅作未来档案，不代表扎雷克已解锁：

- Venice — Costume：让当前衣服呈现任意外观，持续 24 小时；费用条件：先让某人感到自己受到重视。
- Wodge — Connect：约 30 米内无差别听见所有人的思绪，除非思绪自行暴露来源，否则不知道来自谁；费用条件：先让两个人看到彼此共同点。
- Mimi — Sculpt：改变正在触碰的任何肉体；费用条件：先做出令自己自豪的东西。
- Feast — Sacrifice：承受原本施加给他人的 Harm、让针对他人的 Chaos Effect 改为针对自己，或接过他人的病症/伤势；费用条件：先向某人许下准备兑现的承诺。
- Leyden — Overload：触碰电子设备，使其持续执行某项主要功能直到耗尽电力或被毁；费用条件：先保护一个在乎的人免受伤害。

### Anomaly Ability：Nosedive VIP

达到某名成员的最大 Connection（通过 Seek）后，获得：每场任务一次，若该成员有空，可请求其使用能力协助，代价为代表该成员支付任意组合的 3 QA；每场任务一次，可请求 Nosedive 当天出现在指定地点，但若会使派对参与者明显陷入危险则会拒绝。若与至少 3 名成员达到最大 Connection，派对可作为特工的 Domain，遵循 Playwalled Document X2 的 Domain Creation 规则。扎雷克当前未拥有这些 Connection；此项只作结局后长期钩子。

## 9. 原文之外的主持约束

- 不把社群成员简化为“待收容目标”；他们的意愿、关系与危险都是真实的。
- 不用 GM 旁白解释角色动机；用动作、选择、对话节奏和关系反应展示。
- 不让所有 NPC 排队向扎雷克发放线索；信息通过各自可信渠道流动。
- 不因扎雷克是单人 PC 就自动让凯瑟琳知道、解释或解决关键问题。
- 所有 GM 补充必须标 GM ADAPTATION，并进入 Runtime State/Session Log。
