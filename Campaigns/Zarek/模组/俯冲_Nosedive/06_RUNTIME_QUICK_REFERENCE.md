# 《俯冲》｜Runtime Quick Reference（GM-only）

> 现场入口；不是完整备团。详细事实见对应权威文件。

## 当前阶段
- Prep QA 已于 2026-11-23 执行，原始结论不通过；针对性修订与最终定向复核已完成。首次 Preflight 已于 2026-11-23 执行；等待玩家审核与开团前最终确认，未开团。
- 任务目标：调查电击伤，定位异常来源，处理 Leyden/Nosedive 的现状。
- 原文页码：印刷 198–215；源 PDF 102–110。

## 主要入口
- 机构简报 → 三名受害者（Cass / Gabe / Julie）→ 多路径定位 Nosedive → La Cave → 五位成员 → 谈判/遭遇 → 余波。
- 不要求走完所有受害者线。
- 派对安静时无法定位；派对人群涌入后 La Cave 快速超员。

## Domain
- Nosedive 的 Domain 随派对移动；本晚位于 La Cave。该 Domain 属于目标异常 Leyden（GM 推断）；核心规则：Domain 内 3 Chaos 及以下效果免费显现，实际花费的 Chaos 按三倍计算；非整除结果按本桌裁定向上取整（TABLE CANON）。仅用于 Leyden/异常的 Domain 规则，不自动套给其他成员。
- Leyden 的 Focus 是 Nosedive 安全；让派对不安全直接威胁她的生命。

## 五位成员
- Venice：领袖；最难说服；保护 Nosedive；不愿 Leyden 被拆散/实验。
- Wodge：友善、信任他人；舞池入口；21 岁生日；与 Mimi 是大学室友；只有其他所有人一起加入 Urgents 才会跟随。Gabe 的爱慕 Venice 与斗殴嫉妒线不属于 Wodge。
- Mimi：害羞；身体重塑；自身也逼近转化；不会成为特工。
- Feast：照料来客；可吸收物质/处理过量；愿为成员牺牲；可被说服机构可能保护 Leyden。
- Leyden：已转化为电力异常；焦点 Nosedive 安全；监控设备、对可疑者敏感。

## 派对规则
- 手机关机收起，不许拍照。
- 不许暴力，不许坏气氛；有需要找 Feast。
- 派对免费；不伤害现场的人，成员尽量不拒绝。

## Leyden 质询
- 为什么上楼？来参加派对还是另有目的？怎么听说 Nosedive？是否与 Julie Bean 一起偷偷调查？
- 已结交的 Host 会阻止 Leyden 继续逼问并安抚她；若没有这份关系，需 Venice 邀请或另一名 Host 陪同才能上三楼。进入严肃话题时若 Venice 对特工印象良好，ve 可承诺无人逃跑，允许继续参加派对，并在夜末后巷会面。

## 触发器
- 特工创造性使用闪粉 → Venice 可能注意并邀请。
- 直接找 Mimi → 她可能融化离开；Wodge 是直接入口。
- 有人过量/不适 → Feast 插曲。
- 特工显得有一点可疑 → Leyden 把他们引向 Venice；若她认为特工像警察，或特工试图捕获她 → Encounter。
- 未经共识试图收容 Leyden或暴力扰乱 → Encounter / Fighting it Out。

## 谈判立场
- Venice 与 Leyden反对被分开；Venice 最难说服。
- Feast/Wodge 可被说服机构可能保护 Leyden，但需考虑他们不知道密库研究细节。
- Mimi 可透露自身转化前兆。
- 可说服所有 Host 同意 Leyden 入包；Leyden 只有全体 Host 一致同意才自愿进入。不是所有 Host 同意自己入包。Venice 最难说服，成功后会永远憎恨特工。
- 加入 Urgents：Wodge 只有其他所有人都加入才会去。
- Feast/Wodge 可成为特工；Venice/Mimi 不会。

## 可选目标
- 辨明闪闪发光的东西是否为金子：+1 Commendation（每名特工最多 3 次；不要求答案必须为“是”）。
- 参与编排好的舞蹈：+6 Commendations（每名特工一次；不要求玩家亲自编舞）。
- 每句自嘲措辞：+1 Demerit；原文不限书面表达，按角色实际表达与语义公平裁定，不把普通规则提问或玩家离场发言扩大计罚。

## Chaos 运行纪律（每次行动即时结算）
- Leyden 是本模组唯一使用普通 Chaos Pool 的成员；开场 Pool = 0（模组未指定其他初始值）。普通 Pool 的当前数量及变化向玩家公开。
- 四位共振者（Venice/Wodge/Mimi/Feast）的个人九格轨道与 Leyden 的 Pool 分开记录；非免费能力使用按效果等级标记各自轨道，不混扣普通 Pool。个人轨道仍属 GM-only。
- Leyden 在 Domain 内的免费显现与实际 Chaos 支出分开判定；实际支出按中文 v22 规则计算三倍；非整除结果按用户确认的本桌裁定向上取整（TABLE CANON）。
- 每次生成、发动效果、免费/倍率判定、实际消耗、Pool 前后值、个人轨道变化均即时记账；结束时复算并按规则结算 Pool 去向。
- 普通 Chaos Pool 当前数量及变化始终向玩家公开；这是规则明确的公开信息。GM-only 仅保留个人九格轨道、NPC 动机、隐藏触发和后台计划等确属秘密的内容。

## 高影响规则核验
- 四条共振者九格轨道（官方样章 PDF 第 17 页 / 印刷页 202–203）：Feast 0/9（剩 9）、Venice 1/9（剩 8）、Wodge 3/9（剩 6）、Mimi 6/9（剩 3）。预填色是开场已标记的轨道进度；同页规则规定每花费 1 Chaos 再标记一格。原文未说明预标记的具体过往事件，不补写。
- 能力免费条件：使人开心/创造 Nosedive；其他用途按效果等级支付 1/2/3 Chaos，并标记轨道。
- 轨道填满：立即转化，+21 Chaos，成为拥有 Nosedive 安全焦点的强大异常；Feast 可牺牲自己清空目标轨道。注意 Mimi 开场只剩 3 格，Wodge 剩 6 格。
- 效果等级：Minor 1 格，可造成 1 Harm，或保护自己／他人最多 3 Harm；Major 2 格、3 Harm（需要专注的重大效果；四名共振者无 Focus，不得把此处译义理解为要求其拥有异常 Focus）；Extreme 3 格、5 Harm。费用按对应 Host 的个人轨道支付，不扣普通 Chaos Pool。
- Encounter 的 Special Rules 交叉引用指向模组 Unique Rules 系统；没有独立的传统战斗数值卡。
- 不猜测 Urgency / Urgents 译名与背景。
- 规则以用户指定中文 v22 为准。

## 检定与资源规则提醒
- 普通检定只能使用本次所用 Quality 的 QA；不能跨属性挪用。Ask the Agency 按所选相关职业素质使用 QA。
- 人寿保单防伤害是明确例外：每 1 Harm 可用任意素质 1 QA 忽略其后果。
- 普通 Chaos Pool 余额与变化始终向玩家公开；Host 个人九格轨道及 NPC 后台信息保密。
- 普通危险/困难行动没有通用技能检定，默认失败；由玩家决定是否请求机构、使用异常能力、装备或改走其他方案。不得强迫掷骰。
