# Sessions｜场次日志目录

本目录只存放实际发生的 Session 日志，不预写玩家行动。

- Session 01：尚未开始；开始后创建 `SESSION_01.md`。
- 后续 Session 依序创建独立文件，不覆盖历史日志。
- 每场结束更新模组根目录的 `08_RUNTIME_STATE.md`；日志保存事实经过，Runtime State 保存当前有效状态。
- 新对话/新 Session 开始时必须执行独立 Preflight，重新加载本次需要的资料。
- 本模组尚未执行 Prep QA；该流程可选，若执行必须在第一次 Preflight 前完成。第一次 Preflight 后 Prep QA 窗口关闭。
