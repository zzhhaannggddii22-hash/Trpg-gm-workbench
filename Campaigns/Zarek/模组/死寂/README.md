## 原始资料与历史快照

本目录已集中复制该模组的开团准备、外部研究、早期 Session Log 与玩家便笺，避免调用时在不同目录拼接资料。原始文件仍保留在 `GM_Training/` 根目录作为历史来源；本目录中的副本用于按模组整体调用。中文规则书与《密库》原文仍以其独立权威仓库为准，不复制整本规则文本。

## 调用规则

- **继续扎雷克战役**：先读本目录 README、04 奖励、05 CANON、07 状态账本，再读角色档案与最新交接。
- **复盘模组设计**：读 06，再对照官方模组原文；不要把 GM 补充写成原文。
- **审查奖励**：以 04 为当前结算权威；历史 Session Log 里的旧数值仅代表当时快照。
- **检查规则**：以用户指定中文 v22 为准；08 只提供定位，不替代原文。
- **历史文件**：`GM_Training/SESSION_LOG_DEAD_QUIET_2026-11-20.md` 和玩家便笺保留早期暂停状态，不应再当作最终状态。
