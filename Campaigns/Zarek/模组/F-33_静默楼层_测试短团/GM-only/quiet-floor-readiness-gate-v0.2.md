## 二、角色卡完成后的核验结论

### 1. 实际 ARC 角色验证（已完成）

- 角色档案：Zarek；Absence / Newborn / R&D。
- QA：Professionalism 3、Empathy 3、Subtlety 3；其余六项 0，总计 9。
- Ability：Missed! 使用 Duplicity；Negatives 使用 Attentiveness；Unbound 使用 Subtlety。Trigger、Quality、成功／失败及额外 3 条件已逐项核对。
- 关系：三段；由 GM 扮演，不创建第二名玩家特工。

### 2. 数值与遭遇适配（纸面核验已完成）

- Duplicity 与 Attentiveness 起始 QA 为 0，相关掷骰承受 1 Burnout；Subtlety 有 3 QA。
- 基础 6d4 至少一个 3 的概率约 82.2%；1 Burnout 后需要至少两个原始 3，概率约 46.6%。
- Newborn 的 Burnout Release 是条件性豁免，不是常驻免除。
- 角色没有攻击型异常能力；调查与任务解决路线不得强制攻击或物理耗竭。
- F-33 的 7 Harm 仍是低端候选，未锁为本模组数值；不应为配合数值而否定玩家的规则允许行动。

### 3. 单特工任务评优适配（已确认）

- 不评定 Probation 或 Mission MVP，不执行多人相对排名。
- 按 Participant 的叙事功能授予参与奖绶带，并允许玩家选择一段关系增加 1 点 Connection（以关系场景与规则字段适用为前提）。
- 任务结果、报告、可选目标奖励及最终申诉按官方规则独立结算。

### 4. 剩余的开团前事项

- 玩家审阅并确认角色档案；姓氏、地方语言与住宿安排仍可调整，不作为机械阻塞项。
- GM 向玩家提供无剧透任务简报。
- 确认骰子由谁掷、公开记录方式、暂停／停止信号与内容边界。
- 玩家明确表示开始正式任务。

- [x] 玩家已完成 ARC 角色卡，并提供本次游戏所需字段。
- [x] GM 已完成实际角色资源与能力纸面核验。
- [x] 单特工任务评优方式已由玩家确认。
- [ ] 玩家收到无剧透任务简报，且知道任务目标与可选目标奖励。
- [ ] 确认骰子由谁掷、六枚 d4 如何公开、QA/Burnout/Chaos 如何记录。
- [ ] 确认暂停、停止和内容边界信号。

所有项目勾选后仍需玩家明确发出开始指令。任何 GM 自评、书面压力测试或准备文件都不能自动启动游戏。
