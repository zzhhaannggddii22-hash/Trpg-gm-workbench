# 机构常驻 NPC 索引

> 用途：维护跨模组需要再次检索、对三角机构或扎雷克战役有持续影响的机构人物。此处是身份索引与档案入口，不复制每个人物的完整设定。未实际登场的人物不预先建立 CANON。
>
> 本索引是跨模组检索入口，不等同于 NPC 层级判定。人物是否升级，按《CHARACTER_SIMULATION_SKILL.md》的实际互动、叙事地位和连续性要求判断；不能仅因再次出场或被登记到本索引就自动升级。

## NPC 层级与归档规则

- **L0｜临时功能性路人**：一次性场景角色，默认不建立人物卡；只维护当前功能、即时目标/知识和必要的一两个说话或行为特点。反复与玩家互动后再评估升级。
- **L1｜模组级人物 / 低重要性战役人物**：当前模组中值得建立人物信息卡的角色；低重要性、互动有限的战役岗位也可保持 L1。档案按范围留在模组或战役索引，首次出场以简洁、有辨识度的特征建立初步印象。
- **L2｜战役常驻配角 / 长模组重要人物**：战役中有稳定职务或持续作用、预计再次登场的重要配角；也包括长模组中与玩家大量持续互动、可能存在人物弧的角色。维护稳定动机、关系、知识、权限和跨场景变化。
- **L3｜战役级核心长期角色**：对 PC 或主线具有核心意义，跨模组持续发展，需要完整维护长期经历、记忆、关系和成长的角色。归战役目录并拥有独立长期人物档案。
- **L4｜助手人格**：仅用于凯西，不属于 TRPG 战役角色，不登记在本战役 NPC 索引中。

### 升级规则

- L0 → L1：玩家反复主动与人物互动、持续寻找人物，或人物持续影响调查、选择和后续事件时，建立人物卡；只记录已确认事实。
- L1 → L2：人物成为重要战役常驻配角，或在长模组中成为持续参与关键场景的重要互动对象，并需要维护更丰富的目标、关系、知识或潜在人物弧。
- L2 → L3：人物达到战役核心地位，对 PC 或主线具有长期重要性；需有实际故事依据。
- 普通低重要性岗位可以继续保持 L1；跨模组出现本身不自动构成 L2 或 L3，实际互动增加后再重新评估。
- 升级时保留原规范 ID、首次登场来源和既有 CANON；扩展或迁移档案时，旧模组文件留下引用。

## 待登记

- 局长／机构负责人：**尚未建立 CANON**。玩家曾将其作为未来机构人物的设计示例；在实际登场、姓名与职务确定前，不预设人物事实，也不预先分配 L2/L3 层级。
- 其他机构人员：实际登场后，先按 L0/L1 判断；重要战役常驻配角再升为 L2；只有真正成为战役核心长期角色时才考虑 L3。

## 维护字段

- L1 人物卡：规范 ID、姓名与别名、来源支持的身份/背景、当前目标与顾虑、知识边界、能力/资源、关系、辨识特征、行为倾向和重要状态。
- L2 人物档案：在 L1 基础上增加稳定目标、内部矛盾、权限与资源、跨模组互动、关系演变、记忆与承诺；具有潜在人物弧时记录发展方向和触发条件。
- L3 长期档案：维护战役长期经历、人格核心、长期目标、关系网络、承诺、生活背景、成长、能力/权限和知识边界。
- 本索引自身只保留规范 ID、当前层级、档案入口和必要的跨模组检索提示，不复制完整人物档案。

模组文件只引用规范 ID 和当前场景所需信息；不要复制完整人物档案。
