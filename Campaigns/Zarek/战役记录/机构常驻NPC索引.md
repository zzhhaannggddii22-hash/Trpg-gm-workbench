# 机构常驻 NPC 索引

> 用途：维护跨模组反复出现、对三角机构或扎雷克战役有稳定影响的机构人物。此处是身份索引与档案入口，不复制每个人物的完整设定。未实际登场的人物不预先建立 CANON。

## 人物层级与归档规则
- **L1 模组局部 NPC**：只在一个模组/场景中出现，档案留在模组文件夹。
- **L2 战役级常驻配角**：跨模组可能反复出现，拥有稳定职务、性格、动机、能力、权限、知识边界和有限秘密；适度维护档案。
- **L3 核心长期角色**：核心长期搭档或战役核心人物，拥有独立长期档案、生活背景、关系历史和成长记录。
- **L4 助手人格**：仅用于凯西，不属于 TRPG 战役角色，不登记在本战役 NPC 索引中。

人物可从 L1 升级到 L2；L2 只有在累积出核心搭档级关系和持续故事影响后才可升级为 L3。升级必须有实际故事依据，保留原规范 ID 与首次登场来源。

## 待登记
- 局长／机构负责人：**尚未建立 CANON**。玩家将其作为未来战役级常驻配角的设计示例；在实际登场、姓名与职务确定前，不预设人物事实。
- 其他机构常驻人员：待实际登场并满足 L2 条件后登记。

## 维护字段
每位 L2/L3 人物的独立档案应至少记录：规范 ID、姓名与别名、职务/部门/权限、稳定性格与表达特点、当前目标与长期动机、能力与知识边界、GM-only 秘密和玩家已知信息分层、重要关系、历次跨模组登场与互动、承诺和当前状态。

模组文件只引用规范 ID 和当前场景所需信息；不要复制完整人物档案。
