## 归档范围
凡是在 Triangle Agency 规则下沿用扎雷克当前人物卡开展的正式战役、幕间场景、角色成长、NPC 关系、模组记录和世界后果，均归入本文件夹。新模组独立归档；人物与经历跨模组持续。

GM 能力测试、未进入正式 CANON 的短团可作为测试模组单独归档，但必须标记测试性质，不能把测试中的奖励、处分、关系、装备消耗或世界后果带入正式战役 CANON。

## 记录层级
1. **正式人物卡**：Session 边界上的角色状态快照；每场开始时读取，每场结束后依据 Resource Ledger 对账并更新。
2. **模组 Resource Ledger**：Session 内所有资源交易的唯一流水来源与余额计算依据，覆盖角色资源、模组公共资源及有机制意义的装备充能/次数。
3. **Session Log / Runtime State**：Log 记录事件与玩家可见结果；Runtime State 记录场景和必要的关键物品快照，不重复记录资源流水或自行计算余额。
4. **模组文件夹**：模组原文摘要、GM-only 准备、Session Log、玩家便笺、结算、复盘与余波。
5. **战役记录**：跨模组 NPC、关系、承诺、未完事项与角色可知信息。
6. **GM-only 与玩家侧资料严格分层**；秘密和后台事实不得进入玩家侧便笺。
