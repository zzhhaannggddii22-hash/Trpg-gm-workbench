## 记录层级
1. **正式人物卡**：跨模组长期权威状态。
2. **当前场次副本**：每场开局从正式卡同步；场次中记录临时 QA、Harm、装备与事实变化；结束后核验并回写正式卡。
3. **模组文件夹**：模组原文摘要、GM-only 准备、Session Log、玩家便笺、结算、复盘与余波。
4. **战役记录**：跨模组 NPC、关系、承诺、未完事项与角色可知信息。
5. **GM-only 与玩家侧资料严格分层**；秘密和后台事实不得进入玩家侧便笺。
